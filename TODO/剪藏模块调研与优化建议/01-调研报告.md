## 一、模块全景

### 1.1 架构与数据流

```
[浏览器扩展]                          [前端页面]                    [Electron 桌面]
content.js(页面提取)                  frontend/clip.html           main.js(SPA壳+端口管理)
   │ 选中文本/正文/URL/标题                │  表单/列表/详情/整理        │  生成 application.yml(8081)
background.js(路由/发送)              ────────┐                     │
   │ 右键/快捷键/浮动按钮/popup               │  axios                 │
   │ POST /api/clip/add                    ▼                       ▼
   ▼                               [Spring Boot :8081(扩展)/8080(独立运行)]
clip.html(clip-main.js)             ClipController → ClipService → FileStorageService
   │                                     │ AI: AiService(摘要/分析/标签/分类)
   ▼                                     │ 解析: LinkParseService / DocumentParseService
[Obsidian Web Clipper]                    │ 同步: SourceSyncService → ClipContent
   └→ sources/*.md → SourceSyncService    ▼
                               [本地 JSON 文件]  clip-storage/{分类}/{yyMMdd}.json
                               剪藏/待办/话题/知识/密码库 混存于同一根目录
```

## 三、设计问题（结构性）

### 3.1 存储层
- **JSON 文件 + 全量扫描**：无索引、无分页、无并发控制；查询全部 O(n)；写入 read-modify-write 不原子。这是"无数据库"约束下的必然结果，但锁与原子写是必须补齐的底线。
- **目录按「分类 + 日期」切分**（`{分类}/{yyMMdd}.json`），但分类由 AI 动态生成（真实数据已有 技术探索/读书笔记/公司事务/主密码库 等），目录会无限膨胀；单日单分类大文件风险（一天剪藏几十条时单文件膨胀）。
- **根目录数据卫生差**（实测）：嵌套 `clip-storage`、`clip-organized`、`tmp/`、`.tmp/`、`todoList_backup_20260718`、`vault.7z`、根级 `vaults.json/vault.enc`（旧版密码库遗留，迁移未跑）——历史配置漂移的沉淀。

### 3.2 端口与配置漂移（根因）
同一事实（后端地址）在 6+ 处各写各的：application.yml(8080)、模板(8081)、扩展×4 文件(8081)、前端×4 文件(8081)、Electron main.js(8081)、README(8081)、agent.md(8080)。**缺少单一事实来源**，是 B2 及"扩展连不上后端"类问题反复出现的根因。

### 3.3 字段语义过载
`content` 同时承载：用户原文 / link-ai 拼接文本（"来源链接: …\n\n正文"）/ doc-ai 解析文本 / Web Clipper 的 wiki-link；`bodyContent/selectedText/contextBefore/After/summary` 职责部分重叠。前端三态判定靠**字符串匹配**（"摘要生成失败"/"[文档解析失败]"），脆弱且不可扩展（B 级：结构化失败码更稳）。

### 3.4 AI 链路
同步调用、无重试、无状态机、无超时上限；`@Async processClipAsync` 存在但从未接入主流程（死代码 B15）；失败态用固定文案写入 summary/analysis，污染数据（后续无法区分"真失败"与"内容恰好如此"）。

### 3.5 三端重复实现
frontend/clip.html（内联 5474 行）+ browser-extension/clip.html（注释块 1460 行 + clip-main.js 1247 行）是同一产品的三份实现，行为已显著漂移（B16）。任何需求都要改三处，是"改了 A 忘改 B"类 bug 的温床。

## 五、需要决策的点（需你拍板）

| ID | 决策点 | 选项 | 我的倾向 |
