# 设计文档：截图小工具Snipaste对标增强

## 架构设计
- 截图覆盖层与贴图窗口均为本地受控 Electron 窗口，nodeIntegration 仅限本项目页面
- 标注绘制链路：anno 画布（已提交，物理像素）+ annoFloat 画布（绘制中预览）+ annoText 输入框（文本工具）
- 背景+标注合成：composeAnno 按选区物理坐标从背景源 drawImage + 叠加 anno，输出 PNG dataURL 回传主进程
- 坐标体系：选区/标注用 CSS/DIP 坐标（渲染交互），物理像素坐标 = CSS × sf（显示器缩放），裁剪/合成用物理像素

## 技术方案
- 标注工具扩展：drawShapeOn 新增 ellipse 分支；画笔/橡皮走连续路径点集（非两点直线）
- 橡皮擦：globalCompositeOperation='destination-out' 擦除 anno 像素，露出背景
- 撤销：undoStack 存 ImageData 快照（每成功提交入栈，限 50 层），Ctrl+Z putImageData 回滚
- 取色：初始化背景后就绪，背景源含原始像素；pickColorAt 取光标物理坐标 1x1 像素色，更新色点 + 剪贴板
- 贴图阴影：CSS box-shadow 双态（默认黑阴影 / body.selected 蓝色描边阴影），pointerdown 选中、blur 失焦
- 置顶切换：右键菜单 isPinned 状态 + 主进程 paste:set-top 调 setAlwaysOnTop（screen-saver 级别）

## 接口定义
- IPC（渲染 → 主进程）
  - `paste:set-top(pinned)` → `setAlwaysOnTop(Boolean(pinned), 'screen-saver')`
  - 沿用既有 `screenshot:confirm / screenshot:copy-last / paste:set-opacity / paste:zoom-at / paste:save`
- 主进程 → 渲染
  - 沿用既有 `paste:init / paste:text-ready / paste:rendered`

## 关键决策
- 不使用开源标注库（Fabric.js/Konva/tui-image-editor/Annotorious），原生增量约 150 行达成需求，规避重写与依赖风险
- 文本工具输入聚焦时 keydown 早退，避免输入字符被当成标注快捷键
- 取色后绕过 setColor（否则被调色板下标覆盖）
