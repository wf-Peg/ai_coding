## 四、用户场景

### 场景1：知识库日常使用
用户打开知识详情页 → 查看关联知识（显示标题，可点击跳转）→ 点击来源剪藏 → 内联弹窗展示剪藏内容 → 评论区浏览/发布评论 → 知识图谱查看关联关系

### 场景2：Wikilink 体验
用户在知识编辑器中用 `[[知识标题]]` 语法创建关联 → 保存后在详情页看到蓝色链接样式 → 点击链接跳转到对应知识详情页 → 不同主题下颜色适配

### 场景3：Wiki 知识库管理
用户通过 Web Clipper 剪藏网页到 Obsidian Vault → VaultWatchService 自动检测新文件 → BatchIngestService 批量 AI 处理生成实体/概念/综述页面 → 在 wiki.html 中查询/浏览

### 场景4：密码库首次使用
用户进入密码模块 → 锁屏页 → 点击初始化 → 输入密码库名称 → 自动生成/自定义 DES Key → 保存Key提示 → 点击创建 → 解锁进入主界面

### 场景5：密码库日常使用
用户解锁密码库 → 查看密码列表 → 搜索条目 → 编辑/删除条目 → 切换密码库 → 导入CSV密码 → 管理多密码库

### 场景6：浏览器插件导入密码
用户浏览网站 → 右键 → 密码管理 → 保存当前网站密码 → 弹窗自动填充网站信息 → 填写密码 → 保存到密码库

## 五、约束条件

1. **评论存储**：以 JSON 文件形式存储，不引入数据库
2. **CSV导入**：前端解析，后端只负责去重加密存储
3. **密码库加密**：DES/ECB/PKCS5Padding 加密，零知识设计
4. **Wiki 省 Token**：批量攒批、index优先查询、模型路由、增量更新、按需 lint
5. **向后兼容**：旧版单密码库文件自动迁移到新的多密码库结构
6. **跨域支持**：PasswordVaultController 添加 @CrossOrigin 支持浏览器插件
