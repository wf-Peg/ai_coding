# 设计文档：学习观测移入工具模块内置子工具入口

## 架构设计

- `index.html`：删除「学习」「观测」nav 按钮，保留 learningPlanView / dataObservabilityView 面板及 viewMap 与路由映射；新增 `navigateModuleTool` 消息处理，将工具模块发来的视图名切换对应顶层视图。
- `js/tools-core.js`：新增 `MODULE_TOOLS` 前端硬编码常量（system:true + module:true + viewName），在 loadTools 中前置插入工具列表；openTool 对 module 类型走 openModule，通过 `window.parent.postMessage({type:'navigateModuleTool', view})` 让主框架切换视图；卡片菜单对子工具显示「🚀 打开」。

## 技术方案

- 内置工具固化在进程前端常量中，不注册进 /api/tools，天然无删除/禁用/排序入口。
- 采用 postMessage 通知主框架切视图，而非嵌套 iframe 装载子页面。

## 接口定义

- 主框架新增消息：`{ type: 'navigateModuleTool', view: 'learning-plan' | 'data-observability' }`（由 tools-core.js 发出，index.html 接收）。

见 feature-points.json 的 knowledgePoints：父窗口通信保护、内置工具固化。
