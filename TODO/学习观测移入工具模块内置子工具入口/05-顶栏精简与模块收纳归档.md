# 归档：顶栏精简与模块收纳工具中心（v1.0.9）

## 变更目标

除「编辑、工作台、剪藏」三大核心模块外的其余模块，统一收纳到「工具」模块作为子工具卡片入口；工具内可配置各模块子工具**是否显示到标题栏菜单头 + 顺序**。AI干活 也作为工具卡片，且带前置检测激活（依赖 dsh，未装时先给安装说明与步骤，就绪后才允许激活）。

## 标题栏菜单头（改动后固定五项）

```
[编辑][工作台][剪藏][工具][设置]
```

顶栏主入口固定为五项。知识/Wiki/密码/AI干活 及此前的 学习计划/数据观测 全部收纳进「工具」模块作为子工具卡片，不再直接出现在顶栏；用户可在「工具设置」里把高频模块重新固定回顶栏并排序（写入 config.json `navHeaderTools`）。

## 落地内容

- **收纳为工具卡片**：`frontend/js/tools-core.js` 的 `MODULE_TOOLS` 扩展 `module-knowledge`（知识）、`module-wiki`（Wiki）、`module-vault`（密码库）、`module-agent`（AI干活），均为 `module:true, system:true`；连同此前的 `module-learning-plan`、`module-data-observability` 一并收纳。点击卡片经 `navigateModuleTool` 跳主框架顶层视图（规避嵌套 iframe 拦截）。
- **AI干活前置检测激活**：`openModuleAgent` 点击卡片先调 `api.checkDshInstall()`；就绪则装载面板；未装则在工具内弹安装说明浮层（npx 命令 + 复制 + 检测/重试），不直接跳转。
- **工具设置配置显隐/顺序**：`openMenu` 对 module 卡片新增「显示到顶栏/隐藏」与「前移/后移」，写主进程 config `navHeaderTools`，并经 postMessage 通知主框架 `applyHeaderNav` 动态重渲染顶栏。
- **顶栏动态渲染**：`frontend/index.html` 新增 `applyHeaderNav(config)`，读取 `navHeaderTools` 把被固定的模块入口（含 svg 图标）追加到「工具」前后；`handleAgentProgress` 新增 `need-install` 态。
- **dsh 自助安装联动**（详见 DSH 集成设计/验收）：不再内置离线 dsh 闭包、不再自动联网安装，未装提示 `npx @deepseek-ai/dsh@0.1.0-rc.7 web` 并检测解锁，显著减小安装体积。

## 验证要点

- 顶栏仅五项，无知识/Wiki/密码/AI干活独立按钮。
- 工具中心六张 module 卡片（知识/Wiki/密码/AI干活/学习计划/数据观测）均可跳转到对应顶层视图。
- AI干活卡片：3081 已有 dsh 直接装载；未装显示说明+命令+重试，无自动下载进程。
- 工具设置勾选「显示到顶栏/顺序」后，顶栏按配置出现/消失/排序。
