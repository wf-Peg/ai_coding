# 工作台规则与筛选 — 验收清单

## 一、规则引擎验收

### 1.1 表达式功能
- [ ] 新建/选中普通工作台 → 规则区顶部出现匹配模式控件和"＋ 添加分组"
- [ ] 添加 2 个分组，分别设组内 AND/OR，组间切 AND/OR → 内容列表按预期过滤
- [ ] 删除分组 → 组内规则一并删除，confirm 提示数量正确
- [ ] 空分组存在且不参与匹配
- [ ] 仅 manual/relation 成员旁路规则匹配

### 1.2 pd-builtin 默认规则
- [ ] 修改 pd-builtin 规则后重启后端 → 修改保留，未被覆盖
- [ ] 首次启动（工作台不存在）仍正常创建默认表达式
- [ ] 默认表达式内容：`(tag=product-dev OR category⊇product-dev) AND type∈(clip,todo)`

### 1.3 AND 模式
- [ ] 切换 AND 模式 → 内容必须匹配所有启用规则
- [ ] 手动/关系成员在 AND 模式下旁路规则
- [ ] 空规则时 AND 模式不产生规则命中
- [ ] 开关不回弹

## 二、规则UI验收

### 2.1 规则区
- [ ] 根关系控件（匹配模式 AND/OR segmented）在规则区顶部
- [ ] 分组卡片：组内 AND/OR 下拉可切换
- [ ] 分组卡片：删除分组按钮
- [ ] 添加规则可选定目标组
- [ ] 切到"全部" → 规则/排除 Tab 隐藏；切回真实工作台 → 恢复显示

### 2.2 规则弹窗
- [ ] 选择 type → 操作符只显示 equals/in → 值控件为下拉框
- [ ] 选择 tag → 操作符显示 equals/contains/in → 值控件为标签多选
- [ ] 选择 updatedAt → 操作符只显示 before/after → 值控件为时间选择器
- [ ] 选择 sourcePath → 操作符显示 equals/contains/in → 值控件为文本框
- [ ] 选择 workspace → 操作符显示 equals/in → 值控件为下拉框
- [ ] 时间选择器：点击日期弹出日历面板 → 选择日期 → 面板关闭
- [ ] 标签多选：输入文本 → 自动补全 → 点击/回车选择 → 胶囊显示 → 点击 ✕ 移除

## 三、规则字段扩展验收
