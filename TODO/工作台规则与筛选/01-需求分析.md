# 工作台规则与筛选 — 需求分析

## 一、需求背景

工作台系统是产品开发归档的核心模块，当前规则与筛选功能存在以下主要问题：

1. **规则表达能力不足**：仅支持全局 OR/AND，无法表达复杂组合条件（如 `(A OR B) AND (C OR D)`）
2. **规则字段维度缺少**：无法按内容所属工作台进行筛选，排除场景受限
3. **UI 交互粗糙**：规则弹窗字段-操作符不区分，时间选择器样式丑陋，标签字段无多选
4. **概览统计不准确**：显示的是工作台数量统计，而非内容统计
5. **默认工作台不可配置**：硬编码，无法通过 UI 设置默认工作台
6. **侧边栏不可排序**：工作台顺序固定，无法拖拽调整
7. **建议 Tab 功能弱**：卡片显示 UUID 无意义、无详情弹窗、无规则建议
8. **内容归属缺失**：在工作台内新增内容不自动关联，缺乏来源追踪
9. **全局筛选未打通**：各模块独立加载，不感知工作台筛选状态
10. **数据入库延迟**：feature-points.json 扫描入库后索引重建不及时，前端不可见

## 二、需求范围

### 2.1 规则引擎升级
- 两级 SQL 式分组表达式：组内 AND/OR × 组间 AND/OR
- 支持多分组添加/删除，组内规则管理
- 表达式持久化存储，原子写
- 向后兼容旧平铺规则（惰性迁移）

### 2.2 规则字段扩展
- 新增 `workspace` 字段，支持按内容归属工作台筛选
- 支持 `equals` / `in` 运算符
- 概览统计改为内容维度

### 2.3 规则 UI 优化
- 根关系控件（匹配模式 AND/OR）
- 字段-操作符智能映射
- Notion 风格时间选择器
- 标签多选输入
- 操作反馈优化

### 2.4 侧边栏改进
- 默认工作台改名"全部"
- 默认工作台可配置（isDefault + 绿点标识）
- 右键菜单、设置页按钮设置默认
- 拖拽排序

### 2.5 建议 Tab 优化
- 卡片显示标题而非 UUID
- 详情弹窗
- 规则建议自动生成
- Toast 反馈

### 2.6 内容自动归属
- 新增内容自动关联当前工作台
- 来源标记 manual_input
- 前端传递 workspaceId

### 2.7 全局筛选与数据入库
- 各模块 Controller 增加 workspaceId 筛选
- 跨页面状态同步（localStorage + postMessage）
- 索引重建时序修复
- TODO 目录定时扫描

## 四、技术约束

- **后端**：Java 21, Spring Boot 3.2, Jackson, 文件 JSON 存储, Maven 3.5.4
- **前端**：Vanilla HTML+JS, Electron, localStorage, postMessage
- **规则引擎**：文件索引驱动，非数据库
- **跨页面通信**：localStorage 事件 + postMessage 机制
