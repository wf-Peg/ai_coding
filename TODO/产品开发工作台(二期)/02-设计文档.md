# 产品开发工作台(二期) — 设计文档

## 1. 修复与对齐

### 1.1 feature-points.json 字段解析对齐

| 字段 | 文档定义（spec/SKILL/规范） | 代码实际读取 | 修复方案 |
|------|---------------------------|-------------|---------|
| clips[].contentFile | `contentFile` | `clipDef.get("file")` | 改为 `clipDef.get("contentFile")` |
| clips[].title | `title` | `clipDef.get("label")` | 改为 `clipDef.get("title")` |
| clips[].category | `category` | `clipDef.get("type")` | 改为 `clipDef.get("category")` |
| todos[].status | `status: "done"/"todo"` | `todoDef.get("completed")`（boolean） | 改为 `todoDef.get("status")`（string） |

### 1.2 requirement 对象解析

```java
// 当前（错误）
String requirement = (String) fp.getOrDefault("requirement", dirName);

// 修复后
Object reqObj = fp.get("requirement");
if (reqObj instanceof Map) {
    Map<String, Object> reqMap = (Map<String, Object>) reqObj;
    String title = (String) reqMap.getOrDefault("title", dirName);
    String summary = (String) reqMap.getOrDefault("summary", "");
    List<String> tags = (List<String>) reqMap.getOrDefault("tags", List.of());
    String phase = (String) reqMap.getOrDefault("phase", "planning");
}
```

### 1.5 增量导入逻辑

```
.imported 文件内容：{"importedAt": "2026-08-12T10:00:00Z", "importedIds": ["fp-001", "fp-002"]}
扫描流程：
1. 读取 .imported 文件，获取已导入的 featurePoint ID 集合
2. 遍历 featurePoints[]，跳过已导入的 ID
3. 导入新增的 featurePoint（clip/todo）
4. 更新 .imported 文件中的 importedIds 和 importedAt
```

## 4. 数据流

```
Agent 归档 → TODO/{需求名称}/feature-points.json
  → TodoScannerService.scanAndImport()（修复后）
    → 解析字段对齐
    → 增量导入（跳过已导入的 ID）
    → 使用存储路径派生 todoDir
  → ClipService.saveClip() / TodoService.saveTodo()
    → 使用 config.clipCategory 而非硬编码
  → ContentIndexService.rebuildFromStorage()
  → WorkspaceRuleService.resolve() 匹配 pd-builtin 规则
  → /api/workspace/{id}/resolve 返回筛选结果
  → 前端仪表盘/标签筛选/看板展示
```
