# 产品开发工作台(二期) — 需求分析

## 1. 背景

产品开发工作台 MVP 阶段已完成核心链路打通（Agent 归档 → TODO 目录 → 后端扫描落库 → 工作台规则展示），但 MVP 审阅评估（2026-08-10）发现了 2 个阻断级问题和 1 个流程级问题：

- **阻断级**：feature-points.json 字段解析与 spec 完全错位、双初始化器并存且行为不一致
- **流程级**：tasks.md/checklist.md 仍是旧 spec 内容，照单执行会重建已废弃的独立数据源

二期聚焦于修复这些遗留问题，并进行视图交互、仪表盘、标签筛选等增强。

## 3. 需求范围

### 3.1 P0（必须修复，否则无法进入开发）

1. **字段解析对齐** — TodoScannerService 解析字段与 spec/SKILL/规范三方定义错位
2. **requirement 对象解析** — 修复 ClassCastException（String 强转 → Object 解析）
3. **初始化器合并** — 两个初始化器合并为一个，统一工作台属性
4. **内置规则统一** — operator 四处不一致，需统一并与 matches() 验证
5. **tasks.md/checklist.md 重写** — 删除旧接口和废弃功能验收项

### 3.2 P1（功能增强与修复）

6. **全部概览仪表盘改造** — 从内容列表改为仪表盘风格
7. **视图交互统一** — product-dev-view 移入 .main-area，修复全屏覆盖问题
8. **标签筛选 + 埋点 + 提示** — 本地标签筛选、功能按钮埋点、悬浮提示
9. **文字标准化** — 产品开发工作区 → 产品概览
10. **最近活动修复** — 修复卡在加载中...的问题
11. **扫描路径配置化** — todo-dir 从 AppConfigService 派生
12. **增量导入逻辑** — 按 featurePoints[].id 增量导入
13. **历史代码清理** — 废弃旧 ProductDevController/Service/Model
14. **面包屑导航** — 全部概览 > 工作台名称

### 3.3 不包含的范围（二期不涉及）

- 知识图谱与甘特图（留待三期）
- Wiki 与工作台衔接设计
- 学习模块接入方案
- 独立数据存储方案

## 4. 用户故事

1. **作为用户**，我打开全部概览页面时，能看到仪表盘统计卡片和图表，而不是空的内容列表。
2. **作为用户**，我点击产品概览后，侧边栏仍然可见，我可以随时切换到其他工作台。
3. **作为用户**，我可以在产品概览中按标签筛选内容，筛选结果在所有子视图同步。
4. **作为用户**，我悬停在功能按钮上时，能看到说明文字。
5. **作为用户**，我在工作台详情页能看到面包屑导航，方便返回全部概览。
6. **作为开发者**，我按 spec 生成的 feature-points.json 能被正确解析，不会出现字段错位。
7. **作为开发者**，我看到的产品概览文字与侧边栏导航文案一致。
