## 二、人工走查验收（需在应用内点击确认）

> 以下项需要启动 Electron 应用后在画布模块实际交互确认。

### 默认可见性

- [ ] 首次打开画布：自动存在「我的画布」文档，视图默认「分栏」（左大纲 + 右画布）
- [ ] 视图切换「大纲 / 分栏 / 画布」三态可来回切，切后刷新页面仍保持上次选择
- [ ] 空文档时大纲面板显示空态提示，画布显示空态

### 大纲键盘范式（对标幕布）

- [ ] `Enter` 在当前行后插入同级新行，光标落到新行
- [ ] `Tab` 把当前行缩进为「上一兄弟的最后一个子节点」
- [ ] `Shift+Tab` 反缩进（已是根节点则无效果）
- [ ] `Alt+↑ / Alt+↓` 同级上下移动整行
- [ ] `Ctrl/Cmd + ↑ / ↓` 折叠 / 展开当前行
- [ ] 空行按 `Backspace` 与上一行合并；已是根节点空行则删除该行
- [ ] 粘贴外部富文本只保留纯文本，行结构不被破坏

### 双向联动

- [ ] 画布点击节点 → 大纲对应行高亮并滚动到可见位置
- [ ] 大纲点击某行 → 画布对应节点高亮放大
- [ ] 在大纲改文字 → 画布便签/引用卡文字同步更新（无需手动刷新）
- [ ] 在大纲新建节点 → 画布立即出现对应节点
- [ ] 在大纲删除某行 → 画布对应整棵子树的节点一并消失

### 一键按大纲排版

- [ ] 点击「按大纲排版」后，画布节点按大纲层级排成左→右分层树
- [ ] 排版后视口自动适配到内容范围（不跑到画布外）
- [ ] 无层级（全根节点）时按 `orderIndex` 竖排兜底，不报错

### 多画布文档

- [ ] 顶栏文档切换器可下拉列出全部文档（含节点数），切换后画布内容随之切换
- [ ] 新建文档 → 切到新空文档，画布为空、大纲为空
- [ ] 重命名文档 → 顶栏名称与文档列表同步更新
- [ ] 删除当前文档 → 有二次确认，确认后切到其他文档（不会出现无文档状态）
- [ ] 文档列表视图网格卡片展示正确，打开/重命名/删除可用

### 导出

- [ ] 大纲面板「导出 Markdown」得到层级正确的 Markdown 文件，文件名合理
- [ ] 画布导出 PNG 文件名带当前文档标题

### 规模与性能

- [ ] 节点数 > 300 时顶栏出现规模提示
- [ ] 节点数 > 500 时大纲自动折叠并给出提示，界面不明显卡顿
- [ ] 大纲连续快速输入时文本落库有 300ms 防抖，不产生逐字 IPC 风暴

### 兼容性回归

- [ ] 从旧版本升级（已有画布数据）后，旧节点全部出现在「我的画布」里，位置不乱
- [ ] 跨设备同步后（快照 v2）另一台设备能看到相同文档与层级
- [ ] 知识图谱模块与本批改动无相互影响（本次未改动该模块）
