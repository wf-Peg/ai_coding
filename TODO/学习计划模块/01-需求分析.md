# 学习计划模块 — 需求分析

## 一、产品定位

**核心功能**：用户输入学习主题、当前水平、目标和时间投入，AI 自动生成分阶段学习路线图，用户可跟踪每阶段的学习进度。

**参考来源**：[tech-shrimp/tech-shrimp-learning-roadmap](https://github.com/tech-shrimp/tech-shrimp-learning-roadmap) — 其核心产品理念和结构被借鉴，但完全重新设计为适配本系统风格的前后端一体化模块。

**关键升级**：集成 [Exa](https://exa.ai) 语义搜索引擎，为每个学习阶段搜索真实、高质量的学习资源（教程、文档、视频、论文），替代 AI 幻觉生成的虚假推荐，确保内容靠谱可用。

## 二、需求列表

### 2.1 基础功能需求

| 需求 ID | 需求名称 | 优先级 | 说明 |
|---------|---------|--------|------|
| R001 | 创建学习计划 | P0 | 用户输入主题/水平/目标/时间，AI生成分阶段路线图+Exa搜索资源 |
| R002 | 查看学习计划列表 | P0 | 卡片式列表，显示标题、阶段数、总进度、创建时间 |
| R003 | 查看学习计划详情 | P0 | 展示Mermaid路径图、阶段卡片（可折叠）、资源、作业 |
| R004 | 更新学习计划 | P1 | 编辑标题、进度、完成状态 |
| R005 | 删除学习计划 | P1 | 单条删除和批量删除 |
| R006 | 阶段进度跟踪 | P0 | 每阶段独立进度条+完成勾选 |
| R007 | 导出Markdown | P1 | 完整学习计划导出为Markdown文件 |
| R008 | 导出PDF | P1 | 学习计划导出为PDF（含打印对话框） |
| R009 | 打开存储目录 | P2 | 在文件管理器中打开学习计划存储目录 |

### 2.2 Exa搜索集成需求

| 需求 ID | 需求名称 | 优先级 | 说明 |
|---------|---------|--------|------|
| R101 | Exa语义搜索资源 | P0 | 为每个学习阶段搜索真实学习资源 |
| R102 | 双语搜索 | P1 | 中文+英文分别搜索，取综合结果 |
| R103 | 域名偏好过滤 | P2 | 中文站点(csdn/juejin/zhihu/bilibili)和英文站点(youtube/github/medium/arxiv) |
| R104 | 自动降级 | P0 | Exa不可用时自动降级为AI生成资源，标记source:ai |
| R105 | Exa配置管理 | P1 | 设置页面可配置Exa API Key和启用开关 |

| 需求 ID | 需求名称 | 优先级 | 说明 |
|---------|---------|--------|------|

| R205 | ∞时间显示 | P0 | 内置计划总周数和阶段周数显示∞ |

### 2.4 Bug修复需求

| 需求 ID | 需求名称 | 优先级 | 说明 |
|---------|---------|--------|------|
| R301 | API Key启动缓存不一致 | P0 | 启动时AppConfigService不同步到ModelConfigService导致AI调用失败 |
| R302 | Exa在Electron中不可用 | P0 | Electron模式下main.js不生成exa配置段 |
| R303 | PDF导出中文乱码 | P0 | document.write不保证UTF-8编码 |

### 2.5 边界约束

| 需求 ID | 需求名称 | 优先级 | 说明 |
|---------|---------|--------|------|
| R401 | 学习模块不进入工作台MVP | P0 | 本轮不打通产品开发工作台，不修改pd-builtin规则 |
| R402 | ContentRef索引已就绪 | P0 | 系统索引已含learning-plan类型，无需改动 |

## 三、用户角色

- **普通用户**：创建学习计划、跟踪进度、查看学习资源
- **系统**：内置学习计划自动初始化

## 四、功能范围

### 范围内
- 学习计划 CRUD
- AI 生成学习路径
- Exa 搜索学习资源
- 阶段进度跟踪
- 内置"产品功能学习"计划
- PDF 导出
- Markdown 导出

### 范围外（本轮MVP）
- 学习计划自动落库为剪藏/待办
- 学习计划进入 pd-builtin 工作台
- 独立学习工作台
- 与 Obsidian 打通
- 学习计划分享/协作
