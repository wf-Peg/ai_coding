# 学习计划模块 — 设计文档

## 一、数据模型设计

### 1.1 LearningPlan（学习计划）

```java
public class LearningPlan {
    private Long id;                    // 唯一标识
    private String title;               // 学习主题
    private String level;               // 当前水平：zero/beginner/intermediate
    private String goal;                // 学习目标：intro/project/job/portfolio
    private int hoursPerWeek;           // 每周投入小时数
    private String totalWeeks;          // 预计总周数（String，内置计划为"∞"）
    private List<Phase> phases;         // 学习阶段列表
    private String mermaidDiagram;      // Mermaid 可视化路径图
    private boolean builtin;            // 是否为内置计划
    private String category;            // 分类（内置计划为"product"）
    private List<String> tags;          // 标签
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}
```

### 1.2 Phase（阶段）

```java
public class Phase {
    private int phaseNumber;            // 阶段编号
    private String title;               // 阶段名称
    private String goal;                // 阶段目标
    private String estimatedWeeks;      // 预计周数（String，内置计划为"∞"）
    private String detailMarkdown;      // 详细说明Markdown（内置计划使用）
    private List<VideoResource> videos; // 推荐资源（Exa搜索填充）
    private List<QuizQuestion> knowledgeQuiz;  // 知识作业（AI生成）
    private List<PracticeTask> practiceTasks;  // 实战作业（AI生成）
    private int progress;               // 进度 0-100
    private boolean completed;          // 是否完成
}
```

### 1.3 子模型

```java
public class VideoResource {
    private String title;       // 资源标题
    private String url;         // 资源链接
    private String reason;      // 推荐理由
    private String source;      // 来源：exa / ai
    private String snippet;     // 内容摘要
}

public class QuizQuestion {
    private String type;        // "choice" | "essay"
    private String question;    // 题目
    private List<String> options; // 仅选择题
}

public class PracticeTask {
    private String description;          // 任务描述
    private int difficulty;              // 难度 1-3 星
    private String acceptanceCriteria;  // 验收标准
}
```

## 二、存储设计

- **存储位置**：`clip-storage/learning-plan/{yyyy-MM-dd}.json`
- **ID 分配**：`saveLearningPlan` 自动分配 ID（基于时间戳）
- **查询方式**：`getAllLearningPlans` 扫描全部日期文件，按创建时间倒序

## 三、后端API设计

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/learning-plan` | 创建学习计划（AI生成结构+Exa搜索资源） |
| GET | `/api/learning-plan` | 获取所有学习计划列表 |
| GET | `/api/learning-plan/{id}` | 获取单个学习计划详情 |
| PUT | `/api/learning-plan/{id}` | 更新学习计划 |
| DELETE | `/api/learning-plan/{id}` | 删除（内置计划返回400） |
| PUT | `/api/learning-plan/{id}/phase/{phaseNum}` | 更新阶段进度/完成状态 |
| POST | `/api/learning-plan/batch-delete` | 批量删除（跳过内置计划） |
| POST | `/api/learning-plan/open-folder` | 打开存储目录 |
| POST | `/api/learning-plan/{id}/export-pdf` | 导出PDF |

### 3.1 创建流程

```
前端提交: { title, level, goal, hoursPerWeek, totalWeeks }
    ↓
Step 1: AI 生成阶段结构（phases + mermaidDiagram）
    ↓
Step 2: Exa 为每个阶段搜索真实资源（双语搜索），填充 videos[]
    ↓
Step 3: 合并结果，保存到文件存储
    ↓
返回完整 LearningPlan
```

### 3.2 降级策略

Exa 不可用时（API key 未配置、网络异常、配额耗尽）自动降级为 AI 生成资源，标记 `source: "ai"`，前端展示"AI 推荐"标识。

## 四、Exa搜索集成设计

### 4.1 集成架构

```
用户输入学习主题
    ↓
LearningPlanService.generatePlan()
    ↓
┌─────────────────────────────────────┐
│  Step 1: AI 生成阶段结构             │
│  AiService.chat(prompt) → phases[]  │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  Step 2: Exa 搜索真实资源            │
│  for each phase:                    │
│    ExaSearchService.search()        │
│    → 填充 videos[]                  │
└─────────────────────────────────────┘
    ↓
完整的 LearningPlan（结构+真实资源）
```

### 4.2 搜索策略

每个阶段执行 **2 次搜索**（中文+英文）：

| 搜索方向 | 域名偏好 | 用途 |
|---------|---------|------|
| 中文教程 | csdn.net, juejin.cn, zhihu.com, bilibili.com | 中文视频/文章 |
| 英文资源 | youtube.com, github.com, medium.com, arxiv.org | 英文教程/论文 |
| 官方文档 | 主题相关官方域名 | 一手资料 |

### 4.3 配置管理

- Exa 配置从 `AppConfigService` 运行时读取（不依赖 `application.yml`）
- 设置页面可配置 Exa API Key 和启用开关
- `ExaSearchService` 每次搜索时读取最新配置

## 六、前端设计

### 6.1 页面结构

- **列表页（默认视图）**：标题+新建按钮+卡片列表+空状态引导
- **新建弹窗**：表单+加载动画+分步进度提示
- **详情页**：返回按钮+标题+Mermaid图+阶段卡片列表+进度跟踪

### 6.2 主题系统

- 使用 CSS 变量体系：`--background` / `--surface` / `--text` / `--primary` 等
- 支持 `data-theme="dark"` / `data-theme="notion"` / `data-theme="regular"`
- Mermaid 图表随主题切换（`mermaid.initialize({ theme: 'default' | 'dark' })`）

### 6.3 内置计划前端处理

- 列表卡片显示"内置"徽标
- 详情页不渲染删除按钮
- 批量模式隐藏内置计划的 checkbox
- 阶段卡片显示"查看说明"按钮 → Markdown弹窗
- 弹窗使用 `marked.parse()` 渲染（`marked.min.js` 已存在于 `frontend/libs/`）

## 八、Bug修复方案

### 8.1 API Key启动缓存不一致

**根因**：`AppConfigService.loadConfig()` 启动时不调用 `syncToModelConfig()`，导致 `ModelConfigService` 缓存与 `app-config.json` 不一致。

**修复**：在 `loadConfig()` 末尾、`return config` 前添加 `syncToModelConfig(config)` 调用。

### 8.2 Exa在Electron中不可用

**根因**：`main.js` 的 `generateApplicationYml()` 不生成 `exa` 配置段，`@Value("${exa.api-key:}")` 读到空字符串。

**修复**：ExaSearchService 改为从 AppConfigService 运行时读取配置，不再使用 `@Value` 注入；设置页面新增 Exa 配置区域。

### 8.3 PDF导出中文乱码

**根因**：`window.open` + `document.write(html)` 在 Electron 中不保证 UTF-8 编码。

**修复**：改用 `new Blob([html], {type: 'text/html;charset=utf-8'})` + `URL.createObjectURL(blob)` + 隐藏 iframe 加载打印。
