# 需求分析：全局体验与主题系统

## 原始需求

对齐 `docs/superpowers/plans/2026-08-23-cut-shelter-experience-plan.md` 实现 CutShelter 全局体验与主题系统：六套全局主题、统一页面骨架、柔和动效，保持 Electron/浏览器模式、业务状态与现有 iframe 架构兼容。

## 分析结论

- 以纯逻辑主题核心统一主题名称、动效偏好和消息契约；主页面负责持久化与广播，子页面负责应用令牌。
- 共享 UI CSS 负责基础控件和状态，页面迁移只处理布局与特殊组件，避免继续复制主题分支。
- **实现阶段确认**：删除 focus/calm/studio 三套实验主题，回归 regular/notion/dark 三主题，动效/UX/高级感统一作用于三主题。
