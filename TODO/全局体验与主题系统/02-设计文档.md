# 设计文档：全局体验与主题系统

## 架构设计

主页面（index.html）作为唯一事实来源：读取偏好 → 应用 `data-theme`/`data-motion` → 广播 `{ action: "themeChange", theme, motion }`；iframe 子页面在 `<head>` 内同步应用存储主题避免白屏，`listen` 接收广播并回执 `{ type: "themeReady" }`。

## 技术方案

- `frontend/js/theme-core.js`：纯逻辑（主题/动效规范化、system 外观解析、消息契约、持久化读取），Node/浏览器双端导出。
- `frontend/js/theme-bridge.js`：`init` / `apply` / `listen`。
- `frontend/styles/design-tokens.css`：三主题令牌 + 组件语义令牌 + 旧版别名。
- `frontend/styles/ui-common.css`：共享控件与动效令牌消费 + `[data-motion="reduced"]` + `prefers-reduced-motion`。
- 全部模块入口页接入共享样式与主题桥接。

## 关键决策

- 三主题收敛：删除 focus/calm/studio，回归 regular/notion/dark。
- 设置模块双栏布局：sticky 分组侧栏导航 + 分组主内容区。
