# 需求分析：编辑器功能增强

## 原始需求

对编辑器模块进行全面功能增强，涵盖以下九大子需求：

### 1. 多标签（Multi-Tab）功能
- 为编辑器模块增加类似 Notepad++ 的多画布/多标签功能
- 双击标签栏空白区域或 Ctrl+T 新建标签
- 标签间可切换编辑，各标签的编辑状态完全隔离
- 支持标签关闭、未保存确认、快捷键切换

### 2. 右键菜单扩展 + 标签拖拽排序
- 编辑器画布右键菜单中增加"智能入库"和"AI 识别导入密码"两个操作项
- 为标签栏增加拖拽排序能力（类似 Notepad 的标签拖拽重排）

### 3. 右键打开目录 + 路径双击 + 历史回退 + 快捷键调整
- 文件树/最近文件/标签栏右键菜单增加"打开文件所在目录"
- 文件名下方路径栏支持双击打开目录
- 历史面板支持点击条目回退到指定状态，默认保留 200 条
- 全局唤醒快捷键从 Ctrl+Shift+Z 改为 Alt+X

### 4. 常用文件收藏功能
- 右下角状态栏新增收藏按钮，点击后左侧滑出收藏面板
- 用户可手动收藏/取消收藏文件，支持拖拽排序
- 不限数量上限，数据通过 localStorage 持久化

### 5. 面板动画与视觉美化
- 为五个面板（机器人/文件/最近/历史/概览）增加推拉式抽屉动画
- 进行视觉升级：按钮激活态、列表项 hover 动效、面板滑入动画
- 无障碍降级（prefers-reduced-motion）

### 6. 选中逻辑优化
- 优化编辑器选中行为，使空行在多行选区中也能正确显示选中高亮
- 借鉴 VS Code / Monaco 的实现方式

### 7. 翻译与词典增强
- 离线词典支持中英文双向翻译
- 在线翻译改为 AI 对话方式
- 用户自定义词典管理（分区管理：自定义映射 + 词典库）
- 编辑器输入时自动匹配词典内容提供候选词补全

### 8. 启动加载遮罩
- 先显示窗口和加载遮罩，后端异步启动
- 通过 IPC 推送进度，就绪后自动隐藏遮罩
- 失败时显示错误信息和重试按钮

## 分析结论

所有子需求均围绕编辑器模块的交互体验和功能完整性展开，涵盖以下维度：

| 维度 | 子需求 |
|------|--------|
| 编辑核心能力 | 多标签、选中优化、历史回退 |
| 快捷操作 | 右键菜单扩展、快捷键调整、路径栏双击 |
| 文件管理 | 收藏文件、右键打开目录、标签拖拽排序 |
| 翻译/词典 | 中英双向离线翻译、AI 在线翻译、自定义词典、自动补全 |
| 视觉/交互 | 面板动画美化、按钮激活态 |
| 启动体验 | 加载遮罩、异步启动 |

所有改动均为前端或全栈（Electron IPC），不涉及后端核心业务逻辑变更。已存在的后端 API（智能入库、密码导入）可直接复用。
