# 反链（双链 wikilink）功能使用说明

> 编辑器模块内置 Obsidian 风格的双链 / 反链能力，可在编辑器内引用知识库文件、剪藏与知识条目，并查看反向引用。

---

## 一、前提条件

- **桌面模式**：反链扫描、双链跳转需通过 Electron 桌面端使用；纯浏览器访问时相关功能不可用（会提示）。
- **知识库索引**：补全候选取自知识库根目录下的 `.md` 文件（当前为 `剪藏收集\clip-organized`，共 82 个文件）。启动时自动构建索引。

---

## 二、双链补全（输入 `[[` 出候选）

1. 在编辑区输入 `[[`，会**立即弹出候选列表**，列出知识库中所有可引用的文件名（basename）。
2. 继续输入文件名的一部分（如 `[[知识管理`）可实时过滤候选。
3. 用 **↑/↓** 选择候选，**Enter/Tab** 或点击选中，即可插入形如 `[[文件名]]` 的双链。
4. 候选列表右侧显示文件相对路径，便于区分同名文件。

> 说明：补全依赖知识库索引。若索引为空（如改了存储路径尚未重建），候选列表为空；此时先保存一个文件或重启编辑器触发重新索引。

---

## 三、Markdown 预览中的双链

- 在 **Markdown 预览**（Ctrl+Shift+M）中，`[[文件名]]` 会被渲染为可点击链接。
- 链接显示为目标文件名；若目标不存在（未命中索引），链接会以"缺失"样式标红/虚化提示。

---

## 四、双链跳转

- 点击预览中的 wikilink 链接，会在**新标签页**打开目标文件。
- 目标可为：知识库中的 `.md` 文件、剪藏、或知识条目。
- 若存在**多个同名 basename**，会提示"存在多个同名目标，请使用相对路径消除歧义"，此时需用 `[[相对路径/文件名]]` 形式精确引用。

---

## 五、反链面板（反向引用）

- 状态栏点 **🔗 反链** 按钮，或按 **Ctrl+Shift+B**，在左侧打开反链面板。
- 面板展示**当前文档被哪些文件引用**（这些文件中包含 `[[当前文档名]]`）。
- 每条反链显示：引用文件名、相对路径、以及命中的原文行（最多 3 行）。
- **点击某条反链 → 在新标签页打开引用它的源文件**。
- 面板与文件树/历史/最近/收藏抽屉互斥，打开反链会自动关闭其它左抽屉。

---

## 六、存入知识库

- 反链面板顶部的 **「存入知识库」** 按钮，将当前编辑器内容保存为 `知识库根目录/notes/{当前文档名}.md`。
- 保存成功后自动重建链接索引、刷新预览中的链接命中状态。
- 这样当前文档也能被知识库索引到，从而被其它文件通过双链引用。

---

## 七、常用快捷键汇总

| 快捷键 | 功能 |
| --- | --- |
| `[[` + 文件名 | 双链补全 |
| Ctrl+Shift+B | 开关反链面板 |
| Ctrl+Shift+M | 开关 Markdown 预览 |
| 点击 wikilink | 新标签页跳转目标 |
| 点击反链接钮 | 打开引用源文件 |

---

## 八、典型使用流程

1. 打开一个 `.md` 文件（或新建）。
2. 输入 `[[` 选择候选，插入双链引用其它知识文件。
3. 按 Ctrl+Shift+M 预览，确认双链渲染为可点击链接。
4. 按 Ctrl+Shift+B 查看哪些文件引用了当前文档。
5. 需要让当前文档被索引 → 点「存入知识库」。
