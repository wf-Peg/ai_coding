# L2 工作台规则筛选与排除覆盖验收清单

- [x] `WorkspaceRule` 包含 id、workspaceId、field、operator、value、enabled、createdAt、updatedAt。
- [x] `WorkspaceExclusion` 包含 workspaceId、contentId、reason、createdAt、updatedAt。
- [x] 规则和排除分别落盘到 `workspace-rules.json`、`workspace-exclusions.json`。
- [x] 仅接受规划规定的字段和操作符，非法数据被拒绝。
- [x] 支持规则保存、更新、启用/禁用、读取和删除。
- [x] 支持排除记录保存、幂等、移除和查询。
- [x] 多条启用规则按并集计算，结果按 ContentRef.id 去重。
- [x] 禁用规则不参与命中计算。
- [x] 支持 equals、contains、in、before、after 匹配。
- [x] 规则命中不会写入 WorkspaceMembership。
- [x] 手动成员和关系带入可以参与最终合并结果。

- [x] 排除记录优先于规则命中、手动加入和关系带入。
- [x] 返回规则命中、手动加入、关系带入、排除和最终可见数量。
- [x] 删除工作台同步删除规则、排除和成员关系，不影响其他工作台。
- [x] 缺失文件按空集合处理，损坏 JSON 明确失败。
- [x] L2 定向测试、`WorkspaceIndexService.resolveWorkspace` 集成测试、后端全量测试和编译通过。
- [x] 解析统一读取持久化手动成员，合并关系带入，并保持成员关系文件不被解析过程改写。
