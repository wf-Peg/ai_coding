# L2 工作台页面交互规格

## Why
L2 后端已提供规则筛选、排除管理和解析结果 API，但尚未通过前端页面呈现给用户。需要将 workspace.html 从只读概览页升级为可交互的工作台管理页面，让用户创建/选择工作台、管理规则、排除内容和查看解析结果。

## What Changes
- 扩展 `workspace.html` 为两级视图结构。
- 左侧窄边栏：工作台列表 + "全部概览"入口 + 新建工作台按钮。
- 右侧主区域分为：
  - 概览视图：保留原有内容概览和项目摘要。
  - 工作台详情视图：内容列表、来源统计、规则管理、排除管理。

## API 调用

页面通过 fetch 调用以下后端端点：

| 用途 | 方法 | 路径 |
|------|------|------|
| 概览 | GET | `/api/workspace/overview` |
| 工作台列表 | GET | `/api/workspace/list` |
| 解析结果 | GET | `/api/workspace/{id}/resolution` |
| 规则列表 | GET | `/api/workspace/{id}/rules` |
| 创建规则 | POST | `/api/workspace/{id}/rules` |
| 更新规则 | PUT | `/api/workspace/{id}/rules/{ruleId}` |
| 删除规则 | DELETE | `/api/workspace/{id}/rules/{ruleId}` |
| 排除列表 | GET | `/api/workspace/{id}/exclusions` |
| 创建排除 | POST | `/api/workspace/{id}/exclusions` |
| 删除排除 | DELETE | `/api/workspace/{id}/exclusions/{contentId}` |
| 工作台列表 | GET | `/api/workspace/list` |

## 交互流程

### 概览视图（默认）
- 加载后显示全部内容概览，与当前行为一致。
- 左侧边栏"全部概览"高亮。
- 显示工作台列表和项目摘要。

### 工作台详情视图
- 点击左侧工作台名称，切换到详情视图。
- 顶部显示工作台名称、类型和来源统计（规则命中/手动/关系/排除/可见）。
- 默认显示"内容"选项卡，列出 resolution 返回的可见内容。
- 内容项标记来源（规则命中/手动加入/关系带入）。
- 每项内容有"排除"按钮，点击后调用排除 API 并刷新列表。
- 规则选项卡：列出规则、新增、编辑、删除、启用/禁用。
- 排除选项卡：列出已排除记录、恢复排除。

### 新建工作台
- 点击"+"按钮弹出简单表单（名称、描述、类型、颜色）。
- 创建后自动选中并切换到详情视图。

### 状态处理
- 加载态：骨架屏/旋转指示器。
- 空数据：友好提示。
- 错误：带重试按钮的错误消息。
- 后端不可用：错误提示，不阻塞概览加载。

## 样式约束
- 复用 `design-tokens.css` 主题令牌。
- 响应 `postMessage` 的 `themeChange` 事件。
- 适配深色模式和窄屏（<820px 侧边栏折叠）。

## 数据安全
- 内容列表不显示 `content` 正文，只显示元数据。
- 所有用户输入通过 `escapeHtml` 转义。
- 不存储 token 或敏感信息在前端 localStorage。
