# L1 工作台本地持久化验收清单

> 状态：已完成（2026-08-04）

- [x] `Workspace` 模型包含 id、name、type、description、color、status、createdAt、updatedAt。
- [x] `WorkspaceMembership` 模型只保存工作台与内容引用关系，不保存正文。
- [x] 数据分别落盘到 `workspace.json` 和 `workspace-memberships.json`。
- [x] 工作台保存后可以读取，更新同 id 不产生重复记录。
- [x] 同一工作台重复加入同一内容保持幂等。
- [x] 支持按工作台读取成员和移除成员。
- [x] 删除工作台同步删除其成员关系，不影响其他工作台。
- [x] 删除工作台不修改 ContentRef、原始业务 JSON 和旧 Project 文件。
- [x] 非法 id、名称、类型、状态和 contentId 被拒绝。
- [x] 缺失文件按空集合处理，损坏 JSON 明确失败。
- [x] 定向测试和后端全量测试通过。
