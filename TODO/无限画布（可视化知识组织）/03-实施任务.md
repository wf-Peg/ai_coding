# 无限画布（可视化知识组织）— 实施任务清单

> 对应设计文档：`00-需求与设计说明.md`。
> 本文把设计拆成可排期、可独立上线、可验收的实施任务。
> 本次开发范围：**阶段一**。阶段二~四为后续计划，先列清任务便于排期。

---

## 阶段一（本次开发）：位置持久化 + 无限平移缩放

先把「力导向图」变成「画布」的最本质能力：**节点拖到哪就停在哪，位置记住，缩放范围放宽**。

| 编号 | 任务 | 改动文件 | 说明 |
|---|---|---|---|
| 1.1 | 数据层：新增画布布局表（schema v3） | `electron/sqlite/init.js` | 新增 `canvas_layout(node_id PK, x, y, updated_at)`；与语义 `relation` 表分离 |
| 1.2 | 数据层：布局读写模块 | `electron/sqlite/canvas-layout.js`（新建） | `positions()` 读、`savePositions()` upsert、`clearPositions()` 清空 |
| 1.3 | IPC：图数据合并位置 + 保存布局接口 | `electron/main.js` | `local-index:graph` 节点合并 x/y；新增 `local-index:layout:save` |
| 1.4 | 桥接：暴露保存布局 API | `electron/preload.js` | `localIndex.saveLayout({positions})` |
| 1.5 | 前端：画布行为升级 | `frontend/knowledge-graph.js` | 读持久化位置并 pin 住；拖动松手不弹回；放宽缩放范围；位置防抖回写 |
| 1.6 | 前端提示文案 | `frontend/knowledge-graph.html` | `nav-hint` 补充「位置自动保存」 |
| 1.7 | 单测：布局层读写 | `electron/sqlite/canvas-layout.test.js`（新建） | 保存/读取/覆盖/无效条目过滤 |

**阶段一验收**：拖动节点松手后位置不弹回；刷新/重启后位置还在；画布可无限平移、缩放 ≥ 10 倍。

---

## 阶段二：新建节点 + 手动连线

让用户真正能「自己画」，而不是只能看 AI 关系。

| 编号 | 任务 | 说明 |
|---|---|---|
| 2.1 | 画布右键菜单 | 新建便签/链接/图片/引用已有节点 |
| 2.2 | 手动连线（拖拽拉线） | 复用 D3 drag；新关系存 `canvas_layout` 层（手动关系），不污染语义 `relation` |
| 2.3 | 新建节点渲染 | 便签=文本框、链接=URL 卡片、图片=缩略图节点 |
| 2.4 | 便签/链接内容编辑 | 双击节点编辑文字 |

**阶段二验收**：能新建便签/链接/图片节点、能手动连线，刷新后仍存在。

---

## 阶段三：分组 / 框选 + 右键菜单 + 网格吸附

补齐白板的操作体验。

| 编号 | 任务 | 说明 |
|---|---|---|
| 3.1 | 框选 / 多选 / 批量移动 | 拖出选区框住多节点 |
| 3.2 | 分组（frame） | 圈成一堆命名，拖框节点跟随 |
| 3.3 | 网格吸附 | 拖动对齐到网格（可开关） |
| 3.4 | 小地图缩略图 | 大画布快速定位（可选） |

**阶段三验收**：多节点可框选成组、命名、整体拖动。

---

## 阶段四：AI 能力（差异化，最像 NoteGen）

| 编号 | 任务 | 说明 |
|---|---|---|
| 4.1 | AI 自动布局 | 一键把乱节点排成有序分层/环形 |
| 4.2 | AI 生成 Mermaid 流程图 | 选中节点 → 生成 Mermaid 导入画布（复用 `frontend/libs/mermaid.min.js`） |
| 4.3 | AI 增补节点 | 基于选中内容联想「还缺什么节点/关系」 |

**阶段四验收**：一键 AI 布局后节点有序；选中节点可生成 Mermaid 流程图。

---

## 全局约束（所有阶段都必须遵守）

1. **守「文件为真、库为缓存」**：画布布局是视觉缓存（存 SQLite `canvas_layout`），重建/丢失最多回退自动布局，语义关系不能丢。
2. **手动关系 ≠ AI 关系**：手动连线进布局层，不写语义 `relation` 表，避免 `relation-builder` 全量 `DELETE` 时被误删。
3. 原地升级 `knowledge-graph` 页面，不另开入口，避免入口分裂。
