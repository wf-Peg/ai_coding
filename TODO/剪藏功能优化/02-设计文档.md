### 1.2 数据流

```
[Web Clipper同步]
     ↓ source.md
SourceSyncService
     ├→ content = [[sources/文件名|标题]] (wiki-link)
     ├→ bodyContent = 正文(不含frontmatter)
     └→ sourceFilePath, sourceUrl

[剪藏列表加载]
     ↓ GET /api/clip/list

     ├→ 过滤 todolist 目录
     └→ 返回 clip 列表

[剪藏详情展开]
     ↓

     ├→ ready → 渲染 Markdown 分析内容
     ├→ failed → 失败态 + "重新生成分析"按钮
     └→ empty → 中性空态 + "生成分析"按钮

[点击源文件路径]
     ↓
openClipInEditorNewTab(clipId, sourceFilePath)
     ↓ postMessage
index.html 接收
     ├→ 有 sourceFilePath → 拼接路径 + openFileByPath → 编辑器打开文件
     └→ 无 sourceFilePath → 回退 clipId 逻辑

[整理/周报后自动Git]
     ↓
ContentOrganizeService / WeeklyReportService
     ↓
GitService.executeGitOperations()
     ├→ git pull
     ├→ git add .
     ├→ git commit
     └→ git push
```

## 二、核心设计决策

### 2.1 三态模型（ready/failed/empty）

| 状态 | 判定条件 | 前端展示 | 用户操作 |
|------|----------|----------|----------|
| ready | analysis 非空且非失败 | 渲染 Markdown 分析内容 | 发散性总结按钮 |
| failed | summary 含"摘要生成失败"/"[文档解析失败]"或 analysis 含"分析生成失败" | ❌ AI 分析失败 + 失败说明 | 🔄 重新生成分析 |
| empty | 无分析且无失败标记 | 暂无 AI 分析内容 + 说明 | ✨ 生成分析 |

**判定函数**：
```javascript
function getAnalysisState(clip) {
    const analysis = (clip.analysis || '').trim();
    const summary = (clip.summary || '');
    const failed = summary.indexOf('摘要生成失败') !== -1
        || summary.indexOf('[文档解析失败]') !== -1
        || analysis.indexOf('分析生成失败') !== -1;
    if (analysis && !failed) return 'ready';
    return failed ? 'failed' : 'empty';
}
```

### 2.2 事件委托方案

由于 createClipItem/quickOrganizeClip/generateDivergentSummary 等函数位于 DOMContentLoaded 闭包内，非全局函数，内联 onclick 不可用。新按钮采用事件委托：

```javascript
document.addEventListener('click', function(e) {
    const btn = e.target.closest('.generate-analysis-btn');
    if (btn) {
        quickOrganizeClip(parseInt(btn.dataset.clipId));
    }
});
```

### 2.3 Web Clipper 双字段存储

| 字段 | 内容 | 用途 |
|------|------|------|
| content | `[[sources/文件名|标题]]` | Obsidian 集成 wiki-link 引用 |
| bodyContent | 正文（不含 frontmatter） | 前端展示 + AI 分析 |

### 2.4 源文件路径打开流程

```
clip.html → postMessage({ type: 'openClipInNewTab', clipId, sourceFilePath })
  → index.html 接收
    → 有 sourceFilePath:
      window.electronAPI.getConfig() → storagePath
      fullPath = storagePath + '/obsidian-vault/' + sourceFilePath
      window.electronAPI.openFileByPath(fullPath)
      → sendToEditor({ type: 'openFileData', fileData })
    → 无 sourceFilePath:
      → 回退到 clipId 从 API 获取数据
```

### 2.5 fetchClips 展开状态恢复

```javascript
// 清空前记录展开ID
const expandedIds = new Set();
document.querySelectorAll('.clip-detail.expanded').forEach(detail => {
    const clipItem = detail.closest('.clip-item');
    const idEl = clipItem?.querySelector('[data-clip-id]');
    if (idEl) expandedIds.add(idEl.dataset.clipId);
});

// 重建后恢复展开状态
expandedIds.forEach(id => {
    const detail = document.querySelector(`.clip-detail[data-clip-id="${id}"]`);
    if (detail) detail.classList.add('expanded');
});
```

## 四、边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 历史数据（content 是 wiki-link，无 bodyContent） | 前端回退展示 clip.content 作为纯文本 |
| bodyContent 为空 | 回退到 summary（来自 frontmatter description） |
| sourceUrl 为空 | 不显示 URL 链接 |
| sourceFilePath 为空 | 不显示文件路径，回退到 clipId 逻辑 |
| 非 Web Clipper 同步剪藏 | bodyContent 为 null，clip.content 作为正文展示 |
| 正文为空 extractBodyContent | 回退到 summary，再回退到空字符串 |
| 没有 frontmatter | extractBodyContent 返回全部内容 |
| Git 操作失败 | 捕获异常仅打日志，不影响主流程 |
| 图片删除 | 同时删除正文中的 Markdown 引用 |
| 内容超长 | CSS 多行省略号截断 + 展开/收起按钮 |
