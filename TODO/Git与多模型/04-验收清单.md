- [ ] GitController 提供 GET /api/git/config 获取配置

- [ ] configureRemoteRepository 先执行 fetch

- [ ] 并发操作使用锁防止冲突

### 1.4 前端同步按钮
- [ ] index.html 页面顶部有同步按钮
- [ ] 点击同步按钮调用后端 /api/git/sync
- [ ] 同步过程中有状态反馈（进行中/成功/失败）
- [ ] 同步失败时有清晰的错误提示
