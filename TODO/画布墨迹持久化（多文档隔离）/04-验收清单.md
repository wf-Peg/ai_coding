## 二、功能闭环走查

### 基本持久化

- [x] 画一笔后刷新页面，墨迹仍在，且位置、颜色、粗细、透明度与刷新前一致　（实测：画 n=9 点笔迹 → 刷新 → `ink-layer` 还原 1 条，颜色 #222/粗细/点位一致）
- [ ] 画一笔后完全重启应用，墨迹仍在　⚠️ 需真机（浏览器刷新已等价覆盖 loadInk 路径）
- [ ] 画笔「细 / 粗」与荧光笔（宽 + 半透明）三种样式各自落库后还原正确　⚠️ 需真机（落库字段 width/opacity 已实测正确）
- [x] 橡皮擦擦掉一笔后刷新：被擦的笔不再出现，其余笔完整保留　（实测：擦后 `inkPaths:0`、DB 仅剩他文档墨迹，隔离完好）
- [x] 撤销（Ctrl+Z）后刷新：被撤销的笔不再出现　（实测：画 2 笔 → 撤销 1 笔 → `inkPaths:1`、DB 剩 1 条）
- [x] 清空画布后刷新：墨迹为空，且库中该文档墨迹已清　（实测：点清空 → `inkPaths:0`、DB 该文档墨迹清空）

### 多文档隔离

- [x] 文档 A 画一笔 → 切到文档 B（无墨迹）→ 切回 A：A 的墨迹完好　（实测：切 B 只显 B 的 ink、切回 A 还原）
- [x] 文档 A、B 各画不同笔迹 → 来回切换互不串味　（实测：DB 按 docId 隔离，页面 ink 渲染随文档切换）
- [x] 删除含墨迹的文档：该文档墨迹随之清理；随后拉取后端快照，**不出现幽灵墨迹**　（实测：删空文档后其墨迹消失；cearAll/wipe 由单测覆盖）
- [x] 新建文档：墨迹为空，不与任何既有文档共享　（实测：新建「未命名画布」墨迹为空可独立作画）
