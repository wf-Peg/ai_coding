## 决策点（已批准结论）

| ID | 决策 | 结论 |
|---|---|---|
| D-A | 上传时机：粘贴即传（非随提交） | 即传 |
| D-B | content 引用：相对路径 + 渲染重写 | 相对路径 |
| D-C | 压缩：客户端 canvas 为主 + 后端 ImageIO 缩略图 | 客户端为主 |
| D-D | 旧数据：一次性迁移接口 | 迁移接口 |
| D-E | 图片目录：`clip-storage/media/`（与剪藏同根） | 同根 |
| D-F | doc-ai 附件：独立 `documents/` | 独立 |
| D-G | 列表缩略图：256px | 做 |
| D-H | 端点/存储命名：通用 media 层 `/api/media/*` | 通用 |
| D-I | web 剪藏远程图片下载 | 本期不做（后续增强） |
| D-J | 列表缩略图（原 D-G） | 做 |
| D-K | XSS 消毒：DOMParser 白名单，不引依赖 | 自写白名单 |
| D-L | 扩展 helper：复制到 `browser-extension/libs/` 并标注同步 | 复制 |
