## T-001：待办事项与剪藏功能分离

### 子任务

1. **创建 todo.html 文件**
   - 基于 timeline-todo.html 的设计
   - 实现完整的待办事项时间线功能
   - 包含优先级、筛选、编辑等功能
   - 独立的样式和脚本
   - 集成后端 API 调用

2. **创建 clip.html 文件**
   - 从 index.html 中提取剪藏相关代码
   - 保留所有剪藏功能和样式
   - 独立的样式和脚本
   - 确保 API 调用正常

3. **修改 index.html 为导航页面**
   - 创建简单的导航界面
   - 添加两个功能的入口链接
   - 响应式设计，在小屏幕上自适应

### 依赖关系
- 无

### 验收标准
- [ ] todo.html 独立打开，待办事项功能完整
- [ ] clip.html 独立打开，剪藏功能完整
- [ ] index.html 导航页面提供清晰的入口链接
- [ ] 两个页面布局互不影响
- [ ] API 调用路径正确

## T-002：待办事项存储实现

### 子任务

1. **创建 TodoContent 模型类**
   - 包含 id、title、priority、deadline、completed、createdAt、category 字段
   - 提供构造函数和 getter/setter 方法

2. **FileStorageService 扩展**
   - 添加 saveTodo 方法
   - 添加 getAllTodos 方法
   - 添加 getTodosByDate 方法
   - 添加 deleteTodo 方法

3. **创建 TodoService 服务类**
   - 实现待办事项的业务逻辑
   - 调用 FileStorageService 进行存储操作

4. **创建 TodoController 控制器类**
   - 实现 REST API 接口
   - 处理前端的请求

5. **修改前端代码**
   - 更新 todo.html 中的 API 调用地址
   - 实现待办事项的添加、编辑、删除功能
   - 实现待办事项的状态更新和过滤功能

### 依赖关系
- T-001 完成后进行（需要 todo.html 作为基础）

### 验收标准
- [ ] 待办事项数据真实存储到 `./clip-storage/todolist/{date}.json`
- [ ] 整理结果存储到 `./clip-organized/todolist/{date}.md`
- [ ] 前端可以正常添加、编辑、删除待办事项
- [ ] 前端可以正常更新待办事项的完成状态
- [ ] 前端可以按优先级/分类/日期过滤待办事项
- [ ] 与现有剪藏功能兼容

## T-003：待办事项时间线UI/UX优化

### 子任务

1. **HTML 结构修改**
   - 添加浮动'+'号按钮，隐藏待办表单
   - 创建添加待办模态框（todo-modal）
   - 创建待办详情模态框（todo-detail-modal）
   - 为每个待办项添加'...'详情按钮

2. **CSS 样式优化**
   - 模态框样式（现代化设计、平滑动画、响应式布局）
   - '+'号按钮样式（浮动设计、悬停效果）
   - 时间线滚动优化（垂直滚动、禁用横向滚动）
   - 详情按钮样式（右下角'...'按钮、悬停提示）

3. **JavaScript 功能优化**
   - 实现 openTodoModal/closeTodoModal/handleTodoSubmit 模态框控制函数
   - 实现 openTodoDetailModal/closeTodoDetailModal 详情函数
   - 实现滚动优化（确保垂直滚动、禁用横向滚动）
   - 实现键盘快捷键（ESC关闭）和点击外部关闭

### 依赖关系
- T-001 完成后进行（需要 todo.html 作为基础）

### 验收标准
- [ ] 待办表单默认隐藏，'+'号按钮浮动显示
- [ ] 点击'+'号弹出添加待办模态框
- [ ] 每个待办项有'...'详情按钮
- [ ] 时间线支持垂直滚动，无横向滚动条
