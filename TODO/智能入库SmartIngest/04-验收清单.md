# 智能入库SmartIngest - 验收清单

## 一、功能验收

### 1.1 双AI路径架构
- [ ] Agent 路径：用户粘贴文本 → Skill 意图识别 → curl 调用后端接口 → 入库成功
- [ ] 代码路径：POST /api/ingest {text} → 后端 AI 识别 → 路由入库 → 返回正确响应
- [ ] 两条路径对同一文本的意图识别结果一致
- [ ] SKILL.md 顶部有同步提醒注释

### 1.2 意图识别与字段提取
- [ ] 输入"明天下午3点前完成报告，高优" → 识别为 todo
- [ ] 输入"TCP 三次握手过程详解..." → 识别为 clip
- [ ] 输入"推荐 Obsidian 这个笔记工具" → 识别为 topic
- [ ] 字段提取按意图映射到正确的 API 参数
- [ ] LLM 返回空字符串时 → getString() 正确降级为 defaultValue
- [ ] 意图模糊时 → 降级为 clip store-only
- [ ] 字段提取失败时 → 原文前 30 字作 title

### 1.3 默认流程与例外流程
- [ ] 无关键词时走默认流程：Agent 自主识别意图+提取字段+调接口
- [ ] 用户说"智能剪藏/智能入库" → 走例外流程 → POST /api/ingest
- [ ] 用户说"添加剪藏/剪藏入库" → 走例外流程 → POST /api/clip/add
- [ ] 用户说"添加待办/创建待办" → 走例外流程 → POST /api/todo/add
- [ ] 用户说"剪藏到话题/添加话题" → 走例外流程 → POST /api/topic
- [ ] 项目级和全局级 SKILL.md SHA-256 一致
- [ ] 全局级 SKILL.md 无 BOM

### 1.4 后端统一入库接口 IngestController

- [ ] intent=todo → 调用 TodoService 入库
- [ ] intent=topic → 调用 TopicService 入库
- [ ] LLM 返回空标题时 → 响应 title 为截断的原文而非空字符串
- [ ] 降级场景 → 响应含 degraded: true + degradedReason
- [ ] 失败场景 → 响应含 success: false + error + errorType
- [ ] 传空文本 → 返回 validation 错误
