# 智能入库SmartIngest - 设计文档

## 一、架构设计总览

### 1.1 双AI路径架构

```
┌─ Agent 路径 ──────────────────────────────────────────────┐
│  用户粘贴文本 → Skill(AI 意图识别+字段提取)                  │
│    → 检查是否含"强制类型关键词"                              │
│    ├─ 含关键词 → 走例外流程 → 按关键词选定接口               │
│    └─ 无关键词 → 走默认流程 → 按识别意图调对应接口           │
│    → curl 调用后端已有接口(clip/add|todo/add|topic)         │
└───────────────────────────────────────────────────────────┘

┌─ 代码路径 ────────────────────────────────────────────────┐
│  浏览器插件/前端/外部 → POST /api/ingest { text }          │
│    → IngestController                                     │
│    → AiService.identifyIntent(意图识别)                    │
│    → AiService.extractFields(字段提取)                     │
│    → 路由到对应 Service(ClipService/TodoService/TopicService)│
│    → 返回 { success, intent, id, title, redirect }         │
└───────────────────────────────────────────────────────────┘
```

### 1.2 默认流程与例外流程决策树

```
用户发送内容
    ↓
检查是否含"强制类型关键词"
    ↓
┌───────────────┬──────────────┐
│ 含关键词       │ 无关键词      │
└───────┬───────┴──────┬───────┘
        ↓              ↓
   走例外流程       走默认流程
        ↓              ↓
   按关键词         Agent 做意图识别
   选定接口         + 字段提取
        ↓              ↓
   入库            按识别意图调对应接口
```

### 1.3 接口优先级规则

1. **用户明确指定类型** > 一切（最高优先级）
2. **Agent 意图识别结果** > 默认降级（clip）
3. **字段提取失败** > 降级为 clip，使用原文作为 content

## 二、核心设计决策

### 2.1 意图识别规则

| 意图 | 特征 | 示例 |
|------|------|------|
| `clip` | 长文、报告、URL、无明确行动项 | "TCP 三次握手过程..." |
| `todo` | deadline、优先级、行动项 | "明天下午3点前完成报告，高优" |
| `topic` | 分享推荐、观点讨论 | "推荐 Obsidian 这个笔记工具" |

### 2.2 字段提取映射

| 意图 | 提取字段 | 目标 API |
|------|----------|----------|
| clip | title, content, summary, analysis, tags, category, sourceUrl | `POST /api/clip/add` |
| todo | title, priority, deadline, deadlineTime, category | `POST /api/todo/add` |
| topic | title, summary, content, tags, category | `POST /api/topic` |

### 2.3 强制类型关键词映射

| 用户关键词 | 走的接口 | 说明 |
|----------|---------|------|
| "智能剪藏"、"智能入库"、"smart clip"、"ingest"、"后端AI处理" | `POST /api/ingest` | **特殊路径**：Agent 不做字段提取，只传 text，让后端 AI 全权处理 |
| "剪藏到话题"、"作为话题入库"、"添加话题"、"创建话题"、"topic入库" | `POST /api/topic` | 跳过意图识别，强制按话题整理字段入库 |
| "添加剪藏"、"剪藏入库"、"保存为剪藏"、"clip入库"、"clip this" | `POST /api/clip/add` | 跳过意图识别，强制按剪藏整理字段入库 |
| "添加待办"、"创建待办"、"新建待办"、"todo入库"、"todo this" | `POST /api/todo/add` | 跳过意图识别，强制按待办整理字段入库 |

### 2.4 后端接口清单

| 接口 | 路径 | 入参 | 处理逻辑 |
|------|------|------|---------|
| 智能入库 | `POST /api/ingest` | `{"text": "原文"}` | 后端 AI 自主做意图识别+字段提取+路由入库 |
| 直接剪藏 | `POST /api/clip/add` | 完整 ClipRequest | 直接存储，Agent 已整理好字段 |
| 直接待办 | `POST /api/todo/add` | 完整 TodoContent | 直接存储 |
| 创建话题 | `POST /api/topic` | 完整 TopicRequest | 直接创建话题 |
| 从剪藏升级话题 | `POST /api/topic/from-clip/{clipId}` | path 参数 clipId | 把已存在的剪藏转换为话题 |

### 2.5 POST /api/ingest 响应格式

**成功响应**：
```json
{ "success": true, "intent": "todo", "id": 123, "title": "...", "redirect": "/api/todo/123" }
```

**降级响应**：
```json
{ "success": true, "intent": "clip", "id": 123, "title": "...", "degraded": true, "degradedReason": "..." }
```

**失败响应**：
```json
{ "success": false, "error": "...", "errorType": "validation|storage_failed|internal_error" }
```

### 2.6 异常处理规则

| 异常场景 | 处理方式 |
|----------|----------|
| 后端未启动 | 提示用户启动后端服务 |
| 意图模糊 | 降级为 clip store-only |
| 字段提取失败（空标题） | 原文前 30 字作 title |
| curl 超时 | 3 次重试 + 延迟 0/2/5 秒策略 |
| LLM 返回空字符串 | getString() trim 后返回 defaultValue |
| capturedAt 缺失 | 后端自动填充 LocalDateTime.now() |
| Git 操作失败 | 捕获异常仅打日志，不影响主流程 |

### 2.7 三态降级判断

```javascript
function getDegradationState(fields) {
    const title = getString(fields, 'title', '');
    const intent = getString(fields, 'intent', 'clip');
    if (!title && intent === 'clip') return 'clip_store_only';
    if (!title) return 'title_fallback';
    return 'normal';
}
```

## 四、边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 文本为空 | 前端拦截提示"请输入内容" |
| 文本过短（<5字符） | 前端拦截提示"内容过短" |
| 意图识别为 clip 但标题为空 | 使用原文前 30 字作 title，降级标记 |
| 意图识别为 todo 但无 deadline | deadline 字段为 null，正常创建待办 |
| 意图识别为 topic 但无 summary | 使用 content 前 50 字作 summary |
| LLM 返回 `{"title": ""}` | getString() 返回 defaultValue（截断原文） |
| 后端服务未启动 | 前端提示"网络错误，请确认后端服务已启动" |
| 浏览器插件未配置 ingestUrl | 使用默认值 `http://localhost:8081/api/ingest` |
| 关键词包含匹配（如"智能剪藏这个"） | 仍识别为"智能剪藏"关键词 |
| 话题从剪藏导入时无 AI 分析 | 拼接原文+AI分析+发散总结 |
