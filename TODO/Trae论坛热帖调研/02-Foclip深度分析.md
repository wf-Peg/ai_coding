## 二、产品功能全览（复赛版）

Foclip 是一条完整的用户路径，覆盖 **拾取 → 加工 → 分发 → 沉淀** 四个环节：

| 环节 | 功能 | 说明 |
|---|---|---|
| **拾取** | 智能识别模式 | **元素级 / 帖子级 / 内容块 / 大容器四级识别**，可精准选中单张图片、代码块、表格、段落，也可整页提取 |
| | 层级选择 | 单选状态机，支持「选中父级 / 选中子级」沿层级链上下调整，暂停 / 继续拾取 |
| **加工** | 多格式输出 | Markdown（内联格式保真）/ 富文本（所见即所得，图文兼得）/ 结构树 / JSON / 图片，实时预览 |
| | Studio 编辑器 | 富文本编辑（去空行、去分割线、去图片、正则替换、去重）+ 图像画布（8 控制点裁剪、标注对象化、网格切分、马赛克）+ AI 对话（多模态 / 参考图 / 文生图，可自定义 API） |
| **分发** | 8+ AI 平台一键投递 | DeepSeek、豆包、ChatGPT、Kimi、Claude、Gemini、通义千问、文心一言 + 自定义平台；**Prompt 模板自动包裹** |
| | 本地导出 | 下载 .md / .txt / .html / .docx 文件 |
| **沉淀** | 剪藏历史库 Vault | 每次抓取 / 复制 / 导出自动入库，支持**搜索、标签、再导出、统计** |
| **效率** | 快捷键 | Alt+X 进入选择、Alt+C 快拷、Alt+S 截图、Alt+V 打开历史库 |
| **体验** | 主题 + 设计系统 | 浅色 / 深色 / 跟随系统，统一线性 SVG 图标，无 emoji |

## 三、核心亮点技术（复赛阶段打磨出的关键实现）

1. **内容密度算法（识别边界）**：从点击位置向上遍历 DOM，找到含 ≥2 个内容元素的祖先节点作为识别边界，把识别从"单段落"升级为"内容块"，解决论坛页"发帖人 vs 评论"分不清的问题——这是整个拾取能力的地基。
2. **三路并行解析（让 AI 正确消费网页）**：
   - **Markdown**：喂 AI 对话，剥离图片，体积可控；
   - **结构树**：让 AI 看页面布局，体积最小，升级为"语义角色"推断（`[main]`/`[list]`/`[heading:h1]`）+ 同构兄弟节点聚合；
   - **富文本**：按渲染态提取，保留图文混排、所见即所得。
   - 三路互不替代，按场景选用，并带"防爆炸机制"（图片剥离、硬上限、白名单清洗、同构聚合）。
3. **新增"设计快照"格式**：输出 class 去重 + `<style>` 块 + 完整布局属性的代码块，让 AI 以"读源码"方式理解页面设计、复刻页面。
4. **数据不丢**：导出内容从"URL hash 传大对象"（长文截断）改为**写入 IndexedDB，URL 只带 clipId**。
5. **投递可靠**：AI 平台自动填入从硬编码选择器改为**"数据驱动"的规则包**（8+ 平台），平台改版也能快速适配。
6. **截图链路**：`visibility:hidden + requestAnimationFrame` 防闪烁；长截图按帧裁剪去重并实时预览（解决选中框入图、粘性顶栏入图问题）。
7. **Studio 画布**："底图 + 标注对象 + 预览层"三层合成，撤销/重做为统一快照。
8. **架构**：拆分为「抓取 / 加工 / 分发 / 沉淀」四层 + 独立 core 纯逻辑模块，跨上下文统一走消息总线协议，数据经 chrome.storage / IndexedDB 传递，避免巨石文件和 URL 传大对象。

**技术栈**：Chrome Extension Manifest V3、Vanilla JavaScript（无框架、无构建依赖）、IndexedDB、Shadow DOM、Canvas、WebSocket。

## 四、从初赛 ClipFlow 到复赛 Foclip 的演进

| 维度 | 初赛 ClipFlow（2026-06） | 复赛 Foclip（2026-07） |
|---|---|---|
| 平台投递 | DeepSeek / 豆包 / ChatGPT 3 个，硬编码选择器 | **8+ 平台**（加 Kimi/Claude/Gemini/通义/文心 + 自定义），数据驱动规则包 |
| 编辑器 | 简单导出编辑器（去空行/去重/正则） | **Studio 高级编辑器**：富文本 + 图像画布（裁剪/标注/切分）+ AI 对话（多模态/文生图） |
| 内容沉淀 | 无（用完即焚） | **Vault 剪藏历史库**：自动入库、搜索、标签、再导出、统计 |
| 识别 | 单段落 → 内容块（内容密度算法） | **四级识别**（元素/帖子/内容块/大容器）+ 父级/子级层级调整 |
| 存储 | URL hash 传对象（长文截断） | **IndexedDB + clipId**，大内容不丢 |
| 架构 | 2200+ 行单文件巨石 | 四层架构 + core 模块化 + 消息总线 |
| 格式 | Markdown / HTML / 结构树 / JSON | + 设计快照、按渲染态富文本提取、Markdown 内联管线重写（逐项保真） |

**创作历程（可复用的 TRAE 协作方法论）**：
1. 灵感：在 TRAE 里看到大段内容想整理喂给 AI，全选复制带杂质、拖动太慢 → 想做"点一下"工具；
2. 初赛：搭骨架跑通"识别→复制→跳转 AI 填入"核心链路（spec 模式确认开发计划、反馈驱动迭代：内容密度算法就是反馈"论坛分不清发帖人和评论"后引入的）；
3. 复赛四阶段：**架构重构**（评审 20+ 影响产品化的问题 → 拆模块）→ **多轮实测反馈迭代**（识别精度/格式保真/截图链路/Studio）→ **解析引擎性能优化**（三路并行 + 防爆炸 + 设计快照）→ **产品化打磨**（Vault/主题/快捷键）。

## 五、商业化与迭代规划（作者原述）

- **商业模式**：核心能力免费开放；后续可选 ① 企业/团队高级版（云同步、站点净化规则库、团队共享剪藏）；② 与 AI 助手/生产力工具联动的增值服务；③ 引流到同生态付费工具链。
- **护城河**：精准网页内容解析能力、三路并行格式、可沉淀的剪藏库、以及"AI 也能调用"的 CLI / Skill 能力。
- **迭代规划**：近期（更多站点净化规则、云同步、PDF 导出）→ 中期（规则包远程更新"数据驱动"体系、Firefox/Safari、**foclip-cli 命令行 + TRAE Skill**，通过 WebSocket / Native Messaging 与扩展通信，让 AI Agent 也能自然语言端到端调用）→ 长期（团队协作与生态化）。

## 七、对「剪藏 Clip」项目的借鉴清单

### P0 —— 直接可移植（与 Clip 浏览器扩展/剪藏链路同构）
1. **四级内容识别 + 内容密度算法**：Clip 浏览器复制剪藏可升级为"元素/内容块/整页"识别，用"点击位置向上找含 ≥2 内容元素的祖先"算法定边界；
2. **三路并行解析输出**：剪藏正文同时产出 Markdown（喂 AI）/ 结构树（页面布局）/ 富文本（图文保真），供不同消费场景选用；
3. **IndexedDB + clipId 存储**：大内容（长文/长截图）不走 URL，Clip 的链接解析与文档解析可借鉴，避免长文截断；
4. **数据驱动平台规则包**：Clip 多 LLM 路由（DashScope/DeepSeek）可扩展为"平台规则包 + Prompt 模板自动包裹"，一键投递到指定模型。

### P1 —— 二次开发借鉴
5. **Vault 剪藏历史库**：Clip 已有剪藏列表，可补"统计仪表盘 + 标签检索 + 再导出"；
6. **Studio 编辑器**：富文本整理工具（去空行/去分割线/正则/去重）+ 图像画布，可增强 Clip 专题编辑与图片管理；
7. **设计快照格式**：让 AI 以"读源码"方式复刻网页设计——可作 Clip 对前端类剪藏的分析模板。

### P2 —— 思路参考
8. **foclip-cli / TRAE Skill 化**：把"抓取→加工→分发→沉淀"封装成命令行/Skill 供 AI Agent 调用——与 Clip 未来"AI 智能入库"（TODO/智能入库SmartIngest）方向一致；
9. **商业化分层**：核心免费 + 团队高级版（云同步/站点规则库）的护城河思路，可作为 Clip 产品化参考。
