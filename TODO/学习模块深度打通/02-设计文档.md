# 设计文档：学习模块深度打通

## 设计借鉴

| 借鉴点 | 落地设计 |
|--------|---------|
| Obsidian 双链（[[知识]]） | 学习阶段以 linkedKnowledgeIds 引用知识 |
| Obsidian 反链面板 | 知识/剪藏详情展示被学习计划引用 |
| Obsidian 全库图谱 | 学习计划节点 + plan_links 边入图谱 |
| Notion 数据库关联 | 阶段卡片关联区块 + 多选 picker |
| Obsidian 编辑器联动 | 阶段说明编辑器新标签打开 |

## 数据模型变更

- `LearningPlan.Phase` 新增：`linkedKnowledgeIds`(关联知识)、`sourceClipIds`(关联剪藏)，阶段级、为唯一真源。

## 后端设计

- `LearningPlanService`：`updatePhaseLinks`、`getPlansByKnowledge`、`getPlansByClip`。
- `LearningPlanController` 新增：
  - `PUT /api/learning-plan/{id}/phase/{phaseNum}/links`
  - `GET /api/learning-plan/by-knowledge/{knowledgeId}`
  - `GET /api/learning-plan/by-clip/{clipId}`
- `GraphService`：`recordPlanRelations`(plan_links 边)、`removePlanRelations`；`syncRelations`/`getGraph` 扩展纳入学习计划。

## 前端设计

- `learning-plan.html`：阶段卡片关联区块 + picker 弹窗 + 编辑器打开 + `?planId=` 直达。
- `knowledge-detail` / `clip`：被学习计划引用反链区块。
- `knowledge-graph`：学习计划节点(绿三角) + plan_links 边(绿线) + 图例。
- `index.html`：`navigateLearningPlan` 与 `openTextData` 转发路由。

## 数据流转图

```
[学习计划] Phase.linkedKnowledgeIds --plan_links--> knowledge:{kid}
          Phase.sourceClipIds     --plan_links--> clip:{cid}
    ├─ 反链：知识/剪藏「被学习计划 X · 阶段 N 引用」→ 跳转学习计划
    ├─ 图谱：learning-plan 节点(绿三角) + plan_links 边(绿线)
    └─ 编辑器：阶段说明 detailMarkdown → openTextData → 编辑器新标签编辑
```

## 关键决策

- 阶段级关联为唯一真源，图谱边为投影（与 derived_from/linked_to 同模式）。
- plan_links 为新增关系类型，不混用 derived_from。
- 反链用遍历实现，不引入新索引。
- 编辑器联动为单向打开，不做双向同步。
- 两套知识模型断层记录为已知问题，本次不处理。
