# 图标文件说明

此目录需要包含以下PNG格式的图标文件：

- `icon-16.png` - 16x16像素
- `icon-32.png` - 32x32像素
- `icon-48.png` - 48x48像素
- `icon-128.png` - 128x128像素

## 生成图标

请在浏览器中打开 `generate-icons.html` 文件，点击"生成所有图标"按钮，下载所有图标并放在此目录下。

## 临时解决方案

在正式生成图标之前，你可以：
1. 使用任何图片编辑器创建上述尺寸的PNG图标
2. 使用在线图标生成工具
3. 暂时注释掉manifest.json中的icons配置
