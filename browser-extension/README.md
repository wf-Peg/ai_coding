# 智能剪藏助手 - 浏览器扩展

这是一个与后端服务配合使用的浏览器扩展，支持从网页快速剪藏内容。

## 功能特性

- 🖱️ **右键菜单剪藏** - 右键点击页面、选中内容或图片快速剪藏
- ⌨️ **快捷键支持** - Ctrl+Shift+S 剪藏页面，Ctrl+Shift+D 剪藏选中内容
- 📝 **弹出窗口编辑** - 在发送到后端之前可编辑剪藏内容
- ⚙️ **灵活配置** - 可配置API地址、默认剪藏类型等
- ✨ **智能内容提取** - 自动识别并提取页面正文内容

## 安装说明

### 1. 准备图标文件

在使用前，请先生成所需的图标文件：

1. 在浏览器中打开 `icons/generate-icons.html`
2. 点击"生成所有图标"按钮
3. 将下载的4个图标文件放入 `icons/` 目录中

或者，临时修改 `manifest.json` 注释掉icons相关配置。

### 2. 加载扩展到Chrome浏览器

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择此 `browser-extension` 文件夹

### 3. 配置扩展

1. 点击浏览器工具栏中的扩展图标
2. 点击设置按钮（⚙️）或在扩展管理页面点击"选项"
3. 配置后端API地址（默认：http://localhost:8080/api/clip/add）
4. 点击"测试连接"确保后端服务正常运行
5. 保存配置

## 使用方法

### 方式1: 右键菜单

1. 在任意网页右键点击
2. 选择"智能剪藏"子菜单
3. 选择剪藏方式：
   - 剪藏整个页面
   - 剪藏选中内容
   - 剪藏图片
   - AI文本整理（快速）
   - 仅存储内容（快速）

### 方式2: 快捷键

- `Ctrl+Shift+S` (Mac: `Cmd+Shift+S`) - 剪藏当前页面
- `Ctrl+Shift+D` (Mac: `Cmd+Shift+D`) - 剪藏选中内容

### 方式3: 弹出窗口

1. 点击浏览器工具栏中的扩展图标
2. 在弹出窗口中手动输入或粘贴内容
3. 选择分类、添加标签
4. 点击"添加剪藏"

## 配置选项

- **API地址**: 后端服务接口地址
- **API超时时间**: API调用的超时时间（1-60秒）
- **API重试次数**: API调用失败时的重试次数（0-5次）
- **默认剪藏类型**: AI文本整理 / 仅存储内容 / 链接AI解析 / 文档AI解析
- **界面风格**: 常规风格 / Notion风格（`options` 与 `popup` 联动）
- **默认使用AI自动生成标签**: 开启/关闭
- **自动记录来源URL**: 开启/关闭
- **浏览器通知**: 开启/关闭成功通知
- **快捷键设置**: 显示默认快捷键，可在Chrome扩展管理页面自定义
- **内容提取规则**: 配置CSS选择器规则，按顺序执行
- **大模型噪声内容整理**: 启用/禁用，配置API密钥和模型参数

## 架构说明

```
浏览器扩展 (前端)
├── Manifest (配置文件)
├── Background Script (背景脚本)
│   ├── 创建右键菜单
│   ├── 处理快捷键
│   ├── 管理消息传递
│   └── 发送请求到后端
├── Content Script (内容脚本)
│   └── 提取页面内容
├── Popup (弹出窗口)
│   └── 编辑和确认剪藏内容
└── Options (选项页面)
    └── 配置扩展设置

后端服务
└── REST API接口
    ├── POST /api/clip/add - 添加剪藏
    └── GET /api/clip/list - 获取剪藏列表
```

## 依赖后端API

确保后端服务正在运行，并提供以下接口：

- `POST /api/clip/add` - 添加剪藏内容
  - 请求体: `{ type, content, source, category, tags, useAiTags }`
  - 响应: `{ status: 'success', data: { id, ... } }`

- `GET /api/clip/list` - 获取剪藏列表（用于测试连接）

## 开发说明

### 文件结构

```
browser-extension/
├── manifest.json          # 扩展配置
├── background.js          # 背景脚本
├── content.js             # 内容脚本
├── content.css            # 内容样式
├── popup.html/css/js      # 弹出窗口
├── options.html/css/js    # 选项页面
├── shared-ui-theme.css    # 共享主题变量（regular/notion）
├── shared-ui-base.css     # 共享基础组件样式
├── icons/                 # 图标文件
└── README.md              # 说明文档
```

### 主题说明

- `uiTheme` 配置保存在 `chrome.storage.local`。
- `options.html` 里切换风格并保存后，`popup.html` 会自动应用相同风格。
- 默认风格为 `notion`。

### 调试技巧

1. 打开 `chrome://extensions/`
2. 点击"Service Worker"查看背景脚本日志
3. 打开网页按F12查看内容脚本日志
4. 右键点击弹出窗口选择"检查"调试弹出窗口

## 注意事项

- 确保后端服务正在运行
- CORS配置正确，允许浏览器扩展访问
- 首次使用请配置API地址并测试连接
