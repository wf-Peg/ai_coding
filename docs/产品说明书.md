## 第1章：认识 CutShelter

### 1.1 产品定位

CutShelter 是一款全功能个人信息管理工具，集信息剪藏、知识管理、密码管理、学习规划于一体，帮助用户捕捉、整理和管理各类信息，构建个人知识库。

- **解决问题**：解决用户信息碎片化、难以有效管理和检索的问题，目标用户为需要频繁收集和整理信息的个人用户。
- **产品价值**：提高信息管理效率，通过 AI 辅助实现智能整理和分析，形成结构化的个人知识体系。
- **核心优势**：本地存储保障数据安全，AI 智能分析提升信息价值，简洁直观的 Notion 风格界面，支持多模型灵活切换，覆盖桌面端和浏览器扩展。

## 第2章：快速上手

### 2.1 环境要求

| 组件 | 要求 |
|------|------|
| JDK | 17+ |
| Maven | 3.6+ |
| Node.js | 18+（仅桌面打包需要） |
| 浏览器 | 现代浏览器（Chrome/Firefox/Edge） |
| API Key | DashScope 和/或 DeepSeek |

### 2.2 桌面应用安装（推荐）

#### Windows 安装

1. 从发布页面下载 `剪藏 Setup x.x.x.exe` 安装包
2. 双击运行安装程序，按照向导完成安装
3. 安装完成后，桌面生成快捷方式，双击启动
4. 首次启动显示配置引导窗口，填写 API Key 等配置信息
5. 配置完成后，自动启动前端和后端服务，进入主界面

#### macOS 安装

1. 下载 `剪藏-x.x.x.dmg` 安装包
2. 双击 DMG 文件，将 CutShelter 拖入 Applications 文件夹
3. 首次启动时，右键点击应用图标选择"打开"（绕过 Gatekeeper 限制）
4. 自动进入配置引导流程

#### Linux 安装

1. 下载 `剪藏-x.x.x.AppImage` 文件
2. 赋予执行权限：`chmod +x 剪藏-x.x.x.AppImage`
3. 双击运行即可

### 2.3 源码运行

#### 配置 API Key

1. 复制 `backend/src/main/resources/application_templete.yml` 为 `application.yml`
2. 填写 API Key：
   ```yaml
   spring:
     ai:
       dashscope:
         api-key: your-dashscope-api-key  # 阿里云DashScope API Key（必填）
   ```
3. 可选：在设置页面中配置 DeepSeek API Key

#### 一键启动（推荐）

**Windows：**
```bash
start.bat
```

**macOS / Linux：**
```bash
chmod +x start.sh
./start.sh
```

脚本会自动检查 Java 环境、编译 JAR 包（如需要）、启动后端和前端服务。

#### 手动启动

**启动后端服务：**
```bash
cd backend
mvn clean package -DskipTests
mvn spring-boot:run
```
后端服务将在 `http://localhost:8081` 启动。

**启动前端服务：**
```bash
npx serve frontend -l 3000
# 或使用 Python
cd frontend && python3 -m http.server 3001
```
前端服务将在 `http://localhost:3001` 启动。

### 2.4 浏览器扩展安装

1. 打开 Chrome 浏览器，进入扩展管理页面（`chrome://extensions/`）
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择项目中的 `browser-extension/` 目录
5. 安装完成后，浏览器工具栏出现剪藏图标
6. 点击扩展图标，进入设置页面配置后端 API 地址
7. 点击"测试连接"按钮验证配置是否正确

### 2.5 首次使用流程

1. 启动应用后，进入配置引导窗口（首次运行）
2. 设置存储路径、API Key、模型偏好
3. 完成后进入主界面，左侧导航栏展示各功能模块
4. 在剪藏页面添加第一条剪藏内容
5. 在设置页面配置主题外观、快捷键等个性化选项

## 第3章：剪藏模块

### 3.1 添加剪藏

#### 3.1.1 内容输入

位于剪藏页面上方，提供多行文本框（`<textarea>`），支持以下输入方式：

- **文本输入**：手动输入或粘贴文本内容
- **语音输入**：点击麦克风图标，通过浏览器 Web Speech API 进行中文语音识别，识别结果自动填充到内容输入框
- **图片粘贴**：支持直接从剪贴板粘贴图片（Ctrl+V），自动触发图片上传
- **批量上传**：点击上传按钮，选择多张图片进行批量上传，自动存储并在内容中添加图片引用

文本框具有自适应高度特性，根据输入内容自动调整高度，最大化编辑区域。`placeholder` 提示文案为"输入或粘贴要剪藏的内容..."。

#### 3.1.2 类型选择

下拉选择框（`<select>`），提供四种剪藏类型：

| 类型 | 值 | 说明 |
|------|-----|------|
| AI 文本整理 | `ai-text` | 默认类型，AI 自动分析内容、提取关键词和摘要 |
| 仅存储内容 | `store-only` | 不进行 AI 分析，直接存储原始内容 |
| 链接 AI 解析整理 | `link-ai` | 输入 URL 链接，后端 `LinkParseService` 解析并 AI 分析 |
| 文档 AI 解析整理 | `doc-ai` | 上传文档文件，后端 `DocumentParseService` 解析并 AI 分析 |

#### 3.1.3 来源选择

文本框输入，提示用户输入来源地址，如 `www.sspai.com`。支持任意格式的 URL 或文本描述。

#### 3.1.4 分类选择

下拉选择框，提供预定义分类 + AI 自动匹配：

| 分类 | 值 | 说明 |
|------|-----|------|
| AI 自动分类 | `""` | 默认选项，由 AI 分析内容后自动匹配分类 |
| 工作项目 | `work` | 工作相关的项目、文档、资料 |
| 学习成长 | `study` | 学习笔记、教程、课程资料 |
| 生活健康 | `life` | 生活记录、健康信息、日常备忘 |
| 兴趣探索 | `hobby` | 兴趣爱好、休闲娱乐内容 |
| 财务规划 | `finance` | 财务信息、投资理财、账单记录 |
| 人脉社交 | `social` | 社交关系、联系人信息、社交动态 |

#### 3.1.5 标签管理

标签输入区域包含两个交互组件：

- **AI 生成标签复选框**：默认选中，选中时 AI 自动分析内容生成标签，同时禁用手动输入。取消选中时，手动输入标签区域启用。
- **手动标签输入**：输入框支持回车添加标签，标签以彩色圆角矩形显示在输入框上方，每个标签带有删除按钮（×）。最多支持 10 个标签。
- **标签展示**：标签以彩色圆角矩形显示，不同分类使用不同颜色区分。

#### 3.1.6 操作按钮

| 按钮 | 功能 |
|------|------|
| 添加剪藏 | 提交表单，将内容发送至后端。显示加载状态动画，按钮变为"处理中..."并禁用 |
| 清空 | 清空所有输入字段，重置表单 |

#### 3.1.7 提交流程

1. 用户点击"添加剪藏"按钮
2. 前端校验内容是否为空，非空则发送 POST 请求到 `/api/clip/add`
3. 后端接收请求，根据类型进行 AI 分析（`ai-text` 类型）
4. 调用 `AiService` 生成关键词和摘要
5. 如果有图片，存储图片到 `{storagePath}/images/{category}/{fileName}`
6. 将剪藏内容和 AI 分析结果存储到本地 JSON 文件 `{storagePath}/{category}/{date}.json`
7. 返回成功响应，前端显示成功提示

### 3.2 剪藏列表

#### 3.2.1 列表展示

剪藏列表以卡片形式展示所有剪藏记录，每条卡片包含：

- **摘要**：截取剪藏内容的前 100 字符
- **类型标签**：显示剪藏类型（AI 文本整理/仅存储/链接/文档）
- **来源链接**：可点击跳转至来源 URL
- **分类标签**：显示所属分类
- **标签列表**：展示前 3 个标签，超出 3 个时显示 `+N` 按钮，点击展开所有标签
- **创建时间**：显示格式化的创建日期和时间
- **操作按钮**：悬停时显示删除和展开按钮

#### 3.2.2 卡片交互

- **悬停效果**：鼠标悬停时卡片轻微上浮（`transform: translateY(-2px)`），显示操作按钮
- **点击展开**：点击卡片展开按钮，显示详细内容和 AI 分析结果
- **标签点击**：点击标签可筛选同标签内容

#### 3.2.3 详细内容面板

展开后展示：

- **原文内容**：完整原始内容，支持 Markdown 渲染
- **AI 分析结果**：以 Markdown 格式渲染，包含关键词提取和摘要
- **关联信息**：如果关联了专题，显示专题链接
- **操作按钮**：发散性总结、转为待办、关联专题

### 3.3 AI 分析

#### 3.3.1 自动分析

添加剪藏时自动触发 AI 分析，分析内容包括：

- **关键词提取**：识别内容中的关键概念和术语
- **内容摘要**：生成简短的内容摘要，概括核心信息
- **分类匹配**：自动匹配最合适的分类
- **标签生成**：生成相关标签（当 AI 生成标签开启时）

#### 3.3.2 分析结果展示

- 分析结果以 Markdown 格式渲染（使用 Marked.js 库）
- 显示在卡片展开后的详细面板中
- 支持复制分析结果文本

### 3.4 发散性总结

#### 3.4.1 功能入口

在剪藏卡片展开后的详细面板中，点击"发散性总结"按钮。

#### 3.4.2 生成过程

1. 点击按钮后，发送 GET 请求到 `/api/clip/divergent-summary/{id}`
2. 后端调用 AI 分析，生成专家级分析和深度见解
3. 结果以流式（SSE）返回，前端使用打字机效果逐字展示
4. 展示完成后，可复制生成的分析结果

#### 3.4.3 交互细节

- 生成过程中显示加载动画
- 打字机效果逐字渲染，增强用户体验和期待感
- 生成完成后，显示"复制结果"按钮
- 支持重新生成（再次点击按钮）

### 3.5 搜索功能

#### 3.5.1 切换搜索模式

点击页面右上角的"切换到信息检索"按钮，从剪藏列表模式切换为搜索模式。

#### 3.5.2 搜索交互

- **搜索框**：顶部搜索框，输入关键词后按回车或点击搜索图标执行搜索
- **分类筛选**：侧边栏展示分类列表，支持选择特定分类进行筛选
- **搜索结果**：以卡片列表形式展示，显示内容摘要和匹配度
- **清除搜索**：搜索框右侧显示清除按钮（×），点击重置搜索

#### 3.5.3 搜索逻辑

- 发送 GET 请求到 `/api/clip/search?keyword={keyword}&category={category}`
- 后端 `SearchService` 执行关键词模糊匹配和同义词搜索
- 结果按相关度排序返回
- 支持一级和二级分类筛选

### 3.6 删除操作

#### 3.6.1 删除流程

1. 点击卡片上的删除按钮（垃圾桶图标）
2. 弹出确认弹窗："确定要删除这条剪藏吗？"
3. 点击"确认"执行删除，发送 DELETE 请求到 `/api/clip/{id}`
4. 删除成功后，卡片从列表中移除，显示成功提示
5. 点击"取消"关闭弹窗，不执行任何操作

#### 3.6.2 确认弹窗

- 半透明遮罩层覆盖整个页面
- 居中弹窗卡片，包含标题、确认文案和两个按钮
- 圆角矩形按钮，"取消"为次要按钮，"确认"为主要按钮

### 3.7 剪藏转待办

#### 3.7.1 功能入口

在剪藏卡片展开后的详细面板中，点击"转为待办"按钮。

#### 3.7.2 转换流程

1. 点击按钮后，弹出待办编辑窗口
2. 自动填充剪藏内容摘要为待办标题
3. 用户可编辑待办内容、设置截止日期
4. 确认后发送 POST 请求到 `/api/todo/from-clip`，包含剪藏 ID
5. 后端创建待办并关联原始剪藏内容
6. 在待办详情中可查看关联的剪藏来源

### 3.8 剪藏关联专题

在剪藏详情中，可通过"关联到专题"按钮将剪藏条目关联到已有专题。选择专题后，发送 POST 请求到 `/api/topic/{topicId}/link-clip`，关联成功后该剪藏会出现在专题详情页的关联剪藏列表中。

## 第4章：待办管理

### 4.1 待办时间线

#### 4.1.1 页面布局

待办时间线页面（`todo.html`）采用垂直时间线布局，待办事项按截止日期升序排列。顶部显示统计信息条，展示总待办数、已完成数和进行中数。

#### 4.1.2 时间线视觉

- 每条待办左侧显示时间线圆点（未完成显示空心圆、已完成显示实心圆并带对勾）

## 第8章：密码管理

### 8.1 DES 加密零知识架构

#### 8.1.1 加密算法

密码管理模块使用 DES/ECB/PKCS5Padding 算法加密密码库，采用零知识架构：

- 加密算法：`DES/ECB/PKCS5Padding`
- 密钥长度：8 字节（64 bit）
- 加密库文件：`vault.enc`
- 元数据文件：`vault-meta.json`

#### 8.1.2 密钥管理

- **密钥生成**：使用 `SecureRandom` 生成 8 字节随机密钥，Base64 编码后展示给用户
- **密钥存储**：**系统不存储用户的密钥**，密钥仅由用户持有，需要自行保存
- **密钥校验**：后端存储密钥的 SHA-256 哈希（前 8 位十六进制），用于验证用户输入的密钥是否正确
- **密钥推导**：支持两种密钥输入方式：Base64 编码密钥（推荐）和任意密码字符串（通过 MD5 取前 8 字节推导）

#### 8.1.3 加解密流程

1. 用户首次使用 → 生成 DES 密钥 → 展示给用户 → 用户保存密钥
2. 用户输入密钥解锁 → Base64 解码 → 校验哈希 → 解密 `vault.enc` → 返回明文数据
3. 用户操作密码条目 → 内存中修改数据 → 重新加密存储
4. 密钥只在会话期间内存中保存，锁定时清除

### 8.2 密钥解锁

#### 8.2.1 锁屏界面

进入密码管理页面（`vault.html`）时，首先显示锁屏界面：

- 居中锁屏卡片（`lock-card`）
- 锁图标动画
- 标题："密码库已锁定"
- 副标题："输入 DES 密钥解锁密码库"
- 密码输入框（`type="password"`，等宽字体）
- "解锁"按钮
- 错误提示区域（默认隐藏，解锁失败时显示红色错误信息）

#### 8.2.2 解锁流程

1. 用户输入密钥，点击"解锁"按钮
2. 发送 POST 请求到 `/api/vault/unlock`，携带密钥
3. 后端校验密钥哈希，验证通过后解密密码库
4. 解锁成功后，跳转到密码库主界面
5. 解锁失败时，显示错误提示："DES 解密失败，请检查 Key 是否正确"

#### 8.2.3 首次使用

首次进入密码管理时，引导用户生成密钥：

- 点击"生成密钥"按钮
- 系统生成 8 字节随机密钥，Base64 编码显示
- 警示用户"请妥善保存此密钥，丢失后将无法恢复密码数据"
- 用户确认已保存后，进入设置流程

#### 8.3.1 主界面布局

解锁后进入密码库主界面，采用侧边栏 + 内容区布局：

#### 8.3.2 创建密码条目

点击"添加"按钮，弹出创建表单：

| 字段 | 类型 | 说明 |
|------|------|------|

| 用户名/邮箱 | 文本输入 | 必填，登录账号 |
| 密码 | 密码输入 | 必填，支持手动输入或使用密码生成器 |
| 分类 | 下拉选择 | 登录/卡片/笔记/身份 |
| 备注 | 文本区域 | 可选，其他信息 |

- **长度滑块**：拖动滑块设置密码长度（8-64 位，默认 16 位）
- **字符集复选框**：大写字母（A-Z）、小写字母（a-z）、数字（0-9）、特殊符号（!@#$%^&* 等）
- **密码强度指示器**：根据密码长度和字符集实时显示强度（弱/中/强/非常强）
- **密码预览**：显示生成的密码文本
- **刷新按钮**：重新生成随机密码
- **使用此密码**：将生成的密码填入当前表单

#### 8.4.3 生成逻辑

使用 `SecureRandom` 从选定的字符集中随机选取字符，确保密码的随机性和安全性。

### 8.5 安全审计

#### 8.5.1 审计功能

在侧边栏点击"安全审计"按钮，进入安全审计仪表盘：

- **弱密码检测**：识别长度不足、缺少字符类型的密码，按严重程度分级提示
- **重复密码检测**：检测多个条目使用相同密码的情况
- **安全评分**：整体安全评分（百分比）
- **问题条目列表**：列出所有存在安全问题的密码条目

#### 8.5.2 交互操作

- 点击问题条目可跳转到对应的密码详情进行修改
- 支持一键生成新密码替换弱密码
- 审计结果实时更新

### 8.6 导入导出

#### 8.6.1 CSV 导入

支持从 CSV 文件批量导入密码：

- 点击"导入密码"按钮
- 选择 CSV 文件
- 系统解析文件，预览导入数据
- 确认后批量导入

#### 8.6.2 加密导出

### 8.7 多密码库

支持多密码库管理（multi-vault）：

### 11.6 后端进程管理

#### 11.6.1 启动流程

1. 查找 JAR 包（自动搜索资源目录、开发目录、Maven target 目录）
2. 查找 Java 可执行文件（优先嵌入式 JRE，回退到系统 Java）
3. 确保存储目录存在
4. 生成 `application.yml` 配置文件
5. 以子进程方式启动 Java（`-Xms64m -Xmx256m`, `-XX:+UseG1GC`）
6. 轮询端口（每 2 秒）检测后端是否就绪，最多等待 120 秒

#### 11.6.2 停止流程

采用三级停止策略：

1. 发送 SIGTERM 请求优雅关闭
2. 3 秒后若未退出则 SIGKILL 强制终止
3. 通过端口清理兜底（防止僵尸进程）

#### 11.6.3 启动模式

桌面应用支持三种启动模式：

| 模式 | 说明 |
|------|------|
| `full` | 完全启动，前后端同步启动，等待后端就绪后创建窗口 |
| `frontend-async-backend` | 前端快速启动，后端异步自动启动，就绪后通知用户 |
| `frontend-only` | 仅启动前端，后端手动启动（默认模式） |

#### 11.7.1 首次启动

#### 11.8.1 关闭对话框

## 第12章：使用技巧与最佳实践

### 12.1 内容管理流程

#### 12.1.1 推荐的工作流

1. **日常收集**：使用浏览器扩展（右键菜单或快捷键）随时剪藏感兴趣的内容
2. **快速整理**：在剪藏列表中查看 AI 自动分析结果，修正分类和标签
3. **深度处理**：对重要内容生成发散性总结，获取 AI 深度分析
4. **知识沉淀**：将重要剪藏派生为知识条目，或关联到专题进行系统化整理
5. **行动转化**：将需要执行的事项转为待办，设置截止日期和提醒
6. **定期回顾**：查看每日整理日报和每周周报，回顾知识积累

#### 12.1.2 内容分类策略

- 利用 AI 自动分类功能快速归类
- 定期手动调整分类，确保分类准确
- 利用标签细化分类，一个剪藏可以有多个标签

#### 12.1.3 标签使用建议

- 标签使用统一的命名规范（如全小写、下划线分隔）
- 每个剪藏使用 3-5 个标签
- 使用 AI 自动生成标签作为起点，手动补充

### 12.2 省 token 技巧

#### 12.2.1 合理选择剪藏类型

- 不需要 AI 分析的内容选择"仅存储内容"，避免不必要的 API 调用
- 需要 AI 分析的内容选择"AI 文本整理"
- 链接和文档内容选择对应的解析类型

#### 12.2.2 模型选择策略

- 简单任务（标签生成、分类）使用轻量模型
- 复杂任务（深度分析、学习计划）使用更强模型
- 通过 LLM 路由配置实现按任务自动分配模型

#### 12.2.3 Prompt 优化

- 自定义 Prompt 模板，减少不必要的 token 消耗
- 精简 Prompt 指令，提高 AI 输出质量

### 12.3 提示词技巧

#### 12.3.1 自定义 Prompt

在系统设置中可以自定义各场景的 Prompt 模板：

- **分析场景**：指定分析的角度和深度
- **总结场景**：控制摘要的长度和格式
- **标签生成**：限定标签的数量和风格
- **发散性总结**：指定分析的专业领域和视角

#### 12.3.2 有效的 Prompt 编写

- 明确指定输出格式（如 Markdown 列表、JSON 结构）
- 给出具体的分析角度和要求
- 设定语言风格（正式/简洁/详细）

### 12.4 数据安全建议

#### 12.4.1 密码管理

- 首次使用密码库时，务必妥善保存生成的 DES 密钥
- 建议将密钥保存在离线密码管理器或物理介质中

- 定期导出加密备份

- 配置 Git 同步功能，定期将剪藏数据推送到远程仓库

### 12.5 主题与界面个性化

## 第13章：故障排除与常见问题

### 13.1 常见问题解答

#### Q1：启动时提示"后端启动失败"

**可能原因：**
- Java 环境未安装或版本不兼容（需要 JDK 17+）
- 端口 8081 被其他程序占用
- 防火墙阻止了 Java 进程

**解决方案：**
1. 检查 Java 版本：`java -version`
2. 检查端口占用：`netstat -ano | findstr :8081`
3. 在配置窗口中修改后端端口
4. 关闭防火墙或添加 Java 到白名单

#### Q2：剪藏内容无法保存

**可能原因：**
- 后端服务未启动
- 存储目录没有写入权限
- API Key 配置错误

**解决方案：**
1. 确认后端服务正在运行
2. 检查存储目录的写入权限
3. 在设置页面重新配置 API Key 并测试连接

#### Q3：浏览器扩展无法连接后端

**可能原因：**
- 后端服务未启动
- API 地址配置错误
- 跨域问题

**解决方案：**
1. 确认桌面应用已启动
2. 检查扩展设置中的 API 地址是否正确（默认 `http://localhost:8081/api/clip/add`）
3. 点击"测试连接"按钮验证

#### Q4：密码库无法解锁

**可能原因：**
- 密钥输入错误
- 密码库文件损坏
- 密钥被更改

**解决方案：**
1. 确认输入的密钥与生成时一致
2. 检查密钥是否包含多余的空格或换行
3. 如有备份，使用备份文件恢复

#### Q5：AI 分析返回错误

**可能原因：**
- API Key 已过期或余额不足
- 网络连接问题
- 模型选择不可用

**解决方案：**
1. 检查 API Key 的有效性和余额
2. 确认网络连接正常
3. 在设置页面切换其他模型测试
4. 查看后端日志获取详细错误信息

#### Q6：学习计划生成失败

**可能原因：**
- AI 模型不可用
- Exa 搜索 API 配置错误
- 输入参数不完整

**解决方案：**
1. 确认 AI 模型配置正确
2. 如不需要 Exa 搜索，可忽略资源搜索错误（会自动降级）
3. 确保学习主题和目标描述清晰详细

#### Q7：主题切换不生效

**原因：**
- 浏览器缓存导致
- iframe 子页面未收到广播事件

**解决方案：**
1. 刷新页面
2. 清除浏览器缓存（设置页面的"清除缓存"按钮）
3. 重新打开应用

#### Q8：桌面应用托盘图标不显示

**可能原因：**
- 托盘图标文件缺失
- 系统托盘区域已满
- 平台不支持（某些 Linux 桌面环境）

**解决方案：**
1. 重新安装应用
2. 在系统设置中调整托盘区域
3. Linux 用户可尝试不同的桌面环境

### 13.2 日志查看

### 13.3 数据备份与恢复

#### 13.3.1 备份方法

**方法一：Git 同步**
1. 在设置页面配置 Git 远程仓库
2. 点击"同步仓库"按钮手动推送
3. 或配置自动同步（内容整理/周报生成后自动执行）

**方法二：手动备份**
1. 找到存储目录（默认 `./clip-storage`）
2. 复制整个目录到安全位置
3. 密码库需额外备份 DES 密钥

**方法三：密码库导出**
1. 在密码管理页面点击"导出备份"
2. 保存加密的密码库文件

#### 13.3.2 恢复方法

1. 停止应用
2. 将备份文件恢复到原存储目录
3. 重新启动应用
4. 密码库恢复需要输入正确的 DES 密钥

#### 13.3.3 数据迁移

1. 在旧设备上备份整个存储目录
2. 在新设备上安装应用
3. 配置相同的存储路径
4. 将备份数据复制到新设备的存储路径
5. 重新启动应用

### 13.4 错误处理机制

#### 13.4.1 前端错误处理

- 网络请求失败时显示友好提示信息
- 表单验证在提交前执行，防止无效数据提交
- 删除操作前弹出确认弹窗，防止误操作
- 加载状态显示加载动画，避免用户重复操作

#### 13.4.2 后端错误处理

- `GlobalExceptionHandler` 统一处理异常，返回标准错误格式
- 参数校验错误返回 400 状态码
- 资源不存在返回 404 状态码
- 服务器内部错误返回 500 状态码，记录详细日志
- 主进程未捕获异常只记录日志，不让应用直接崩溃退出

### 13.5 性能优化建议

- 定期清理不再需要的剪藏内容
- 避免存储大量大文件图片
- 使用"仅存储内容"类型减少不必要的 AI 调用
- 定期清理日志文件
- 配置合适的存储路径，避免系统盘空间不足
