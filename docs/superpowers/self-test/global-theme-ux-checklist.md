## 核心行为验收

- [ ] 主题选择在刷新后保持（`app_theme_v1` / `app_appearance_v1`）。
- [ ] 动效偏好在刷新后保持（`app_motion_v1`）。
- [ ] 重启 Electron 后主题与动效偏好保持。
- [ ] 浏览器模式重新进入后主题保持。
- [ ] 所有已打开 iframe 在 300ms 内同步同一 `themeChange` 载荷（含 `theme` 与 `motion`）。
- [ ] 任一页面不出现明显白底闪烁、颜色孤岛或切换后文字不可读。
- [ ] 主题切换失败时回退到 `regular`，不阻塞业务页面。
- [ ] 主页面控件具有一致的圆角、边框、焦点环、禁用态和错误态。

## 减少动效验收

- [ ] 应用内「减少动效」开关生效（`data-motion="reduced"`）。
- [ ] 系统 `prefers-reduced-motion: reduce` 生效。
- [ ] 编辑器输入、滚动和长文阅读不被持续动画干扰。
- [ ] 减少动效时仍保留必要的状态反馈（成功/失败/加载的透明度与颜色变化）。

## 可访问性验收

- [ ] 主题卡片可通过键盘 Tab 聚焦并选择。
- [ ] 主题卡片暴露 `role="radio"`、`aria-checked` 与 `aria-label`。
- [ ] 主题卡片组暴露 `role="radiogroup"` 与 `aria-label`。
- [ ] 导航到主题选择的键盘路径完整（主导航 → 设置 → 界面主题）。
- [ ] 焦点样式在所有主题下清晰可见。
