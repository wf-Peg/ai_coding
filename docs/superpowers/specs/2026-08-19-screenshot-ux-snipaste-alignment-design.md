# 截图工具 UX 系统性对标（Snipaste 参照）设计

日期：2026-08-19
状态：已获用户确认
方案：A — 关键对标增量

## 背景与目标

在既有截图工具（选区/标注/贴图/OCR 已较完善）基础上，**系统性对标 Snipaste 等优秀工具**，补齐手感与细节。优化重点与优先级：
- **主**：交互体验四维度——选区增强、贴图操作、视觉与工具条、快捷键动线。
- **次**：F1 首次截图延迟与后台占用（轻量，本期不改，避免回归）。
- **硬性要求**：自测各功能正常、**截图区与画笔标注等相对位置不错乱**（坐标体系不可混用）。

既有基础（已 done，本期不动交互逻辑）：8 向选区手柄、滚轮缩放选区、方向键微调、放大镜、标注工具（方框/椭圆/箭头/画笔/文本/马赛克/橡皮）＋撤销＋取色、文本贴图、贴图拖动/缩放/透明度/置顶/右键菜单/层叠、OCR、全局快捷键。

## 范围外（本期不做）
- 启动速度深入优化（覆盖层已预建、OCR 已懒加载）。
- 像素级边缘智能吸附算法全量、贴图托盘、贴图旋转、选区历史。
- 不引入新配置开关（YAGNI，现有配置够用）。

## 设计详情

### 1. 选区增强（overlay：`electron/screenshot/screenshot-window.html`）
- 新增 `#gui` canvas：**尺寸走 DIP**（`width=display.width; height=display.height; style 100%`），与 `#sel`/`#mask` 同一坐标系。
- **十字准星**：三色细线（经典红/绿/蓝，对标 Snipaste），RAF 节流仅更新两条动线；另加读数 chip——未选区显示坐标 `(x,y)`，选坑中/后显示 `w × h`。
- **选区吸附（轻量）**：拖动/调整选区时，边缘逼近时吸附到**屏幕四边**与**垂直/水平中心线**，阈值 ~8px，走 DIP，作用于 `selRect`。
- **延伸参考线**：选中后从选区四边延伸出淡淡辅助线到屏幕边缘，辅助对齐。
- **光标反馈**：按区域切换 cursor（默认十字、选区内移动、手柄处缩放）。
- **坐标不回归**：准星/辅助线/吸附全部跑 DIP；标注/裁剪继续用既有 `sfPhys` 物理映射，**不修改 crop 换算逻辑**，从机制上保证选区↔标注不错乱。

### 2. 快捷键动线 + 动态提示（overlay）
- 保留全部现有快捷键不变。
- 底部 `#hint` 改为**随阶段动态文案**：
  - 初始：`拖拽选择区域 · Enter 复制 · Ctrl+S 保存 · Ctrl+T 贴图 · Esc 取消`
  - 选中后：`拖动内部移动 · 拖手柄调整 · 滚轮缩放 · 方向键微调 · R/O/A/P/T/M/E 标注 · Enter 复制`
- 动作 Toast 反馈保留。

### 3. 贴图操作增强（`paste`、`electron/screenshot/paste-window.html` + service）
- **双击保留关闭**（不动）；新增右键菜单项：`还原到初始尺寸`（`paste:reset-size`）。
- **重新排列**：`paste:rearrange` 级联重排所有打开贴图窗口。
- **右键菜单增强**：补「还原尺寸 / 透明度 − / 透明度 + / 重新排列 / 关闭全部贴图」，并显示缩放百分比。
- 拖动/滚轮缩放/Cmd+滚轮透明度/置顶逻辑保持不动（已验证，避免回归）。

### 4. 视觉与工具栏（overlay + paste）
- 工具栏/图标轻量精致化（圆角、分隔、激活态清晰）；窄屏 `flex-wrap` 自动换行保留。

### 5. 自测（硬性）
- 提供手工自测清单（选区/准星/吸附/标注对位/贴图全操作，macOS + Windows）。
- `node --check` 各改动 JS/内联脚本 + 关键 `console` 日志辅助。

## 涉及文件
- `electron/screenshot/screenshot-window.html`（选区增强、动态提示、视觉：改动主战场）

- `electron/screenshot/screenshot-service.js`（`paste:reset-size`、`paste:rearrange`、关闭全部/透明度 IPC）

- 十字准星与放大镜所取物理像素一致。
- 贴图拖动/缩放/透明度/置顶/还原/重排/关闭全部正常且不糊不抖。
- macOS + Windows 均通过自测清单。
