# 待办事项时间线优化计划

## 1. 现状分析

**当前实现**：
- 待办事项时间线已集成在 index.html 的左侧侧边栏
- 包含待办表单和时间线展示
- 支持添加、删除、标记完成等基本功能
- 按日期分组展示

**问题与需求**：
1. ✅ 待办事项时间线底下添加待办做隐藏，增加'+'号图标按钮
2. ✅ 点击'+'号按钮后在弹出界面做展示添加
3. ✅ 时间线内容展示与操作性需要优化
4. ✅ 需要能相对位置支持鼠标滚轮垂直滑动展示
5. ✅ 即使元素内容过长也不要有横向滚轮支持
6. ✅ 在代办列表具体数据展示的右下角中增加'...'作为详情按钮

## 2. 实现计划

### 2.1 HTML 结构修改

**修改文件**：`frontend/index.html`

**具体修改**：
1. **添加弹出添加待办的模态框**
   - 创建 `todo-modal` 模态框
   - 包含待办事项的输入字段
   - 添加、取消按钮

2. **添加'+'号添加按钮**
   - 在时间线下方添加浮动的'+'号按钮
   - 点击触发模态框

3. **为时间线项添加详情按钮**
   - 在每个待办项右下角添加'...'详情按钮
   - 点击显示详情模态框

### 2.2 CSS 样式优化

**修改文件**：`frontend/index.html`

**具体修改**：
1. **模态框样式**
   - 现代化的模态框设计
   - 平滑的动画效果
   - 响应式布局

2. **'+'号按钮样式**
   - 浮动按钮设计
   - 悬停效果
   - 位置固定在时间线底部

3. **时间线滚动优化**
   - 优化垂直滚动体验
   - 禁用横向滚动
   - 确保内容过长时不出现横向滚动条

4. **详情按钮样式**
   - 右下角'...'按钮
   - 悬停显示提示

### 2.3 JavaScript 功能优化

**修改文件**：`frontend/index.html`

**具体修改**：
1. **模态框控制**
   - `openTodoModal()` - 打开添加待办模态框
   - `closeTodoModal()` - 关闭模态框
   - `handleTodoSubmit()` - 处理待办提交

2. **详情功能**
   - `openTodoDetailModal()` - 打开待办详情模态框
   - `closeTodoDetailModal()` - 关闭详情模态框

3. **滚动优化**
   - 确保时间线容器支持垂直滚动
   - 禁用横向滚动

4. **交互体验**
   - 平滑的动画效果
   - 响应式设计
   - 错误处理

### 2.4 功能流程

1. **添加待办**：
   - 点击'+'号按钮 → 打开添加模态框 → 填写信息 → 提交 → 刷新时间线

2. **查看详情**：
   - 点击待办项右下角'...'按钮 → 打开详情模态框 → 查看详情 → 关闭

3. **滚动体验**：
   - 鼠标滚轮在时间线区域垂直滚动
   - 内容过长时自动换行，不出现横向滚动条

## 3. 技术实现要点

### 3.1 模态框实现
- 使用现有的模态框结构，扩展为待办专用
- 支持键盘快捷键（ESC关闭）
- 点击模态框外部关闭

### 3.2 滚动优化
- 使用 `overflow-y: auto` 实现垂直滚动
- 使用 `overflow-x: hidden` 禁用横向滚动
- 优化滚动条样式

### 3.3 响应式设计
- 确保在移动设备上正常显示
- 模态框自适应屏幕尺寸

### 3.4 性能优化
- 避免不必要的DOM操作
- 优化事件处理
- 确保流畅的用户体验

## 4. 风险与注意事项

1. **兼容性**：确保在主流浏览器中正常工作
2. **性能**：避免过多的DOM操作影响性能
3. **用户体验**：确保操作流畅，响应及时
4. **错误处理**：添加适当的错误提示和处理
