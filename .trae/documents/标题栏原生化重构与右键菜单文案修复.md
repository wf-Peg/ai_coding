# 标题栏原生化重构 + 右键菜单文案修复

## 一、Summary（概述）

分两个独立阶段落地：

1. **第 4 项：标题栏原生化重构（改动较大、回归面大）**
   用系统原生标题栏替换前端手写拖拽/仿分屏：macOS 用 `titleBarStyle: 'hiddenInset'`（保留红黄绿交通灯），Windows 用 `titleBarStyle: 'hidden'` + `titleBarOverlay`（系统自带最小化/最大化/关闭按钮）。拖拽统一改走 CSS `-webkit-app-region`，删除 JS 手写 pointer 拖拽与 window-drag 系列 IPC，以及"贴边仿分屏"。双击标题栏最大化由系统原生接管。两类平台各自去掉前端自绘窗口控制按钮。

2. **第 5 项：右键菜单（NSServices）文案修复**
   只修 `package.json` 中首个 `NSServices` 的乱码菜单名，并补充说明 Electron 下 NSServices 的送达局限；不做原生桥、不动 Windows 注册表逻辑。

> 决策记录：第 4 项按用户确认覆盖 macOS + Windows 双平台统一；第 5 项按用户确认"仅修文案 + 留现状"。

## 三、Proposed Changes（变更方案）

### 阶段 A：标题栏原生化重构（macOS + Windows 统一）

#### A1. `electron/main.js` — 窗口创建与拖拽清理

**位置**：`createMainWindow()`（L1958-1972）+ 窗口控制 IPC（L3448-3576）

1. 窗口选项按平台分支，替换 `frame: false`：
   ```js
   const isMac = process.platform === 'darwin';
   const isWin = process.platform === 'win32';
   ...
   width: 1200, height: 800,
   minWidth: 900, minHeight: 600,
   title: 'Clip',
   // macOS：系统原生标题栏，红黄绿交通灯以 hiddenInset 内嵌于左上；前端作为拖拽区。
   // Windows：隐藏标题栏 + 系统 Overlay 按钮（最小化/最大化/关闭），前端作拖拽区。
   titleBarStyle: isMac ? 'hiddenInset' : 'hidden',
   ...(isWin ? {
     titleBarOverlay: { color: '#2d2d2d', symbolColor: '#d4d4d4', height: 38 }
   } : {}),
   ```
   - macOS 不再设 `frame: false`（`titleBarStyle:'hiddenInset'` 自带原生框架与阴影/缩放角）。
   - Windows 用 `titleBarStyle:'hidden'` + `titleBarOverlay`，不设 `frame:false`。
   - 默认 `titleBarOverlay` 取暗色（与暗色主题一致）；亮色/蓝色主题下由 A3 的主题同步 IPC 实时校正，避免按钮底色与标题栏不符。

2. **删除**手写拖拽/仿分屏 IPC 与状态（现为死代码，重构后无引用）：
   - `window-drag-start`（L3487-3497）、`window-drag-move`（L3500-3545）、`window-drag-end`（L3548-3576）
   - `windowDragState = null`（L3484）
   - 同步删除 `preload.js` 的 `windowDragStart/Move/End`（L226-243）。

3. **保留** `window-minimize/maximize/close/is-maximized`、`set-fullscreen`、`onWindowMaximized`（虽有 native 按钮后不再由前端调用，但可能被托盘 / F11 / 兜底继续使用，做保守保留；若后续确认零引用可再清理）。

#### A2. `electron/preload.js` — 暴露平台与 Overlay 主题同步

**位置**：`window.electronAPI` 对象内

1. 增加 `platform: process.platform`，供 `index.html` 设置 `body` 平台类（mac/win 分平台 CSS）。
2. 增加 overlay 主题 IPC（仅 Windows 生效，macOS 上是 no-op）：
   ```js
   // 同步 titleBarOverlay 颜色，使系统按钮底色/符号色跟随当前主题
   setTitleBarOverlay: (overlay) => ipcRenderer.send('window-set-overlay', overlay),
   ```

#### A3. `electron/main.js` — 新增 `window-set-overlay` IPC

在窗口控制区域（L3448 附近）新增：
```js
// Windows 原生 Overlay 按钮的主题同步（macOS 无 Overlay，自动忽略）；随主题切换由前端调用
ipcMain.on('window-set-overlay', (event, overlay) => {
  if (process.platform === 'win32' && mainWindow && !mainWindow.isDestroyed()) {
    try { mainWindow.setTitleBarOverlay({
      color: overlay.color, symbolColor: overlay.symbolColor, height: 38
    }); } catch (e) {}
  }
});
```

#### A4. `frontend/index.html` — HTML / CSS / JS

1. **HTML**：删除自绘窗口控制按钮组 `#windowControls`（含 `btnMinimize/btnMaximize/btnClose`，L861-871）。macOS/Windows 均由系统按钮接管。
2. **CSS**：
   - `.titlebar`（L57）加 `-webkit-app-region: drag;`（整条标题栏可拖），并含交互区 `no-drag`（品牌/导航/全局搜索已具备）。
   - `.titlebar-spacer`（L139）去掉 `cursor: grab`（不再承载 JS 拖拽），保留 flex 占位即可。
   - 新增平台适配：
     - macOS（`body.platform-darwin`）：给 `.titlebar` 加左侧内边距（约 `padding-left: 76px`）为交通灯让位，避免品牌区被遮挡。
     - Windows（`body.platform-win32`）：给 `.titlebar` 加右侧内边距（约 `padding-right: 148px`），避免右侧内容（全局搜索）与右上 Overlay 按钮重叠（Overlay 宽约 138px）。
   - 删除暗含对 `#windowControls` 的样式（L138 附近"窗口控制按钮"块、L366 no-drag）。
3. **JS**：
   - 删除 `.titlebar-spacer` Pointer Events 拖拽处理器（L2021-2075）。
   - 删除标题栏 `dblclick→windowMaximize` 处理器（L2013-2019，双击改为系统原生 zoom/最大化）。
   - 删除 `#btnMinimize/Maximize/Close` 监听（L2008-2010）。
   - 删除最大化图标同步 `onWindowMaximized` 与 `windowIsMaximized` 图标切换（L2086-2101，系统按钮自带状态）。
   - **保留** `onWindowMaximized` 订阅不动（如需用于其它逻辑）；仅移除图标 DOM 切换。
   - 新增平台类与主题同步：
     ```js
     // 平台判断（供分平台 CSS）
     if (window.electronAPI && window.electronAPI.platform) {
       document.body.classList.add('platform-' + window.electronAPI.platform);
     }
     // Windows 下把 Overlay 按钮颜色同步到当前主题（亮/蓝/暗）
     function syncTitleBarOverlay() {
       const cs = getComputedStyle(document.getElementById('titlebar'));
       const color = cs.getPropertyValue('--titlebar-bg').trim() || '#2d2d2d';
       const txt = getComputedStyle(document.documentElement).getPropertyValue('--text').trim() || '#d4d4d4';
       window.electronAPI.setTitleBarOverlay({ color, symbolColor: txt });
     }
     // 应用加载与每次主题切换后调用 syncTitleBarOverlay()
     ```
   - 在现有"主题切换"的公共入口处一并调用 `syncTitleBarOverlay()`（跟随现有 `data-theme` 切换逻辑，用现有 postMessage 通知链即可）。

#### A5. 回归面与行为变化（重要，需向用户确认可接受）

- **macOS**：原生标题栏 + 原生拖拽 + 原生双击缩放；**失去"贴边仿分屏"**（macOS 本无边缘吸附，原生全屏/Split View 通过绿灯或 Option+拖拽实现）。
- **Windows**：**获得系统原生 Aero Snap**（`app-region:drag` 区拖到顶部/边缘由系统吸附），替代原自定义仿分屏；**移除右侧自绘按钮**，换系统 Overlay 按钮。
- 关闭到托盘（`close` 事件）、托盘恢复、`activate` 恢复逻辑均不受影响（native close 按钮同样触发 `close` 事件）。

## 四、Assumptions & Decisions（假设与决策）

1. **双平台统一**：macOS `hiddenInset`、Windows `hidden`+`titleBarOverlay`（用户已确认）。
2. **NSServices 仅修文案**：不进原生桥、不删无效项（用户已确认"仅修文案+留现状"）。
3. **移除"贴边仿分屏"**：macOS 失去自定义边缘吸附、Windows 改为系统原生 Aero Snap——视为重构目标行为，可接受。
4. **`#windowControls` 自绘按钮**在双平台删除（系统按钮接管）。
5. `titleBarOverlay` 默认暗色，亮/蓝主题由 `window-set-overlay` IPC 实时同步；macOS 该 IPC 为 no-op。
6. `window-minimize/maximize/close/is-maximized`、`set-fullscreen` IPC 与 `onWindowMaximized` 保留不删（可能有托盘/快捷键/F11 引用）；仅删确认为死代码的 window-drag 系列。
7. 编辑器/工作台 iframe 均在标题栏下方，其 `no-drag` 不受影响。
