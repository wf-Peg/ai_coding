# 写作模块打磨：树状文件浏览器（复刻 Obsidian 层级常驻）

## 背景问题（先回答「是否依赖 Obsidian」）

**结论：软件本身不依赖 Obsidian。** 写作区（ACE 编辑器）已具备直接打开/编辑 MD 的能力：md 语法高亮、`[[` 维基链接补全与反链、大纲、Ctrl+O 全局搜索、面包屑导航。Obsidian 只是可选的第三方查看器。

**真正的缺口**：现有文件树（`filetree-pane`）是**单级目录浏览**：
- 点文件夹=进入该目录、`..`=返回上级，无法一眼看到知识库完整层级；
- 与其他左抽屉（大纲/标签/反链/历史/最近/收藏）**互斥开关、不常驻**，每次都要手动唤起；
- 没有「知识库根」快捷定位，用户想快速看层级时只能去开 Obsidian。

本次打磨目标：把文件浏览器升级为 **Obsidian 风格的常驻树状层级侧栏**，写作区内部适配收纳/展开按钮。

### 已确认决策（用户拍板）
1. **数据来源**：复用 Electron `listDirectory` 前端递归懒加载树，默认根=知识库根（`storagePath`），保留「选择目录」任意浏览；**零后端改动**。
2. **常驻语义**：侧栏「标签页替换」—— 树是侧栏默认标签；其它左面板打开时临时替换树，关闭后树自动恢复显示。

## 方案设计

### 一、编辑器状态模型（editor.js）
新增/改造状态：
```
var explorerCollapsed = loadExplorerState();   // 侧栏整体折叠状态，localStorage: editor_explorer_state_v1，默认 false（常驻）
var fileTreeSuspended = false;                 // 树被其它面板临时顶替（非折叠）
var treeRootPath = null;                       // 当前树根（默认=知识库根 storagePath）
var expandedDirs = loadExpandedDirs();         // localStorage: editor_explorer_tree_v1（展开目录集合，cap 200）
```

### 二、面板开关逻辑改造（editor.js）
核心：**其它面板打开=临时顶替树；关闭=树自动恢复**。

1. `toggleFileTree()` 新语义（替换 L6568-L6587）：
   - 若有其它左面板正显示 → 切回树标签：`closeOtherLeftPanes('show-filetree')` + `setFileTreeVisible(true)`（不切换折叠状态）；
   - 否则 → 翻转 `explorerCollapsed` 并持久化：收起=隐藏树（`closeOtherLeftPanes('show-filetree')`），展开=`setFileTreeVisible(true)` 并加载树。
2. 新增 `setFileTreeVisible(open)`：统一设置 `fileTreePane.aria-hidden`、`fileTreeOpen`、`show-filetree` 类、状态栏按钮 active、`mainEditor.resize()`；打开时若树未初始化则 `loadFileTree()`。
3. `closeOtherLeftPanes(keepClass)`（L8865-L8895）改造：当 `keepClass !== 'show-filetree'` 时，除保留现有复位逻辑外，新增 `fileTreeSuspended = true` 标记（树是"被顶替"而非"被折叠"）。
4. 新增 `restoreFileTreeTab()`：若 `!explorerCollapsed && fileTreeSuspended && 无其它面板可见` → `setFileTreeVisible(true)`、`fileTreeSuspended=false`。
5. 在 6 个面板 toggle 的 **close 分支末尾**各加一行 `restoreFileTreeTab()`：history（~L7114）、recent（~L7341）、fav（~L7531）、backlinks（close 分支）、outline（L8909-L8912 after）、tags。
6. `toggleCompare(false)` 与 Markdown 预览退出路径（`toggleMarkdownPreview(false)`）末尾同样调用 `restoreFileTreeTab()`，保证从对比/预览模式回到正常态时树恢复（现有 CSS 在 comparing/markdown-preview 下 `display:none` 隐藏左面板）。

### 三、树状层级渲染（editor.js，核心重写）
将 `renderFileTree(files)` 单级列表替换为**递归懒加载树**：

1. `renderDirectoryNode(dirPath, containerEl, opts)`：
   - 先渲染「目录行」：chevron（▸/▾）+ 📁 + 目录名；点击 chevron/目录名 → 切换展开；
   - 展开时首次调用 `api.listDirectory(dirPath)` 获取子项，子目录递归渲染、文件渲染为叶子行；
   - 子级容器 `padding-left` 按深度递增（复用 `.indent-1..indent-5`，超过 5 级用内联 style 兜底）；
   - 已展开目录记录进 `expandedDirs` 并持久化，重开面板自动恢复展开态。
2. 保留 `..` 返回上级？**移除**——树形层级天然可上溯；根切换改由头部按钮完成。
3. 文件行：保留 `openFileTreeFile()`（新标签打开）与 `showFileTreeContextMenu()`（收藏/打开所在目录）右键行为。
4. 当前文件高亮：文件行 `path === state.displayPath` 时加 `.active` 类并 `scrollIntoView`（打开文件/切标签时刷新）。
5. `loadFileTree()`（L6589-L6627）改造为「根解析」逻辑：
   - 优先 `treeRootPath`（知识库根或手动选择）；
   - 首次（`treeRootPath==null`）：`api.getConfig()` 取 `storagePath` 作为知识库根；失败则回退当前文件父目录；仍失败则显示「选择目录」提示；
   - 浏览器模式（无 API）：保持现状提示「文件树仅桌面模式可用」，且默认不自动展开侧栏。

### 四、面板头部适配（editor.html + editor.js）
`filetree-pane` 头部（editor.html L182-L188）改造：
- 「选择目录」保留（切换树根为任意目录）；
- 新增 `#fileTreeHomeBtn`（🏠 知识库根）：`treeRootPath = storagePath` 并整树重建（Obsidian 式回根）；
- 新增 `#fileTreeRefreshBtn`（↻ 刷新）：清 `expandedDirs` 内存缓存并重建当前根（配合 fs 变更）；
- 「关闭」按钮复用 `#closeFileTreeBtn`，语义改为「收起侧栏」（调 `toggleFileTree()` 折叠并持久化）；
- 标题 `#fileTreeTitle` 显示当前根目录名/路径（`loadDirectory` 已更新，改为显示根名+可点回根）。

editor.js：`elements` 注册新增按钮（L95 附近加 `fileTreeHomeBtn/fileTreeRefreshBtn`），绑定事件。

### 五、样式（editor.css）
- `.filetree-item` 树形样式：chevron 旋转过渡、hover 背景、`.active` 当前文件高亮（用 `--app-primary` 12% 底 + 1px 圆角，深浅主题自适应，对齐既有的 ace_selected-word 同主题主色规范）；
- 目录行/文件行图标沿用 📁/📄 或换为线性 SVG chevron（跟随现有 `btn-icon` 风格，用 SVG 更细腻）；
- 头部新按钮复用 `.inline-btn` 与 `btn-icon`，配色跟随主题；
- 展开子容器缩进复用 `.indent-N`。

### 六、启动行为
- 桌面模式启动（DOM ready 后）：`explorerCollapsed` 为 false → `setFileTreeVisible(true)` + 加载知识库根树；
- 浏览器模式：不自动展开（与现状一致，避免空侧栏）。

## 假设与决策
- 树默认根=知识库根 `storagePath`（用户已确认数据来源方案）；
- 侧栏宽度维持 220px 不调整（避免滚动布局连锁改动）；
- 不引入 fs.watch 前端监听，用「刷新」按钮 + 常驻侧栏被动感知文件变化（保持轻量）；
- 树展开状态持久化到 localStorage（`editor_explorer_tree_v1`，上限 200 条防膨胀）；
- 面包屑定位（`openBreadcrumbDir`）继续可用：面板打开时切换到树根为目标目录（现有逻辑保留）。
