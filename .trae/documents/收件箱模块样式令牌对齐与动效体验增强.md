# 收件箱模块 — 样式令牌对齐 + 动效/交互体验增强

## Summary

收件箱模块（`clip.html` 剪藏列表页，含筛选器、列表项、快速记录、浮动操作栏、各类弹窗、空状态、toast）的样式已**大部分令牌化**，但存在三类残留：
1. **动效时长/曲线硬编码**：`ease-out`、`ease`、`ease-in-out` 及 `0.8s/0.9s/0.7s/0.6s/0.24s`、`cubic-bezier(0.4,0,0.2,1)` 未走令牌；
2. **主色蓝硬编码**：`rgba(86,156,255,…)` 出现 5 处，未用 `--app-primary` + `color-mix`；
3. **辅助色/灰阶硬编码**：`#555`、若干 `rgba(0,0,0,…)`、模 `rgba(0,0,0,0.5)` 遮罩未走令牌。

同时交互体验可增强：缺失 `prefers-reduced-motion` 无障碍支持、弹窗开关缺乏关闭动效、列表项/按钮缺少 `focus-visible` 焦点态、删除动效时长 240ms 与 CSS 令牌脱节。

目标：**无后端改动、纯前端**，把收件箱核心 surface 的动效/颜色全部收敛到 `--app-*` 令牌，并补齐动效交互的友好性（无障碍 reduced-motion + 焦点态 + 弹窗开关动效）。范围聚焦收件箱模块文件，不动编辑器/写作/知识库。

## 拟定改动（文件 + 做什么 + 为什么 + 怎么做）

### 1. `frontend/styles/design-tokens.css`（补充缺失令牌，1 处）
- 增加 `--app-ease-sharp: cubic-bezier(0.4, 0, 0.2, 1);`（底部 `--app-duration-slow` 附近、`--app-ease-spring` 旁）。
- 增加 `--app-scrim: rgba(0, 0, 0, 0.5);`（若项目其他页已定义同名遮罩则复用，避免重复）。
- **为什么**：本模块 3 处使用的锐切曲线与弹窗遮罩目前无令牌载体，先立规再替换。

### 2. `frontend/styles/clip.css`（核心：对齐 + 无障碍 + 动效精简）
把下列硬编码值替换为令牌：
- L81 / L426：`… ease-out` → `var(--app-ease-out-expo)`（曲线入窗用 expo，契合弹窗/面板弹出感）。
- L168：`0.8s ease-out` → `var(--app-duration-slow) var(--app-ease-smooth)`（降冗长首动画到 300ms）。
- L359：`0.9s ease-in-out infinite` → `calc(var(--app-duration-slow) * 3) var(--app-ease-in-out-expo) infinite`。
- L1132：`left 0.7s ease` → `left var(--app-duration-normal) var(--app-ease-smooth)`（若此过渡本身跨度大、缩短会影响手感，退回 `var(--app-duration-slow)`）。
- L1362 / L1402：`… normal ease` → `… normal var(--app-ease-smooth)`。
- L1220 / L1314：`cubic-bezier(0.4,0,0.2,1)` → `var(--app-ease-sharp)`。
- L1248：`checkPop … cubic-bezier(0.4,0,0.2,1)` → `checkPop var(--app-duration-panel) var(--app-ease-sharp)`。
- L1483：`0.24s` → `var(--app-duration-panel)`（与 panel 250ms 一致）。
- L1423：`0.6s linear infinite` → `calc(var(--app-duration-panel) * 2) linear infinite`。
- 主色蓝（L1230/1237/1287/1292/1369）→ `color-mix(in srgb, var(--app-primary) X%, transparent)`，X 比例保持原透明度（0.08→14%? 按 `14%≈0.14/1`；0.15→22%、0.2→28%、0.3→40% 就近取整，与 L1472 同风格），阴影内的主色含灰统一改为 `color-mix(in srgb, var(--app-primary) 18%, transparent)`。

- L64 遮罩：`rgba(0,0,0,0.5)` → `var(--app-scrim)`。

**新增动效/无障碍规则**（追加到文件末尾，命名带收件箱语义或通用）：
- 全局：`@media (prefers-reduced-motion: reduce)` 块内将动画/过渡时长归零或关闭（`*{animation-duration:… !important; animation-iteration-count:1 !important; transition-duration:…}`），静默关闭循环动画（`wcSyncPulse/floatBarSpin`）。

## 假设与决策

- **假设**：收件箱模块 = 剪藏列表页全部样式，以 `clip.css` 为唯一样式载体；动效改动不得改变各交互的既定行为（尤其删除仍保持"淡出右移后刷新"）。
- **决策**：曲线收敛优先用 `--app-ease-smooth` / `--app-ease-out-expo`，新增 `--app-ease-sharp` 用于列表勾选/展开这类"干脆"反馈；循环动画（syncing/浮栏 spin）保持循环但时长令牌化。
- **决策**：无障碍 reduced-motion 与 focus-visible 属"产品体验友好性增强"，是用户明确要求的一部分，纳入本次。
- **决策**：不做任何后端改动；不调整收件箱信息架构/文案（空状态文案等已合规）。
