# 头部菜单栏评估与单栏优化设计方案

## 一、Summary（概述）

对应用顶部菜单栏（`frontend/index.html` `.titlebar`：品牌区 / 后端指示器 / 导航区 / 全局搜索）做设计评估，识别可借鉴优化点，并按**方向 A：单栏信息分层优化**输出设计方案。

- 评估结论：当前单栏存在**信息过载、导航层级扁平、后端按钮技术化、缺全局命令面板、头部与内容脱节**等问题。
- 设计方向（用户已确认）：A 单栏优化——不引入侧边栏/活动栏，在 38px 单栏内做信息分层。
- 产出范围（用户已确认）：**仅评估与设计文档，不实施**。文档内给出具体文件/样式/交互改动点，供后续排期执行。

## 三、评估结论（问题清单）

### 值得保留的亮点

1. 系统原生标题栏（拖拽/双击最大化/平台留白）已达标，**不回归**。
2. 搜索胶囊「150→210px 聚焦展开 + ⌘⇧F 徽章」交互合理，**保留**。
3. 导航项图标+文字、active 下划线、全部走主题变量（`--app-*`），视觉一致性好。
4. 后端状态点含渐变/脉冲动画，状态可视化有基础。

## 四、Proposed Design（方向 A：单栏信息分层优化）

### A1 品牌区压缩

- **目标**：品牌区从 ≈130px 收到 ≈56px，给导航让位。
- **改动**（`frontend/index.html` CSS L61-85）：
  - 保留 18px logo（视觉锚点），去掉文字「碎碎记」，仅保留 logo + tooltip「碎碎记 CutShelter」；或文字缩至 0.75rem 且隐藏 `<small>CutShelter</small>`。
  - 决策：**默认方案为纯图标（保留 tooltip）**；若偏好品牌文字，退化为「0.78rem 单行 + 隐藏 CutShelter」。
- **交互**：点击品牌区无操作（或后续可承载「关于」），hover 显示 tooltip。

### A2 后端状态自动化 + 视觉收敛

- **目标**：正常使用中后端指示器只占 ≈16px（状态点），「启动后端」按钮仅异常态出现。
- **改动**：
  - **HTML**（L791-795）：结构不变（dot + label + start-btn）。
  - **CSS**（L594-648）：
    - `label` 默认 `display:none`，仅 `.starting/.error/.stopped` 态显示；
    - `.ready` 态仅剩状态点 + 悬浮 tooltip（「后端服务正常」）；去掉 READY 态 label，不显示技术文案。
    - `.stopped`/`.error` 态保留「启动后端」按钮（现有 `.show-start` 机制不动）。
  - **JS**（`setGlobalBackendState` L1758-1779）：`READY` 时 label 置空、title 置「后端服务正常」；`frontend-async-backend` 已自动拉起，无需用户干预。
- **决策**：不新增"自动启动开关"，沿用现有 `frontend-async-backend` 模式；仅收敛视觉与文案。若未来 `frontend-only` 为默认，则在启动时先探测 `isBackendRunning`（已有 L1999-2006）再决定是否显示按钮。

### A3 导航分组 + 溢出菜单

- **目标**：一级导航稳定为「5 主入口 + 1 溢出按钮」，pinned 子模块收入「⋯」菜单。
- **改动**：
  - **HTML**：`.titlebar-nav` 尾部新增 `.nav-more` 按钮（`⋯`，icon-only，`data-view` 无）与 `.nav-more-menu` 下拉面板（绝对定位，复用 `gsearch-panel` 视觉：圆角 10px + 阴影 + 主题变量）。
  - **JS**（`applyHeaderNav` L1517-1547 改造）：
    - 主入口（`FIXED_HEADER_VIEWS`）渲染进 `titlebarNav`（不变）；
    - pinned 子模块**不再插入导航条**，改为渲染进溢出菜单容器（图标 + label + 选中态）；
    - 溢出菜单键盘导航复用 `gsearch` 的 `setActive` 模式（↑↓ 选择 / Enter 执行 / Esc 关闭）。
  - **交互**：点击 `⋯` 展开/收起；点击外部或 Esc 关闭；当前激活模块在菜单内高亮。
  - **决策**：pinned 子模块**始终**收入溢出菜单（不按宽度条件切换），保证一级导航恒为 ≤6 项。
- **范围说明**：`navHeaderTools` 配置与 `PINNABLE_NAV` 定义（L1509-1516）不变，仅渲染目标从导航条改为溢出菜单——一份配置两处复用（A3 菜单 + A4 命令面板）。

### A4 全局命令面板（⌘K）

> **与全局搜索（⌘⇧F）的区别**：⌘⇧F 搜**内容**（剪藏/知识/学习计划/密码条目，跳转具体记录）；⌘K 搜**动作**（模块跳转、新建文档、打开设置、启动后端、切主题、最近文档）。⌘⇧F = 找资料；⌘K = 操作应用。

- **目标**：提供键盘流全局操作入口，缓解导航拥挤。
- **改动**：
  - **HTML**：`index.html` 新增 `.global-cmd-palette` 面板（居中弹层），结构对齐 `editor.html` 命令面板：`input` + `list` + 底部 `↑↓ 导航 · Enter 执行 · Esc 关闭` 提示（复用 editor.css L3942-4035 的视觉语言，样式迁移至 `index.html` 内联 CSS，避免跨页样式耦合）。
  - **快捷键**：`⌘K`（macOS）/ `Ctrl+K`（Windows），`platformShortcut` 模式注册；Esc 关闭。
  - **命令源**（运行时生成，无硬编码重复）：
    1. **模块跳转**：`FIXED_HEADER_VIEWS` 5 项 + `PINNABLE_NAV` pinned 子模块（与 A3 同源配置）。
    2. **常用动作**：新建编辑器文档、打开文件、保存、聚焦全局搜索、启动后端（后端非 ready 时）、切换主题（亮/蓝/暗）、打开设置、快捷键帮助。
    3. **最近文档**：取编辑器最近记录（前 5 条）。
  - **JS**：`openGlobalCmdPalette()/closeGlobalCmdPalette()/renderCmdItems()` + 过滤 + `setActive` 键盘导航（参考 `renderGlobalSearch` L2331-2400）。
  - **入口**：⌘K 快捷键 + 搜索胶囊旁新增 ⌘K 图标按钮（`.gsearch` 附近，icon-only）。

### A5 当前上下文显示（P3，可选开关）

- **目标**：编辑器视图下头部感知当前文档。
- **改动**：
  - `editor.js` 在文档切换/保存状态变化时 `window.parent.postMessage({ action:'editorContext', title, modified })`（已有 postMessage 通道，扩展一个消息类型）。
  - `index.html` `.titlebar` 在 `.titlebar-spacer` 位置叠加 `.ctx-label`（模块名 + 文档名 + 未保存点），非编辑器视图显示模块名或不显示。
- **决策**：本次设计包含此能力，实施时设默认**开启**（仅编辑器视图），可通过常量关闭。

### A6 细节与响应式

- 导航项间 `gap: 2px → 4px`，品牌区 padding 收窄，增加可拖空隙。
- `@media (max-width: 768px)`（L500-512）：`nav-label` 隐藏（icon-only），溢出菜单保留，⌘K 按钮保留。
- 所有新增样式使用现有主题变量（`--app-*` / `--primary` / `--panel-border`），不新增色值；动画时长对齐 `--app-duration-fast/normal`（0.12s/0.2s）、缓动 `--app-ease-smooth`。

## 五、Assumptions & Decisions（假设与决策）

1. 采用**方向 A 单栏优化**，不引入侧边栏/活动栏（用户已确认）。
2. 本次**仅输出设计文档，不实施**（用户已确认）。
3. 一级导航恒为「5 主入口 + 1 溢出按钮」；pinned 子模块始终收进溢出菜单。
4. ⌘K（动作）与 ⌘⇧F（内容搜索）职责分离、并存；命令面板不替代搜索。
5. 后端自动拉起沿用 `frontend-async-backend`；「启动后端」按钮仅 stopped/error 态出现。
6. macOS 76px / Windows 148px 平台留白、系统原生拖拽、关闭到托盘等**保持不动**。
7. A5 上下文显示为设计项，实施默认开启、可关闭。
8. 品牌区默认纯图标 + tooltip；如偏好文字品牌再退化方案。
