# 字体模块设计方案（写作模块编辑区 + 预览区）

## 一、Summary（目标）

当前写作模块编辑器（ACE）只有「字体大小」可调，`font-family` 沿用的是全局 `--app-font`（IBM Plex Sans / Noto Sans SC），中文渲染不够美观。本方案新增一个**字体模块**：在编辑器设置弹窗里提供一个「字体」下拉选择，内置数款精选开源 CJK 字体，通过 `@font-face` 打包进应用离线可用，选择后同时作用于 **编辑器编辑区 + Markdown 预览区**。

按用户确认：
- 生效范围 = 编辑区 + 预览区（写作模块内，不动全局其它页面）
- 字体来源 = 打包开源字体（离线一致、保证颜值）
- 入选方向 = 楷体、宋体/衬线、黑体/无衬线、等宽混排 四类都要

## 二、Current State Analysis（现状）

- 编辑器为 **ACE editor**，在 [editor.js](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/js/editor.js#L440-L460) 的 `createEditor()` 初始化，仅设置 `fontSize:'13px'`，未设置字体族（继承全局）。
- 全局字体 token 定义于 [design-tokens.css](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/styles/design-tokens.css#L51-L53)：`--app-font`（正文）与 `--app-font-mono`（等宽）。
- 编辑器设置弹窗在 [editor.html](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/editor.html#L580-L630)，「基本」页有「字体大小」滑块（`fontSizeSlider`）和「缩进」选择，无字体族选项。
- 编辑器偏好均以 `localStorage` 持久化（如外观 `APPEARANCE_KEY`、缩放 `MD_ZOOM_KEY` 等），字体选择沿用此惯例新增一个 key。
- Markdown 预览容器 class 为 `.markdown-preview`（[editor.js](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/js/editor.js) 通过 `editorWorkspace` 切换 `markdown-preview` class）。
- 当前仓库**未打包任何字体文件**（`frontend/**` 无 ttf/otf/woff/woff2）。

关键实现注意点：
- ACE 自带的 `ace.css` 会在 `.ace_editor` 上设置一套 `font-family`（Monaco/Consolas 等），会覆盖继承值，所以必须显式给 `.ace_editor` 设族名（用更高优先级/加载顺序/`!important` 兜底）。
- 浏览器只有某 `@font-face` 族名**真正被渲染使用**时才会下载该字体文件 —— 天然按所选字体懒加载，无需额外逻辑，符合「轻量低占用」。

## 三、字体候选清单（Review 修正版）

从 GitHub / 官方 / 社区评测收集，全部免费可商用。2025-2026 新增系统级黑体（MiSans/HarmonyOS Sans/HONOR Sans）在屏幕锐利度、可变字重、体积上普遍优于思源黑体，故黑体主力位需替换。

按四类方向精挑如下：

| 方向 | 首选 | font-family 族名 | 仓库/来源 | 入选理由 |
|------|------|------------------|-----------|----------|
| 黑体/默认正文 | **MiSans** | `MiSans` | hyperos.mi.com/font | 10 字重可变、屏幕锐利、iF/红点奖、GB18030-2022 覆盖，替代思源黑体 |
| 黑体（备选） | HarmonyOS Sans / HONOR Sans | `HarmonyOS Sans` / `HONOR Sans` | 华为 / 荣耀官方 | 屏幕阅读优化；HONOR 中宫可变、9 字重，阅读感强 |
| 楷体 | **霞鹜文楷 Screen / Lite** | `LXGW WenKai Screen` | github.com/lxgw/LxgwWenKai | 文艺手写风，中短文本/诗词/日记佳；**非大段正文默认** |
| 宋体/衬线 | 思源宋体 SC（子集化）或霞鹜新致宋 | `Source Han Serif SC` | github.com/adobe-fonts/source-han-serif | 典雅纸感、长文舒适；优先轻量变体 `LXGW Neo ZhiSong` |
| 等宽混排 | **更纱黑体 SC Mono** | `Sarasa Mono SC` | github.com/be5invis/Sarasa-Gothic | 中文等宽混排最成熟，代码/技术笔记利器 |
| 等宽（备选） | Maple Mono CN | `Maple Mono CN` | github.com/subframe7536/maple-font | 圆角现代、内置 Nerd Font |

### 关键取舍（务必压实）
1. **黑体主力从思源黑体 → MiSans**：思源黑体完整包 ~95MB、低分屏小字号发虚、Windows 安装后名称碎片化，不适合做编辑器正文默认。MiSans 更锐利、体积更可控。
2. **霞鹜文楷定位纠正**：作者 README 自述其「适合诗词等中短文本，不太适合大段正文阅读」，故仅作「文艺风格」可选项，**不是默认字体**；且选 Screen/Lite 轻量版（标准版 77MB 偏重）。
3. **体积策略（硬约束）**：全量 CJK 每款 60-100MB，5 款全装违背「轻量低占用」偏好。必须对中文做 **GB2312 一级常用字子集化**（约 3-6MB/款，缺失生僻字回落系统字体），或首期只内置 2-3 款。`font-display: swap` 保证首屏不阻塞；未被选中的字体族浏览器不下载，天然懒加载。

## 四、Proposed Changes（具体改动）

### 1. 新建字体目录与 @font-face
- 新建目录 `frontend/fonts/`，放入所选字体的 **woff2** 文件（子集化后，命名语义化，如 `misans.woff2`、`lxgw-wenkai-screen.woff2`、`source-han-serif-sc.woff2`、`sarasa-mono-sc.woff2`、`maple-mono-cn.woff2`）。
- 新建 `frontend/fonts/fonts.css`，为每款字体声明 `@font-face`（含 `font-display: swap;`、正确 `font-weight: 400` 等）。

### 2. 引入字体样式
- 在 [editor.html](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/editor.html) 中 `<link rel="stylesheet" href="fonts/fonts.css">`。

### 3. 新增写作字体 CSS 变量
- 在 [editor.css](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/styles/editor.css)（或 design-tokens.css）新增：
  - `--app-writing-font`（默认 = 现有 `--app-font` 栈，保证未选时行为不变）。
  - 规则：`.ace_editor, .markdown-preview { font-family: var(--app-writing-font) !important; }`（`!important` 覆盖 ACE 自带字体族）。字号仍由 ACE `setFontSize` 控制，逻辑不变。

### 4. 设置弹窗加「字体」下拉
- 在 [editor.html](file:///l:/归档/30_Projects (行动项目)/31_Work (主要工作)/code/ai_coding/frontend/editor.html#L596) 「字体大小」上方插入一个字段：`<label>字体</label>` + `<select id="fontFamilySelect">`，选项含「默认/跟随主题」及上述候选（默认正文 = MiSans，其余按四类方向分组展示）。

### 5. 前端逻辑（editor.js）
- 新增常量 `FONT_FAMILY_KEY = 'editorFontFamily'`（沿用 localStorage 惯例）。
- 初始化：读取 `FONT_FAMILY_KEY`，无则用 `--app-writing-font` 默认栈；写入 `settingsModal` 打开时同步 select 选中态（参考现有 L5866-L5874 同步逻辑）。
- 定义 `applyWritingFont(family)`：设置 `--app-writing-font` 到 `document.documentElement` 的 style（或切换编辑器容器属性），使 `.ace_editor` 与 `.markdown-preview` 同时生效；`localStorage.setItem(FONT_FAMILY_KEY, family)`。
- 下拉 `change` 事件绑定 `applyWritingFont`；并在初始化、每个新标签创建、预览打开时统一调用（保证新打开的文件/预览也继承所选字体）。
- 在 `elements` 数组（L94）注册 `fontFamilySelect`。

### 6. 与字体大小联动保持
- 现有 `setFontSize` 钩子（L4187-L4190）与滑块/快捷键逻辑**不修改**，字重/行高沿用 ACE 主题。

## 五、Assumptions & Decisions（假设与决策）

- 字体选择仅写作模块（编辑区+预览区）生效，**不改**全局 `--app-font`，避免影响其它页面观感。
- 持久化沿用 `localStorage`（与现有编辑器偏好一致），不使用后端 config。
- 默认保持原字体，用户显式选择才切换，避免升级后视觉突变。
- 字体文件需人工/后续脚本从开源仓库下载并子集化；本轮先打通「选择→应用→持久化→预览联动」全链路，字体文件落地方式（全量 SC 变体 vs 子集化）以安装体积为准择一。

## 六、Verification（验证步骤）

1. 启动前端（3001）/后端（8081），打开写作模块编辑一个 `.md` 文件。
2. 设置弹窗「字体」下拉显示「默认 + 各方向候选」；切换任意字体，**编辑区**文字立即改变且字形贴合所选（MiSans=现代黑体、文楷=手写楷、思源宋=衬线、更纱/Monospace=等宽）。
3. `Ctrl+Shift+M` 打开 Markdown 预览，预览区字体与编辑区一致。
4. 关闭并重开编辑器，字体选择被记住（localStorage `editorFontFamily`）。
5. 新建标签 / 打开另一文件，字体保持一致。
6. 切回「默认/跟随主题」，还原为原 `--app-font` 栈，无回归。
7. 主题四态（默认/深色/Notion/跟随系统）下切换字体均正常，无乱码、无缺字方块；生僻字回落到系统字体无方块。
8. （可选）确认未选中字体在 DevTools Network 中不加载（懒加载生效）。

## 附：需要用户配合的决定
- **体积策略（首期推荐）**：黑体主力选 **MiSans**（子集化后 ~3-6MB），楷体选 **霞鹜文楷 Screen/Lite**，等宽选 **更纱黑体 SC Mono**；宋体（思源宋体 SC）为可选第四款。首期先做「MiSans + 霞鹜文楷 Screen + 更纱黑体 SC」三款即可满足覆盖，其余（HONOR Sans / Maple Mono / 思源宋体）留作后续追加。
- **子集化范围**：GB2312 一级 ~3755 常用字 + 应用内常见词，缺失生僻字回落系统字体。若需完整生僻字/学术用途，再切换为全量 SC 变体（体积显著增大）。
