# 标题栏：恢复自绘窗口按钮 + 修复顶部 titlebar 溢出

## 一、Summary（概述）

针对顶部 titlebar 长期存在的两个问题做整改：

1. **右上角「缩小/放大/关闭」样式独立、未整合为整体**：根因是此前「标题栏原生化重构」让 Windows 改用了系统原生 `titleBarOverlay` 按钮，按钮由系统绘制，无法贴合前端主题做平滑 hover，形成「独立区域感」。
2. **titlebar 区域时常超出显示区（各种页面、或切出应用再切回后出现）**：根因是 `titleBarStyle:'hidden'` + `titleBarOverlay` 的系统按钮高度与设备像素缩放（DPI）在 `height:100vh/calc(100vh - var(--titlebar-height))` 计算下错位。

**决策**（用户已确认）：Windows 恢复**前端自绘窗口按钮**（`frame:false` + 自绘最小化/最大化/关闭），完整融入主题与 hover 动画；Aero Snap 由 `-webkit-app-region: drag` 继续保留；同时因自绘按钮完全由前端掌控，消除 DPI 错位导致的溢出。

## 三、Proposed Changes（变更方案）

### 1. `electron/main.js` — Windows 窗口回到无边框自绘（**macOS 分支不动**）

**位置**：`createMainWindow()`（L2474-2490）

- 仅 Windows：删除 `titleBarStyle:'hidden'` 与 `titleBarOverlay`，Windows 改为 `frame:false`（无系统标题栏，由前端自绘按钮接管）。仍然保留 `-webkit-app-region: drag` 拖拽能力，Aero Snap 由系统吸附接管。
- **macOS 分支保持不变**：继续用 `titleBarStyle:'hiddenInset'`（系统交通灯内嵌左上），不设 `frame:false`，系统红黄绿按钮由系统绘制、天然贴合前端主题外观，不参与本次改造。
- 推荐集成分平台判定，示例（替换 L2480-2482）：
  ```js
  // macOS：系统原生标题栏，红黄绿交通灯以 hiddenInset 内嵌左上，不作为改动对象。
  // Windows：无边框 + 前端自绘最小化/最大化/关闭按钮（融入主题、消除 DPI 错位溢出）。
  const winFrameless = isWin ? { frame: false } : {};
  const winStyle = isWin ? {} : { titleBarStyle: 'hiddenInset' };
  ```
  并展开到窗口对象：`...winFrameless, ...winStyle`。

**保留不动**：`window-minimize/maximize/close/is-maximized`、`window-maximized` 广播、`window-set-overlay` IPC（转 no-op 即可，或暂时保留无碍；前端自绘后不再调用 `setTitleBarOverlay`）。

### 2. `electron/preload.js` — 停用 Overlay 同步（可选清理）

- `setTitleBarOverlay`（L261）保留（不再调用即可）；或删除不必要，保留更稳妥，无需改动主进程 `window-set-overlay`。**macOS 相关无需改动。**

#### 3.2 CSS：窗口控制按钮外观（融入 `.titlebar` 整体）

- `.window-controls`：`display:flex; align-items:stretch; height:100%; flex:none; -webkit-app-region:no-drag; margin-left:auto`（在 flex 内自然靠右）。
- `.win-btn`：宽约 46px、高 `100%`、无边框、透明底、`var(--text-secondary)` 图标色、`transition: background/color`，hover 用 `--win-btn-hover`，close hover 用 `--win-btn-close-hover`（`#e81123`）。图标 `stroke:currentColor; stroke-width:1`。
- **平台处理（分平台，非同写）**：
  - Windows（`body.platform-win32`）：显示 `.window-controls`，按钮组在 `.titlebar` 右侧最右端（`margin-left:auto`）。
  - macOS（`body.platform-darwin`）：**隐藏整个 `.window-controls`**（`display:none`），右上角无前端按钮——macOS 继续用系统红黄绿交通灯（`hiddenInset` 内嵌左上），系统按钮天然贴合主题，不做自绘圆点，维持现状。
- 删除 `body.platform-win32 .titlebar { padding-right: 148px }`（不再为系统 Overlay 让位）；改由 `.window-controls` 在 flex 内自然占位居右。

#### 3.3 JS：按钮行为 + 最大化图标同步

在现有所需的初始化函数内新增（复用现有 IPC）：

```js
function initWindowControls() {
  const minBtn  = document.getElementById('btnMinimize');
  const maxBtn  = document.getElementById('btnMaximize');
  const closeBtn = document.getElementById('btnClose');
  const isMac = (window.electronAPI.platform === 'darwin');
  // macOS 由系统交通灯接管，隐藏自绘按钮
  if (isMac) { if (windowControls.parentNode) windowControls.remove(); return; }

  minBtn.addEventListener('click', () => window.electronAPI.windowMinimize());
  maxBtn.addEventListener('click', () => window.electronAPI.windowMaximize());
  closeBtn.addEventListener('click', () => window.electronAPI.windowClose());
  // 最大化/还原图标切换
  const iconMax = maxBtn.querySelector('.icon-max');
  const iconRestore = maxBtn.querySelector('.icon-restore');
  function syncMaxIcon(m) {
    iconMax.style.display = m ? 'none' : '';
    iconRestore.style.display = m ? '' : 'none';
  }
  window.electronAPI.onWindowMaximized(syncMaxIcon);
  window.electronAPI.windowIsMaximized().then(syncMaxIcon);
}
```

- 将 `syncTitleBarOverlay()` 停用（不再需要系统 Overlay 颜色同步）。**macOS 分支的 `syncTitleBarOverlay()` 同样停用不影响现状（其系统交通灯不依赖它）。**

### 4. `frontend/styles/editor.css` 等 — 无改动

编辑器/工作台等 iframe 均在标题栏下方，`app-region: drag` 不越界，不受影响。

## 四、Assumptions & Decisions（假设与决策）

1. Windows 自绘三按钮，**macOS 由系统交通灯接管、前端完全隐藏 `.window-controls`、不改动任何窗口配置**（沿用 `hiddenInset`），避免双套按钮与 mac 回归。
2. Aero Snap 由 `-webkit-app-region: drag` 保留，不受 Windows `frame:false` 影响。
3. UI 尺寸：`--titlebar-height:38px` 不变；按钮组 46px×38px，贴合 Windows Overlay 物理尺寸。
4. 溢出根因消除：自绘按钮后无系统 Overlay 参与，`.titlebar` 高度与 `calc(100vh - 38px)` 完全由前端掌控，不受 DPI 缩放错位影响。
5. 保留 `window-minimize/maximize/close/is-maximized`、`window-maximized` 事件、`window-set-overlay` 与 `setTitleBarOverlay`（不再调用，保守保留）。
