# 剪藏上传图片删除按钮「横向变形」修复方案

## 概述（Summary）

剪藏模块中，上传图片缩略图右上角的删除（关闭）按钮使用文本字符「✕」(U+2715) 渲染，该字符在很多字体中缺字，浏览器会回退到系统中文字体（如微软雅黑/Segoe UI Symbol），导致字形横向溢出 20px 圆形按钮，出现「横向变形」。

**完美解决方案**：改用内联 SVG 关闭图标 + flexbox 居中。SVG 与字体无关，跨平台渲染完全一致、永不变形、任意 DPI 下清晰，且与项目现有图标风格（`stroke="currentColor" stroke-width="2"`，如 vault.html）保持一致。

## 现状分析（Current State Analysis）

### 触发点（2 处渲染 + 2 处样式）

| 文件 | 位置 | 内容 |
|------|------|------|
| `frontend/js/clip-shared.js` | L398 | `renderImagePreviews()` 内生成 `<button class="preview-remove">✕</button>` |
| `browser-extension/clip-main.js` | L1519 | 浏览器扩展版相同逻辑 |
| `frontend/styles/clip.css` | L2301-2318 | `.preview-remove` 样式 |
| `browser-extension/clip.html` | L1750-1767 | 浏览器扩展版样式 |

### 变形根因

当前按钮样式：

```css
.image-preview-item .preview-remove {
    position: absolute;
    top: 3px; right: 3px;
    width: 20px; height: 20px;
    border: none;
    border-radius: 50%;
    background: rgba(0,0,0,0.5);
    color: #fff;
    font-size: 0.72rem;   /* ~11.5px */
    line-height: 20px;    /* 依赖字体行高，脆弱 */
    text-align: center;
    cursor: pointer;
    padding: 0;
    transition: background var(--app-duration-fast) ease;
}
```

1. 「✕」(U+2715) 不属于多数西文字体，浏览器按字形回退到系统字体，其 advance width 常大于 20px，字符横向溢出圆钮边界 → 视觉上「横向变形」。
2. 垂直居中依赖 `line-height: 20px` + `text-align: center`，不同字体基线不一致，位置漂移。
3. 未显式指定 `font-family`，渲染结果随平台/主题字体漂移。

## 变更方案（Proposed Changes）

### 1. 主应用渲染层 — `frontend/js/clip-shared.js` L398

将文本「✕」替换为内联 SVG 关闭图标（两条交叉线，视图 16×16，描边 2px，随 `currentColor` 变色）：

```html
<button type="button" class="preview-remove" data-id="..." title="移除图片（同时移除内容引用）">
  <svg viewBox="0 0 16 16" width="10" height="10" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" aria-hidden="true">
    <path d="M3 3l10 10M13 3L3 13"/>
  </svg>
</button>
```

改动点（保持 `data-id` / `title` / class 不变，仅替换按钮内容）：

```js
inner += '<button type="button" class="preview-remove" data-id="' + entry.localId + '" title="移除图片（同时移除内容引用）">'
    + '<svg viewBox="0 0 16 16" width="10" height="10" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" aria-hidden="true"><path d="M3 3l10 10M13 3L3 13"/></svg>'
    + '</button>';
```

### 2. 浏览器扩展渲染层 — `browser-extension/clip-main.js` L1519

与第 1 步完全相同的替换。

### 3. 主应用样式 — `frontend/styles/clip.css` L2301-2318

`.preview-remove` 改为 flexbox 居中，去掉 `font-size/line-height/text-align` 的文本居中依赖，新增 SVG 尺寸规则：

```css
/* 删除按钮 */
.image-preview-item .preview-remove {
    position: absolute;
    top: 3px; right: 3px;
    width: 20px; height: 20px;
    border: none;
    border-radius: 50%;
    background: rgba(0,0,0,0.5);
    color: #fff;
    display: flex;
    align-items: center;
    justify-content: center;
    cursor: pointer;
    padding: 0;
    transition: background var(--app-duration-fast) ease;
}
.image-preview-item .preview-remove svg {
    display: block;
    width: 10px;
    height: 10px;
}
.image-preview-item .preview-remove:hover {
    background: rgba(220,38,38,0.9);
}
```

> 说明：`fill="none"` 与 `stroke="currentColor"` 保证深/浅色主题下均显示白色叉号；hover 红色背景逻辑保持不变；`aria-hidden="true"` 避免无障碍读屏误读图标（按钮已带 `title`）。

### 4. 浏览器扩展样式 — `browser-extension/clip.html` L1750-1767

与第 3 步相同的 CSS 替换（`transition` 保持 `0.15s ease`，扩展版无 `--app-duration-fast` 变量）。

## 假设与决策（Assumptions & Decisions）

- **采用 SVG 方案而非仅修 CSS**：用户明确要求「重新设计下，给个完美的解决方案」。SVG 图标从根源消除字形回退导致的变形，且与项目现有图标风格统一。CSS 修补（如强制 font-family）仍依赖字体表现，无法根治。
- **图标尺寸 10px**：20px 圆钮内留 5px 边距，视觉舒适、不挤压；两条线用 `stroke-linecap="round"` 圆头更精致。
- **不改变按钮的交互与事件委托逻辑**：`class="preview-remove"`、`data-id`、点击委托（`closest('.preview-remove')`）均不变，删除/重试行为零影响。
- **两套代码同步修改**：主应用（Electron）与浏览器扩展版共用同一套 class 与交互，保持一致避免后续维护分叉。
- **不改 HTML 模板中的其他关闭按钮**：任务范围仅限上传图片缩略图的删除按钮。

## 验证步骤（Verification）

1. **语法检查**：改动后分别检查 `clip-shared.js`、`clip-main.js` 的 JS 语法（`node --check`），确认字符串拼接无误。
2. **主应用运行验证**：
   - 启动前后端服务，打开剪藏页面。
   - 通过「上传图片」按钮与 Ctrl+V 各上传一张图片。
   - 观察缩略图右上角删除按钮：呈正圆、叉号居中、不横向溢出、无变形。
   - 点击删除按钮：图片预览消失，`content` 区对应 `![图片](xx.png)` 引用同时被移除（回归验证）。
   - 深色主题下再次验证按钮显示正常。
3. **浏览器扩展验证**：加载扩展后重复第 2 步，确认行为与样式一致。
4. **hover 态回归**：鼠标悬停按钮变红，点击响应正常。
