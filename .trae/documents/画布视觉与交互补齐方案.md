# 画布「视觉 + 交互」补齐方案（对标 NoteGen 画布体验）

## Summary

用户反馈：画布模块对比 NoteGen 差距大、样式交互一般。经调研，**NoteGen 源码不可移植**（GPL-3.0 传染闭源项目 + React/Tiptap/radix 技术栈与原生 JS 不兼容），延续项目一贯做法：**仅借鉴其与框架无关的交互与视觉，用原生 JS/D3 自行实现**。

本轮范围（用户已确认）：**视觉质感升级 + 交互补齐**，不做 AI 能力（自动布局 / Mermaid 生成），不改数据语义，**数据层零改动**。

---

## 一、源码移植结论（为什么不能直接搬 NoteGen）

| 维度 | 事实 | 结论 |
|---|---|---|
| 协议 | NoteGen（github.com/codexu/note-gen）为 **GPL-3.0**（强 copyleft） | 直接搬运源码 → 整个闭源项目被迫开源，法律不可行 |
| 项目属性 | 本仓库**无 LICENSE 文件**、package.json 无 license 字段，为闭源商业项目（碎碎记/CutShelter） | 与 GPL-3.0 冲突 |
| 技术栈 | NoteGen 是 Tauri + React + Tiptap/radix（@tiptap/suggestion、cmdk、shadcn） | 本仓为 Electron + 原生 JS + Ace + D3，整栈不兼容 |
| 既有先例 | 编辑器斜杠菜单改版已定论：「原生 JS + Ace 重写，仅借鉴与框架无关的交互/视觉/纯算法」（见《画布右键菜单与输入唤起菜单改版.md》第 21 行） | 画布沿用同一口径 |

**结论：不移植源码，按官方能力清单逐项补齐自家实现。**

## 二、现状分析（差距清单）

### 2.1 当前画布已有（拆分后的独立画布页 canvas.js，1247 行）

| 能力 | 位置 |
|---|---|
| 无限画布 + d3.zoom 缩放平移（滚轮/空格/中键） | canvas.js L166-187 |
| 四种节点：便签/链接/图片/引用 | L309-351 `renderCanvasCard` |
| 节点拖拽 + 坐标持久化（canvas_layout） | L454-477 `dragBehavior` |
| 手动连线（直线，中心对中心） | L234-240、L296-303 `updateLinkPositions` |
| 分组 frame（环绕成员、整体拖动） | L587-606 |
| 右键菜单（空白新建 / 节点连线·编辑·分组·删除 / 连线删除） | L720-797 |
| 双击节点编辑、单击选中 | L258-261 |
| 框选（Box Select）、小地图（Minimap + 跳转） | L530、L975+ |
| 空态右键新建（上一轮已修复） | L726-733 |

### 2.2 与 NoteGen 画布的差距（本轮补齐目标）

| 差距项 | 说明 |
|---|---|
| **节点卡片质感一般** | 当前是纯色 SVG rect + 居中文字，无描边/阴影/hover 层级/选中态，图片卡无边框 |
| **连线无方向、无层级** | 直线中心对中心，无箭头、无 hover 高亮、无锚点（NoteGen/Obsidian 连线锚在卡片边） |
| **无网格吸附** | 拖动自由落点，不齐整（NoteGen 明确展示网格吸附） |
| **空白双击无入口** | 空白只能右键新建；NoteGen/Obsidian 双击空白直接建文本卡 |
| **分组不可折叠、不可重命名** | frame 只能整体拖动，无折叠、无重命名 |
| **菜单为纯文字** | 与编辑器已改版的 SVG 图标菜单不一致（视觉落后） |
| 其余差距（图形节点/手绘/图表、AI 自动布局、Mermaid 生成、模板/导入） | **本轮不做**（用户确认范围），留待后续 AI 阶段 |

### 2.3 关键实现前提（决定改动方式）

- 节点渲染为 **SVG `g.node` > rect + text**，卡片中心坐标即布局坐标（`translate(x,y)`），宽度固定（note 108×60、image 110×72、link/ref 108×42）。
- 连线为 `line.link-manual`，端点直接用节点中心坐标；**锚点可用「源→目标方向与矩形边求交」纯渲染计算**，无需给 `canvas_edge` 加列 → 数据模型零改动、旧数据无缝兼容。
- 分组数据表 `canvas_group / canvas_group_member` **无 collapsed 字段**；折叠状态用**前端内存态**（会话内有效），避免本轮引入 schema 迁移 v7，符合「不改数据语义」。

## 三、Proposed Changes

仅改动两个文件：`frontend/canvas.js`、`frontend/canvas.html`。数据层 / IPC / 后端零改动。

### A. 视觉质感升级

#### A1. 节点卡片精致化（canvas.html + canvas.js）

- 卡片 rect 增加：`fill` 保持主题色系但**加描边 `stroke: var(--border)`、stroke-width 1**、`filter` 投影（`--app-shadow-sm`）。
- **hover**：描边变 `--app-primary`，投影升 `--app-shadow-md`，微放大（scale 1.02，`--app-duration-fast` 过渡）。
- **选中态**（`.node.selected`）：描边 `--app-primary` + 2px、外圈 focus ring（偏移 3px 的浅色描边）。
- 文字：居中微调，note 正文 12px/`--app-text-secondary`，标题行加粗；link 卡显示 🌐/🔗 图标 + 标题 + 域名灰字；image 卡加圆角边框与内阴影。
- 类型图标：卡片内 emoji（🖼/🔗/📌）保留但换为**内联 SVG 线框图标**（16px，`--app-text-muted`），与编辑器工具栏图标风格一致。

#### A2. 连线升级（canvas.js + canvas.html）

- **箭头**：`marker-end` 定义在 `defs`（三角形，`--app-primary`），仅在 `line.link-manual` 上启用。
- **锚点吸附**：`updateLinkPositions` 改为计算「从源矩形边 → 目标矩形边」的交点（中心连线方向与矩形四条边求交，取射线首个交点），端点为卡片边缘而非中心。
- hover：`.link:hover` 加粗至 2px + 颜色 `--app-primary`，opacity 提升；默认 `--app-border` 颜色、opacity 0.9。
- 连线右键删除菜单保留，按钮加大命中区。

#### A3. 分组 frame 美化（canvas.html）

- frame rect：圆角 10px、**虚线描边** `--app-border`、半透明填充 `--app-primary-soft`（低 alpha）、hover 时描边 `--app-primary`、标题 chip 化（小圆角底色块 + 12px 文字）。

#### A4. 右键菜单 SVG 图标化（canvas.html）

- 菜单项从「emoji/纯文字」升级为**内联 SVG 线框图标 + 文字**（16px 图标、gap 10px、padding 8px 12px、hover `--app-primary-soft` 底），对齐编辑器改版后的菜单样式；新增 `.danger`（删除节点/删除连线）红色 hover 态。
- 空态提示层、弹窗（新建/编辑表单）沿用主题 token 微调圆角/间距。

### B. 交互补齐

#### B1. 网格吸附（canvas.js，`dragBehavior` 内）

- 拖动中把 `x/y` round 到 **12px 网格**（`Math.round(v / 12) * 12`），落库、连线、分组 frame、小地图全部随吸附后的坐标更新（现有刷新链路已统一走 `refreshNodePos`/`updateLinkPositions`/`renderGroupFrames`/`renderMinimap`，只改 drag 中写入的坐标值）。
- 常量 `const GRID = 12` 放模块顶部，便于后续调。

#### B2. 空白双击新建便签（canvas.js）

- 在 `svg` 上补 `dblclick`：`isCanvasBackground(event)` 为真时 `preventDefault`，调用 `openCreateModal('note', 世界坐标)`（复用现有弹窗，默认类型便签，坐标传 `screenToWorld`），与右键菜单「新建便签」走同一落库链路。
- 注意与「单击选中/框选」不冲突：dblclick 已限定空白区域（非节点/连线/分组）。

#### B3. 分组折叠 / 重命名（canvas.js + canvas.html）

- **折叠**：点击 frame 标题 → 切换 `groupCollapsed[groupId]`（模块级内存 Map）→ 折叠时：frame rect 高度收成标题条高度，成员节点 `display:none`，成员间连线与成员相关连线隐藏；展开时恢复。拖动整组时折叠态不变。
- **重命名**：双击 frame 标题 → 复用现有弹窗（`openCreateModal` 改造或新增轻量 `openRenameModal`）→ 调用现有 `window.electronAPI.localIndex.canvasGroupUpdate`（或对应 rename API，按 main.js/preload.js 现有暴露为准，计划执行时先 grep 确认函数名）→ 成功后更新内存并重渲染该 frame 标题。
- 折叠状态为**内存态**（刷新后恢复展开），计划中注明不落库，避免 schema 迁移。

## 四、Assumptions & Decisions

1. **不移植 NoteGen 源码**：GPL-3.0 + 闭源项目冲突 + 技术栈不兼容；仅借鉴交互/视觉口径（Obsidian Canvas / JSON Canvas 语义）。
2. **数据层零改动**：锚点吸附用纯渲染计算（矩形边求交），折叠状态存内存，不做 v7 迁移。
3. **卡片中心即布局坐标**：锚点/吸附均以中心坐标计算，不改变 `canvas_layout` 语义，旧数据无缝兼容。
4. 折叠不持久化（刷新后展开）为有意的范围取舍，如后续要持久化再引入 `canvas_group.collapsed` 迁移。
5. 节点颜色仍沿用 `nodeColor(type)` 现状，仅增强描边/阴影/选中态，不重构配色体系（避免影响知识图谱一致性）。

## 五、Verification

1. **语法**：`node --check frontend/canvas.js`。
2. **浏览器实测**（`http://127.0.0.1:3001/canvas.html`，经浏览器 agent）：
   - 空白右键新建 / 空白**双击**新建便签 → 弹窗 → 取消关闭；
   - 新建便签节点 → 拖动时**吸附 12px 网格**，落库后位置保留（刷新仍在）；
   - 两节点手动连线 → 连线**锚在卡片边缘**并带**箭头**；hover 变主题色加粗；拖节点时连线端点跟随且始终在卡片边；
   - 框选多节点 → 右键「组成分组」→ 分组显示虚线圆角框 → **点击标题折叠**（成员与连线隐藏）→ 再点展开 → **双击标题重命名**生效；
   - 节点 hover 阴影/描边、选中 primary 描边、右键菜单 SVG 图标与 hover 态均正常；
   - 空态页（无节点）右键/双击新建仍可用（回归上轮修复）。
3. **回归**：知识图谱页不受影响（canvas.js 与 knowledge-graph.js 已拆分独立，本方案不动图谱）。
4. **应用内验证**：Electron 主窗口打开画布重复上述操作，确认主题 token（深/浅色）下样式正常。
