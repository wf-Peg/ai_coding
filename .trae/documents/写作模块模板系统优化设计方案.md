# 写作模块模板系统优化设计方案

> 状态：规划（待确认后实施）
> 目标：在既有「插入模板」能力基础上，补齐三处：

1. `/` 斜杠菜单同时支持「插入模板」与「维护模板（打开管理弹窗）」双能力
2. 内置模板（日记 / 会议记录 / 周报 / 随笔 / SQL 注释 / Java 文件头）初始化并**可编辑**，存储于**配置文件**（config.json 的 `builtinTemplates`）
3. 占位符动态替换升级：支持日期格式参数（`{{date:YYYYMMDD}}` 等）与更全的常用变量

> 约束：自定义模板仍存储于 `{vaultRoot}/templates/` 文件；内置模板存储于配置 `config.json`（符合「数据文件路径 / 配置文件路径」分离的既有约定）。

## 二、设计方案

### 2.1 内置模板数据模型（config.json）

在 `DEFAULT_CONFIG`（[main.js](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/electron/main.js#L252)）新增：

```jsonc
builtinTemplates: [
  { "name": "日记模板.md", "content": "..." },
  { "name": "会议记录.md", "content": "..." },
  { "name": "周报模板.md", "content": "..." },
  { "name": "随笔模板.md", "content": "..." },
  { "name": "SQL 注释模板.md", "content": "..." },
  { "name": "Java 文件头模板.md", "content": "..." }
]
```

运行期：`loadConfig()` 合并后即为「内置模板默认集」。用户编辑内置模板 → `saveConfig` 写入 `builtinTemplates` 覆盖对应项；「删除」内置模板 = **恢复默认**（删除该 name 的 config 覆盖项，回归 `DEFAULT_CONFIG` 默认内容）。

### 2.2 主进程 IPC 扩展（[main.js](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/electron/main.js#L4100-L4169)）

新增 4 个只读 helper + 改造 4 个 handler：

| handler | 改造逻辑（内置 vs 自定义判定） |
|---------|------------------------------|
| `editor-list-templates` | 合并：内置（来自 config，`source:'builtin'`）+ 自定义（来自 templates 目录文件，`source:'custom'`），返回 `templates:[{name, source, builtin:true/false}]` |
| `editor-read-template` | 先是内置 → 返回 config 内容；否则读文件 |
| `editor-save-template` | 名称为内置 → 写回 config `builtinTemplates`；否则写文件 |
| `editor-delete-template` | 名称为内置 → 重置为默认（移除 config 覆盖项）；否则删文件 |

Helper：

```javascript
function getBuiltinTemplates() {           // 从 loadConfig().builtinTemplates 取数组
  const cfg = loadConfig();
  return Array.isArray(cfg.builtinTemplates) ? cfg.builtinTemplates : DEFAULT_CONFIG.builtinTemplates;
}
function isBuiltinTemplateName(name) { return getBuiltinTemplates().some(t => t.name === name); }
function saveBuiltinTemplate(name, content) {   // 写回 config：覆盖同名项，无则追加
  const cfg = loadConfig();
  const list = Array.isArray(cfg.builtinTemplates) ? cfg.builtinTemplates.slice() : (DEFAULT_CONFIG.builtinTemplates || []).slice();
  const idx = list.findIndex(t => t.name === name);
  const rec = { name, content };
  idx >= 0 ? (list[idx] = rec) : list.push(rec);
  saveConfig({ ...cfg, builtinTemplates: list });
}
function resetBuiltinTemplate(name) {           // 删除 config 覆盖项 → 回归默认；默认本身不含该名则整体从列表移除
  const cfg = loadConfig();
  if (!Array.isArray(cfg.builtinTemplates)) return;
  const next = cfg.builtinTemplates.filter(t => t.name !== name);
  saveConfig({ ...cfg, builtinTemplates: next });
}
```

> 说明：不新增 IPC 通道，复用现有 4 个 handler，前端零新增 API。

### 2.3 占位符动态替换引擎（[editor.js](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/js/editor.js#L8299-L8307)）

将 `replaceTemplateVars` 升级为完整引擎，新增 `formatDate(date, fmt)` 与变量闭环：

**`formatDate(date, fmt)`** 支持 strftime 风格 token（最长优先替换，避免 YYYY/YY 误吞）：

```javascript
function formatDate(d, fmt) {
  var pad = function(n, w) { n = String(Math.abs(n)); return n.padStart(w, '0'); };
  var map = {
    YYYY: String(d.getFullYear()),
    YY: pad(d.getFullYear() % 100, 2),
    MM: pad(d.getMonth() + 1, 2),
    M: String(d.getMonth() + 1),
    DD: pad(d.getDate(), 2),
    D: String(d.getDate()),
    HH: pad(d.getHours(), 2),
    H: String(d.getHours()),
    mm: pad(d.getMinutes(), 2),
    ss: pad(d.getSeconds(), 2)
  };
  return String(fmt).replace(/YYYY|YY|MM|M|DD|D|HH|H|mm|ss/g, function(t) { return map[t]; });
}
```

**变量解析（支持 `{{var:param}}` 形式）**：

```javascript
function replaceTemplateVars(content, author) {
  var now = new Date();
  var vars = {
    '{{date}}': formatDate(now, 'YYYY-MM-DD'),
    '{{now}}': formatDate(now, 'YYYY-MM-DD HH:mm'),
    '{{time}}': formatDate(now, 'HH:mm'),
    '{{year}}': String(now.getFullYear()),
    '{{month}}': String(now.getMonth() + 1),
    '{{day}}': String(now.getDate()),
    '{{weekday}}': ['日','一','二','三','四','五','六'][now.getDay()],
    '{{title}}': getCurrentFileName().replace(/\.[^.]+$/, ''),
    '{{author}}': author || ''
  };
  var s = content;
  Object.keys(vars).forEach(function(k) { s = s.split(k).join(vars[k]); });
  // 支持带日期格式参数：{{date:YYYYMMDD}} / {{now:YYYY-MM-DD HH:mm}} / {{date:YYMMDD}}
  s = s.replace(/\{\{(date|now):([^}]+)\}\}/g, function(_, kind, fmt) {
    return formatDate(now, fmt);
  });
  return s;
}
```

> `{{date:YYMMDD}}`（yymmdd）、`{{date:YYYYMMDD}}`、`{{date:YYYY年MM月DD日}}` 等均可用。前缀无匹配自定义格式的统一由 `{{date}}/{{now}}` 兜底。

## 五、假设与决策

| 决策点 | 结论 |
|--------|------|
| 内置模板存储 | config.json `builtinTemplates` 数组（遵循「配置路径 / 数据路径分离」约定） |
| 自定义模板存储 | 维持 `{vaultRoot}/templates/` 文件 |
| 内置模板删除语义 | 删除 = 恢复默认（重置为 `DEFAULT_CONFIG` 内容）；自定义 = 删文件 |
| 占位符格式 | 支持 `{{date:…}}/{{now:…}}` 自定义日期格式 + `{{weekday}}/{{year}}/{{month}}/{{day}}/{{time}}/{{title}}/{{author}}` 变量 |
| IPC 扩展 | 复用现有 4 个 handler，主进程按名称分流，不新增前端 API |
| `/` 菜单维护入口 | 动态模板组末尾追加「管理模板…」行，选择后打开管理弹窗 |
| 默认内置集 | 6 个：日记 / 会议记录 / 周报 / 随笔 / SQL 注释 / Java 文件头 |
| 内置徽标 | 列表行显示「内置」小标签，区分自定义 |

## 六、验证步骤

1. **启动**：`npm start` → 打开编辑器 → 输入 `/` → 右侧出现「模板」分组，含 6 个内置 + 「管理模板…」行。
2. **内置插入**：选「日记模板」→ 正文插入，`{{date:YYYY年MM月DD日}}`、`{{weekday}}`、`{{title}}` 正确替换。
3. **格式参数**：插入「SQL 注释模板」判断 `{{date:YYMMDD}}` → 输出如 `260913`；`{{date:YYYYMMDD}}` → `20260913`。
4. **维护入口**：`/` → 「管理模板…」打开弹窗；`Ctrl+P` → 「管理模板…」也可打开。
5. **内置编辑**：弹窗编辑「日记模板」内容 → 保存 → 重开仍在（persist 于 config.json `builtinTemplates`）；删除 → 恢复默认内容。
6. **自定义不受影响**：新建自定义模板存 `templates/` 文件，编辑/删除/插入正常。
7. **回归**：标题/AI 斜杠组、插入/链接/代码等命令面板项、既有自定义模板均不受影响；`{{author}}` 读取 config `author/authorName` 行为不变。
