# 剪藏原文展开限高生效与冗余复制按钮移除

## 概述（Summary）

上次的「展开原文限高+宽度收敛」CSS 改动（`frontend/styles/clip.css`，尚未提交）实际**从未生效**——根因是 `toggleDetail` 展开时移除 `truncated` 类而非添加 `expanded` 类，导致 `.content-text.truncated.expanded { max-height }` 永远匹配不上，原文仍以全部高度展开。本次修复 JS 类切换逻辑使限高生效，并移除用户指出的冗余按钮「复制原文」「复制到编辑区打开」（下方来源 wiki-link 已提供编辑器打开能力），删除其死代码 `copyToEditor`。最后按项目规范提交（含 `commit_history.log`），防止再次被合并覆盖。

**用户已确认**：高度采用「限高+内部滚动」（`.content-text.truncated.expanded` 限高 `min(55vh, 560px)` + 内部滚动 + 点击收起），不做二级展开。

## 变更方案（Proposed Changes）

### 1. 修复 `toggleDetail` 类切换（高度生效）

文件：`frontend/js/clip-list.js`，L646-659

```js
const contentTexts = detail.querySelectorAll('.content-text.truncated');
if (detail.classList.contains('expanded')) {
    text.textContent = '收起';
    contentTexts.forEach(el => el.classList.add('expanded'));
    const clipId = detail.dataset.clipId;
    if (clipId) {
        renderLinkedKnowledge(parseInt(clipId));
        renderPlanBacklinks(parseInt(clipId));
    }
} else {
    text.textContent = '展开';
    contentTexts.forEach(el => el.classList.remove('expanded'));
}
```

- 展开：`add('expanded')`（保留 `truncated`）→ 命中 `.content-text.truncated.expanded` CSS → 限高 + 内部滚动生效。
- 收起：`remove('expanded')` → 回到 3 行 clamp + 渐变遮罩。
- 与点击内容路径（L65-70 `toggle('expanded')`）行为统一。
