# 组件引擎体验收尾：紧凑排列 + 组件设置弹窗

## Context（为什么做）

组件系统（`workbench-widgets.js`）已完成 MVP：拖拽换位（transform 合成位移 + 实时让位替换 + 松手丝滑归位）、缩放手柄、多工作台独立布局（`setLayoutKey`）、「工作台漏斗」卡。按 MVP 设计文档第九节遗留，本轮补齐两块完整体验：

1. **图表/组件排布优化**：当前拖拽松手用「碰撞下移」避让，长期使用会留下竖向空洞；需要「紧凑排列」一键整理，把卡片按 上→下、左→右 顺序紧凑重排，消除空洞。
2. **组件设置弹窗**：用户可以自定每个组件卡片的**标题**与**宽/高**（夹在 `minSize` 与网格上限之间），值持久化到布局存档。

不做：数据源类设置（如漏斗卡选工作台）已由卡内下拉承担，不进设置弹窗；不做组件删除/复制等扩展。

## 改动范围（2 文件）

### 1. `frontend/js/workbench-widgets.js`（引擎）

**a. 布局紧凑化 `compactLayout()`（内部）+ 公开 `WB.compact()`**
- 按 `(row, col)` 稳定排序，逐张把卡片塞到「首个不与已放置卡片冲突的空位」（逐行从 col=0 扫描，复用 `overlaps`）。
- 兜底：扫描不到空位时放到 `max(row+h)` 底部（与 `addWidget` 的 found 兜底一致）。
- 完成后 `relayout(); persist();`。

**b. 卡片头新增「设置」按钮 + `WB.openSettings(id)`**
- `cardDOM` 头部 `</h3>` 后、`.wb-remove` 前插入 `<button class="wb-settings" title="组件设置">⚙</button>`（文本避免 emoji 依赖，用 SVG 齿轮或字符；按项目风格用 SVG）。
- 卡片标题支持自定义：`entry.title || def.title` 决定 `.wb-title` 文本；`normalize` 透传 `title`；`persist` 随布局存档。
- `openSettings(id)`：自绘 modal（挂 `document.body`）：
  - 标题输入（空=恢复默认标题）
  - 宽度/高度数字输入（clamp：宽 `minSize.w..cols`、高 `minSize.h..12`）
  - [取消/保存] 按钮；保存时校验数字 → 写回 `entry.w/h/title` → 更新卡片标题 DOM + `relayout()` + `persist()`
  - 复用现有 `clamp`；modal 关闭即移除 DOM。

### 2. `frontend/styles/workbench-widgets.css`
- `.wb-settings` 编辑态按钮（与 `.wb-remove` 同排、同风格，`display:none`/`.edit-on` 显示）。
- `.wb-settings-modal` + 子元素（遮罩 `rgba(0,0,0,.18)` 仿 `.wb-palette`、面板 `--ws-surface`、`--app-radius-lg`、`--app-shadow`）+ 表单输入样式（标题、尺寸数字）。
- 紧凑按钮样式（`compactLayout` 触发入口）——见下方交互入口。

## 交互入口
- **紧凑排列按钮**：hero 工具栏（`refreshButton` 旁）加一个常显小按钮「紧凑」，点击 → `WB.compact()`。复用 `.wb-edit-btn` 风格或轻量 icon 按钮。直接在 `workspace.html` 工具栏加 `<button id="widgetCompactBtn">` 并绑定。
- **设置弹窗**：编辑态卡片头 ⚙ 按钮。

> 注：`workspace.html` 为第三处小改动（加紧凑按钮 DOM + 绑定 `WB.compact`）。

## 关键复用
- `overlaps`、`clamp`、`persist`、`relayout`、`defaultLayout`（引擎内已有）。
- `.wb-palette` 弹窗样式模式（`workbench-widgets.css`）作为设置弹窗样式基线。
- hero 工具栏 `.wb-edit-btn`/`.wb-ws-ctx` 布局（`workspace.html`）放紧凑按钮。
