# 设置「播放引导」功能体验优化方案

> 日期：2026-09-21
> 状态：待评审
> 范围：仅前端 + Electron 渲染层，不改后端接口、不改任何 element id

## 1. 现状与问题（已确认结论）

「播放引导」= 设置页「工作区」分组顶部横幅里的按钮，点击后弹出重播弹层，复用共享渲染器 `frontend/js/guide-core.js` 渲染两张清单卡（存储路径 / AI Key）。

当前实现与用户反馈的问题映射：

| # | 用户感受 | 代码层面的根因 |
|---|----------|----------------|
| 1 | 后端未启动无友好提示 | [settings.js](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/js/settings.js#L2329-L2391) 的 `openGuideReplay()` 直接读 DOM 字段（`vi('storagePath')` / `vi('dashscopeApiKey')`…），后端未启动时字段全空 → 弹层误展示「存储未设置 / AI 稍后配置」的假状态，且「去配置 AI Key」跳转目标字段不存在。页面上虽有 `.backend-error` 提示条，但弹层完全没有感知。 |
| 2 | 没有卡片效果，上面还两个点误导 | 弹层宿主只有 `g-root` 背景 + 遮罩（[openGuideReplay 的 host 样式](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/js/settings.js#L2341-L2345)），没有对话框卡片外壳；[spec 的 `progress`](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/js/settings.js#L2360) 传了 2 个「步骤小圆点」，但它是清单卡不是 Stepper → 圆点像分页器/步骤条，实际不可交互、纯误导。 |
| 3 | 折叠区点击卡手、有时没反应 | [guide-core.js](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/js/guide-core.js#L252-L255)：整个卡片（含展开后的 fields 区）点击除控件外都会触发 `header.click()` 二次折叠——在展开区点击时会莫名收起（卡手）；而点 `<label>` 等控件又被 `closest('label')` 拦住无响应（没反应）。整行 header 都是热区、fields 区 `cursor:default` 却可点击，用户不理解「为什么这样设计」。 |
| 4 | 按钮位置不合理（左下角跳转） | AI 卡 `actions` 里的「去配置 AI Key…」（[settings.js L2384](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/js/settings.js#L2384)）被渲染在 `.g-actions`（卡片底部左侧一行小幽灵按钮），做的是「关闭弹层 + scrollIntoView 跳转到 AI 分组」的跳转动作，却放在不起眼的左下角；卡片明细区为空（`fieldsHtml: () => ''`）造成「空白 + 角落按钮」的突兀。 |
| 5 | 样式不美观 | 弹层无卡片感、`.g-step`（「重播模式 · …」）在 guide-core 中**没有对应样式**（裸文本）；横幅 [.help-banner](file:///Users/pengwenfeng/Documents/gitRep/trae_demo/codex-project/frontend/settings.html#L833-L843) 平板风格、无状态反馈、不展示「AI Key 待配置」（设计规格 §5.3 要求持续提示）。 |

## 2. 目标交互流程与产品体验（梳理结论）

「播放引导」的产品定位 = **状态速览 + 指引跳转**（非配置页、非分步向导）。体验闭环设计：

```
设置页「工作区」分组顶部 · 引导横幅（常驻）
   ├─ 常态：🎓 上手引导 · 一句副标题 + 右侧状态摘要
   │        （🟢 存储已就绪 · 🟠 AI Key 待配置 / ⚪ 后端未连接）
   │         + 主按钮「播放引导」
   ├─ 后端未启动：横幅呈警示态，副标题「后端服务未启动，启动后即可查看配置状态」
   └─ 点击「播放引导」→ 对话框卡片弹层
         ├─ 头部：标题 + 副标题 + ✕
         ├─ 状态行（替代误导圆点）：2 项配置 · 🟢 存储已就绪 · 🟠 AI Key 待配置
         ├─ [信息卡 · 存储路径]  默认展开：当前路径 /「尚未设置」+ 状态药丸
         │    明细区内置行内动作「去设置存储路径 →」（关闭弹层 + 定位 #storagePath + 高亮）
         ├─ [信息卡 · AI Key]    默认展开：服务商 + 脱敏 Key（或「未配置」）+ 状态药丸
         │    明细区内置行内动作「前往「AI 与模型」配置 →」（关闭弹层 + 定位 #activeProvider + 高亮）
         └─ 底部：信任文案 + 「完成」
   后端未启动时弹层：顶部警示条「⚠️ 后端服务未启动，当前配置状态不可用。」
   卡片状态统一「未能读取」，跳转动作禁用并提示「启动后端后可用」。
```

设计要点：
- **消除误导圆点**：清单一类卡片不假装分页，改为**一行语义状态摘要**（实心点 = 状态，不只是装饰）。
- **消除「卡手」折叠**：信息卡默认直接展开核心明细，折叠只收细节；折叠热区只限「箭头 + 标题」；fields/actions 区点击**永不触发** toggle。
- **跳转按钮归位**：跳转型动作放在**所属卡片明细区内、右对齐**，语义「从这里去设置」，不再孤悬左下角。
- **平台一致性**：全部使用 `--app-*` 令牌 + `html[data-theme="dark"]` 覆盖，深浅色成立；`guide-core.js` 的改动对首装窗口 `electron/config.html` **纯增量兼容**（首装仍保留步骤圆点与整行展开）。

## 3. 改动方案（文件级）

### 3.1 `frontend/js/guide-core.js`（共享渲染器，纯增量 + 2 处行为修正）

1. **新增可选 `spec.hideProgress`**：为 `true` 时不渲染 `g-progress` 圆点（默认 false，`config.html` 首装不受影响）。
2. **补 `.g-step` 样式**（当前无样式、裸文本）：随令牌粗细/次级色，与 `.g-hero-sub` 同级但带主色「重播模式」胶囊或次级小字。
3. **修正折叠热区**（对 config.html 同步生效、更优）：
   - `.g-card-fields` / `.g-actions` 上一律 `cursor:default`，且 `cardDom` 兜底 click 处理器**命中 fields/actions 时直接 return**（不再二次 toggle）。
   - 仅 header 区域（含 chevron）保持 `cursor:pointer` + hover 高亮；chevron 已有 `.open` 旋转，保留。
4. **新增 `.g-cta`（行内跳转动作）样式类**：右对齐、主色文字 + 箭头「→」，hover 主色——供重播跳转按钮使用（配置在 `actions` 内提供也不影响现有调用）。

> 不新增任何必填 spec 字段；不改变 `render`/`resolveCanProceed` 接口签名。

### 3.2 `frontend/js/settings.js`

1. **重写 `openGuideReplay()`**（`L2329-L2408`）：
   - 弹层外壳改为**对话框卡片**：居中、`max-width:480px`、`--app-surface` 底、`--app-radius-lg/16px` 圆角、`--app-shadow-xl`，头部（标题 + 副标题 + ✕）+ 内容 + 底部（信任文案 + 「完成」主按钮）；遮罩用 `color-mix` 加深色。
   - **后端感知**：用现成 `configLoaded` 标志；`false` 时——弹层顶部插警示条、两张卡状态统一为「未能读取」(muted)、跳转动作 `disabled` + 提示。
   - **spec 重排**：
     - `hideProgress: true`，`progress` 移除；
     - 状态摘要行文案 = 由 `configLoaded/isReady` + `storageSet` + `aiSet` 实时拼出的「2 项配置 · 🟢 存储已就绪 · 🟠 AI Key 待配置」；
     - 存储卡：默认 `open:true`，`fieldsHtml` 展示当前路径（未设置→「尚未设置，去左侧工作区配置」），`actions` 内放右对齐「去设置存储路径 →」（后端未起则禁用）；
     - AI 卡：默认 `open:true`，`fieldsHtml` 展示服务商 + **脱敏 Key**（取 `dashscope/deepseek/custom` 对应值尾部 4 位，形如 `sk-…abcd`；未配置→「未配置」），`actions` 内放右对齐「前往「AI 与模型」配置 →」；跳转实现保留 `scrollIntoView → close`，改为 `block:'center'` 并对目标表单组加短暂高亮类（约 1.2s 后移除）。
   - 移除/替换原 `createReplayCloseBtn`（tegration 进新壳头部，样式跟随令牌）。
2. **横幅状态联动**：新增 `updateGuideBannerState()`——DOM 加载后与 `loadConfig()` 成功后调用，根据后端就绪 + 存储/AI 配置状态刷新横幅右侧状态胶囊与副标题；`configLoaded` 变化（`backendState: ready` 分支）时重刷。

### 3.3 `frontend/settings.html`

1. **横幅重构**（`L833-L843` 样式 + `L873-L877` 结构）：
   - `.help-banner` → `background:var(--app-primary-soft)` + `border:1px dashed var(--app-primary)`（对齐设计原型 §B 区）；
   - 结构：🎓 方形图标（软主色块）｜「上手引导」标题 + 状态副标题｜右侧状态胶囊（绿/橙点 + 文案）+ 主按钮「播放引导」；
   - 新增 `.guide-status`（状态胶囊）、`.guide-status.offline`（后端未连警示态）、`.focus-flash`（跳转目标高亮）样式，全部 `--app-*` 令牌。
2. **保留 `group-workspace` 结构、字段 id 不动**（硬约束）。

## 4. 假设与决策

- **决策 A（重播定位）**：弹层为「状态速览 + 跳转指引」，**不做内嵌可编辑表单**——编辑入口统一在设置页各组，避免双数据源同步；符合「低成本、高收益、不动后端」偏好。跳转目标：AI→`#activeProvider`，存储→`#storagePath`。
- **决策 B（圆点）**：重播移除进度圆点并替换为语义状态行；首装 `config.html` 的步骤圆点**保留**（首装是真实的进度语义）。
- **决策 C（折叠）**：信息卡默认展开核心明细，保留「箭头+标题」折叠细节；fields/actions 区点击不触发 toggle（同时修复 config.html 同类手感）。
- **决策 D（脱敏展示）**：AI Key 只展示尾部 4 位，避免明文。
- 不改：后端接口、preload IPC、任何 element id / data-target、guide-core 接口签名。
- 重播弹层最大宽度约 480px，窄屏（≤560px）自适应顶部留白。

## 5. 验证步骤

1. **静态检查**：
   - `node -e` 校验 settings.html 仍含 `id="group-workspace" / guideReplayBtn / js/guide-core.js`；
   - grep 确认 settings.js 中 `dedebug: openGuideReplay` 新版含 `configLoaded` 分支与 `hideProgress`；
   - guide-core.js 语法 `node --check`。
2. **首装回归（config.html）**：首次运行窗口两张卡 + 步骤圆点 + 整行展开仍正常（guide-core 兼容性）。
3. **运行时验证（Electron 起前端 + 后端）**：
   - 停后端 → 设置页横幅呈「后端未连接」警示态；点「播放引导」→ 弹层顶部警示条、卡片「未能读取」、跳转禁用。
   - 起后端 → 横幅恢复状态摘要；点「播放引导」→ 弹层卡片显示真实路径/AI 状态；点「前往「AI 与模型」配置 →」→ 弹层关闭、滚动定位 `activeProvider` 并高亮；存储同理。
   - 深浅色（regular/notion/dark）三主题下横幅与弹层无硬编码色冲突。
4. **交互手感**：展开区点击不再引起收起/无响应；chevron 旋转动画与主题动效令牌一致。
