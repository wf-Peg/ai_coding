# 画布 P1 三特性：Markdown/OPML 导入 · 大纲搜索定位 · 富文本行内样式

> 背景：P0「智能创建 MVP」已完成并验证。用户要求按优先级表把 P1 三项（导入建树 / 大纲全文搜索 / 富文本行内样式）都做了，对标幕布。
> 已确认决策：① 富文本 = **大纲行内 contenteditable 直接编辑**（Ctrl+B 加粗 / Ctrl+Shift+H 高亮 / Ctrl+K 链接），数据仍是纯文本（markdown 行内标记 `**加粗**`、`==高亮==`、`[文字](url)`），画布 SVG 卡片按行内符文拆段渲染；② 导入 = **弹窗预览后一键应用**（复用 AI 生成器双栏预览，新建文档或插入当前文档）。
> 本批 **零 electron/后端改动**（`importTree` + `local-index:canvas:import-tree` + `importCanvasTree` 已就绪）。

## 四、功能 3：富文本行内样式（大纲行内编辑 + 画布卡片渲染）

**核心设计：纯文本存储 + markdown 行内标记，大纲/画布均为「渲染层」映射。**

**新增纯函数模块（UMD，浏览器挂 `window.CanvasInlineMd`、node 走 module.exports）：** 新建 `frontend/js/canvas-outline-md.js`
- `mdToHtml(text)`：先 `escapeHtml` 全量转义，再按固定顺序 tokenize：`**bold**`→`<strong>`、`==hl==`→`<span class="ol-hl">`、`[t](u)`→`<a class="ol-link" href="u">`（href 仅允许 `http(s)://`、`#`、相对锚，白名单校验，非法原样转义为纯文本）。空 `**`/孤 `==` 按字面量处理。
- `htmlToMarkdown(elOrFragment)`：遍历节点，仅保留 TEXT_NODE / STRONG / B / SPAN.ol-hl / A（A 只留 href 且同白名单校验，非法丢弃），分别逆转为 `**``==``[t](u)`；其余标签/属性一律剥离回纯文本。**快路径**：片段无任何样式节点时直接 `textContent` 原样返回（保证“没加样式时文本一字不变”，避免渲染回写抖动与 diff 误判）。
- `parseInline(text)` → `[{text,bold,hl,link}]` 符文数组，供 canvas.js SVG 渲染复用；与 `mdToHtml` 用同一 tokenizer。
- 导出：`mdToHtml / htmlToMarkdown / parseInline`。

**`frontend/js/canvas-outline.js` 改造：**
- `updateRow()`（L142-145）：非编辑态 `textContent = want` 改为 `innerHTML = CanvasInlineMd.mdToHtml(want)`；`editingId !== n.id` 的既有守卫天然保证**打字/编辑中不被重写、光标稳定**。比较/防抖用「mdToHtml 往返归一化后的串」。
- `flushText()`（L408）：`rec.text.textContent` 改为 `CanvasInlineMd.htmlToMarkdown(rec.text)`（快路径无额外开销）；其余不变（去重比对、`n.text=val`、`opts.onEdit`）。
- `onKeydown()`（L487）：**在函数最前面**插入三个组合键分支（带 `e.preventDefault()` 后 return，绝不影响后续 Enter/Tab/Alt↑↓/Ctrl↑↓/Backspace/方向键分支）：
  - `Ctrl/Cmd+B`：`document.execCommand('bold')`；
  - `Ctrl/Cmd+Shift+H`：选区包 `<span class="ol-hl">…</span>`（自定义，execCommand 无高亮），无选区不动作；
  - `Ctrl/Cmd+K`：弹链接小输入框 `openLinkModal()`（绝对定位浮层输 URL，确认后选区包 `<a class="ol-link" href="…">`，空 URL 解包为纯文本，无选区不动作）。
  - 命令后统一走 `pendingTextId + flushText()` 既有管线落库。
- `onPaste`（L439）保持纯文本插入不动（防注入）。
- `onInput` 不动（input 只记 pending）。
- 对外暴露 `CanvasInlineMd`（通过 `window.CanvasInlineMd`），并在 `CanvasOutline` 上透出 `parseInline`（供 canvas.js 调用，避免摸全局）。

**`frontend/canvas.js` 画布卡片渲染：**
- `renderCanvasCard` 正文（note/ref 卡 `wrapLines` 段，L606-670）：由纯文本换行改为基于 `CanvasOutline.parseInline` 的**符文分段换行**——每行由若干 `tspan` 组成：bold 段 `font-weight:600`，hl 段用主题高亮填充色/下划线，link 段 `--app-primary` 色 + 下划线；段跨行时按字符截断拼接，行数保持既有 `slice(0,maxLines)`。
- `refreshCardText(id)`（L558-580）：同改，保持“大纲改字 → 局部刷 tspan”不整体重绘。
- `onEdit` 链无需改（text 已是 markdown 纯文本，刷新走 `refreshCardText`）。

**`frontend/styles/canvas.css`：** 新增 `.ol-hl`（背景 `--app-warning-soft` + 圆角 2px + 内边距 1px 3px）、`.ol-link`（`--app-primary` 色 + 下划线 + `text-decoration` 透出）、`.outline-search` 浮层、`.is-dim`（`opacity:.35`）、`.is-search-hit`（`--app-primary-soft` 底）。全部 `--app-*` 令牌。

## 五、边界与坑（实现时必须守住）

- **markdown↔HTML 往返不丢**：`mdToHtml`→`htmlToMarkdown` 逆映射 token 顺序一致；只有白名单标签可序列化；空 `**`/孤 `==` 转义为字面量；快路径保证纯文本行零变化。
- **注入**：写入 innerHTML 前必 `escapeHtml`；href 白名单校验；`onPaste` 纯文本不动。
- **快捷键回归**：富文本三个组合键在 onKeydown 最前短路；手工回归幕布键盘范式（Enter/Tab/Alt↑↓/Ctrl↑↓/Backspace/方向键）。
- **光标稳定**：`updateRow` 的 `editingId` 守卫 + 仅 blur/外部变更时归一化回写。
- **smoke-theme**：新样式仅追加类 + `--app-*` 令牌，`node scripts/smoke-theme.js` 保持 126/126。
- **SVG 换行**：中文/无空格长文本跨段截断，行数上限不变。

## 七、交互定稿（review 后修订，实现以本节为准）

> 本节是对 §二~§五 的易用性修正，冲突处**以本节为准**。目标：所见即所得、样式可撤销、搜索定位真正联动画布。

### 7.1 富文本卡片编辑弹窗「所见即所得」
- `canvas.js` `openEditModal()`：便签卡（note）的 textarea 旁新增一格实时预览区，输入时用 `CanvasInlineMd.mdToHtml` 即时渲染；预览区下方加灰字提示「支持 `**加粗**`、`==高亮==`、`[文字](链接)`」。
- 消除「大纲所见即所得、卡片所见非所得」的割裂。

### 7.2 三个富文本命令统一「手动包/解包」，弃用 execCommand
- **禁用 `document.execCommand('bold')`**（产出不可控，`styleWithCSS` 下会生成 tokenizer 不识别的 `<span style>`，导致加粗丢失）。
- 三个命令统一走同一套「选区归一化 → 包标记 / 命中即解包」的函数：
  - `Ctrl/Cmd+B` → 包/解 `<strong>…</strong>`；
  - `Ctrl/Cmd+Shift+H` → 包/解 `<span class="ol-hl">…</span>`；
  - `Ctrl/Cmd+K` → 包/解 `<a class="ol-link" href="…">…</a>`。
- tokenizer 只认 `STRONG/B`、`SPAN.ol-hl`、`A.ol-link`，与包/解包完全一致。

### 7.3 明确 toggle（取消/编辑）语义
- 加粗 / 高亮：命中已存在同行样式时**再按一次即取消**（解包）。
- 链接：**选中已有链接再 Ctrl+K，弹层预填当前 URL**，并提供明确的「移除链接」按钮；空 URL 确认 = 移除链接（不再是唯一隐蔽路径）。

### 7.4 跨节点选区包/解包的安全处理
- 包/解包前对 Range 做归一化：跨多个标记节点时先 `extractContents` 合并为纯文本再包裹，避免 `surroundContents` 抛 `InvalidStateError`。
- **开工前置**：先写约 20 行 tokenizer + 包解包原型验证通过后，再动 `updateRow`/`onKeydown`/`flushText` 热路径。

### 7.5 搜索定位必须联动画布卡片
- 搜索命中大纲行时，除「展开 + 滚动 + 选中」外，**同步触发 `onSelect(id)`** 反向推给画布（画布已有 `selectNode → CanvasOutline.highlight` 单向联动，此处补反向闭环）。
- `.is-dim` 降透明度不只作用大纲行：画布卡片同步加 `.is-dim-card`（非命中降亮），命中卡片高亮；视觉不割裂。
- 搜索浮层显示命中计数「当前 / 总数」（如 `3 / 12`）。

### 7.6 导入模式 DOM 拆分
- `canvas-ai-outline.js` `buildDom` 拆为两个独立子容器：`importModeEl`（粘贴文本域 + 文件选择 + 反馈行）与 `generateModeEl`（主题输入 + 生成按钮 + 示例 chips）。
- `open()` 只显示 generate 容器、`openImport()` 只显示 import 容器，互不复用 `display` 猜谜。

### 7.7 格式按内容探测，不单靠扩展名
- 导入文本首个非空行以 `<opml`（忽略大小写/前导空白）开头 → OPML 路径；否则 Markdown 路径。
- 选文件时扩展名仅作兜底提示，最终以内容探测为准（粘贴场景无扩展名）。

### 7.8 文件选中反馈
- 选文件后显示「文件名 + 已读取 N 行」轻反馈，让用户确认读对了文件；读取失败给出明确错误行。

### 7.9 OPML `_note` 归属
- `<outline>` 的 `_note` 作为该节点的**子节点**追加（信息不丢、预览可见）；`text` 为节点主文本；无 `text` 的 outline 行忽略。
