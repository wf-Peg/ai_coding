# 画布「手绘画笔」方案（临时擦写板，无导出存储）

## Summary

用户已确认方向：
- **画笔**：在现有自由画布上新增「自由手绘墨迹层」，工具集做到**标准**档（画笔/荧光笔/橡皮擦 + 粗细两档 + 色板 + 撤销 + 清空），对标 NoteGen/Obsidian 的画布标注体验。
- **定位 = 临时擦写板**：墨迹仅本次会话有效，刷新/重进/切页即清空。
- **不做导出、不做存储**：**去掉「导出图片」功能**，墨迹不持久化、不进 SQLite，不引入 html2canvas 依赖。

仅改动两个文件：`frontend/canvas.js`、`frontend/canvas.html`。**数据层 / IPC / 后端零改动**（墨迹不落库，天然满足）。

---

## 一、现状分析（探索结论）

| 项 | 现状 | 依据 |
|---|---|---|
| 图层结构 | `frames-layer`(最底) → `temp-link` → `links` → `nodes` → `selection-layer`(框选矩形) | `canvas.js` `initGraph` |
| 交互 | 节点拖拽 d3.drag、空白左键框选 box-select、连线、缩放平移(d3.zoom filter：仅滚轮/空格/中键平移) | `canvas.js` |
| 手绘能力 | **无**任何画笔/涂鸦代码；canvas 页仅加载 `d3.min.js` | `canvas.html` |
| 持久化 | 节点/连线/布局/分组走 SQLite（`canvas_layout/node/edge/group`）+ 内存桥；**无墨迹表**，本次不新增 | `electron/sqlite/init.js` |

> 结论：手绘作为「会话级临时墨迹层」实现，全部状态存前端内存（`strokes` 数组），刷新即失效——完全绕开墨迹持久化问题，不引入 schema 迁移，也不做导出。

### 关键实现约束

- 输入捕获用一个**屏幕空间 HTML 覆盖层**（`draw-overlay`，绝对定位铺满 `#graphContainer`，激活时 `pointer-events:all`），把指针世界坐标换算成画布世界坐标后，在 **SVG 墨迹层**里画 `<path>`。这样：
  - 在卡片之上也能随意画（覆盖层截获所有指针，避免触发节点拖拽/框选/连线）；
  - 墨迹可以随画布缩放平移（墨迹层在缩放组 `g` 内部）。
- 墨迹层 `inkLayer` 在 `initGraph` 里**最后**追加（SVG 最顶层），并每次 `renderCanvas`（重建 SVG）后从 `strokes` 内存数组重画，保证“新建/删除节点等结构变更”不丢墨迹。

## 二、Proposed Changes

### 文件 1：`frontend/canvas.html`

1. **画布工具条（浮动）**：在 `#graphContainer` 内、`#minimap` 之前放一个 `.draw-toolbar`（`position:absolute; top:12px; left:50%; transform:translateX(-50%); z-index: 90`），横向一排，含：
   - 工具开关：`画笔`(pen) `荧光`(highlighter) `橡皮`(eraser)——一组切换按钮（点中高亮 `is-active`）；
   - 粗细：`细`/`粗` 两档；
   - 色板：黑/灰/蓝/红/绿/橙 6 个色块（`<button class="swatch" data-color=...>`）；
   - 分隔线；
   - `撤销`、`清空`。
   - 顶部加一行极简提示文字（工具条 title 或旁注）：`手绘为临时擦写，刷新即清空`。

2. **样式（`<style>` 内）**：
   - `.draw-toolbar`：`background: var(--surface); border:1px solid var(--border); border-radius:12px; box-shadow: var(--app-shadow-md); padding:6px 10px; display:flex; align-items:center; gap:6px; flex-wrap:nowrap;` 窄屏允许缩小/横向滚动。
   - `.draw-toolbar button`：无边框圆角按钮，`color:var(--text-soft/secondary)`；hover `background: var(--app-primary-soft)`；`.is-active` 用 `background:var(--app-primary); color:#fff`。
   - `.swatch`：`16px` 圆形色块，内描边 `1px var(--border)`，选中加 `outline:2px solid var(--primary)`。
   - `.draw-overlay`：`position:absolute; inset:0; cursor:crosshair; display:none;`（画板时 `display:block; pointer-events:all`；非画板 `pointer-events:none`）。

3. **保留现有** `nav-hint`（可追加“选中画笔可随手标注”）。

### 文件 2：`frontend/canvas.js`

1. **常量与状态**（模块顶部，`GRID` 附近）：
   ```js
   const INK_COLORS = ['#222','#6b7280','#1a73e8','#e5484d','#30a46c','#f76b15'];
   const INK_WIDTH = { thin: 2, bold: 6 };      // 画笔 / 荧光笔粗细基底
   let drawTool = null;         // null | 'pen' | 'highlighter' | 'eraser'
   let inkSize = 'thin';        // 粗细档
   let inkColor = INK_COLORS[0];
   let strokes = [];            // 墨迹数据 [{id,color,width,opacity,points:[[x,y]...]}]
   let drawing = null;          // 进行中的墨迹 {el, points, color, width, opacity}
   ```
2. **墨迹层**：`initGraph` 里在 `selectionLayer` 之后追加
   ```js
   inkLayer = g.append('g').attr('class','ink-layer');
   renderInk();
   ```
   `renderInk()`：`inkLayer.selectAll('*').remove()` 后遍历 `strokes` 追加 `<path>`（`fill:none; stroke:color; stroke-width:width; opacity; stroke-linecap:round; stroke-linejoin:round`，`d` 用 `M x y L x y …`）。

3. **覆盖层 + 指针绘制**：
   - 写一个 `<div class="draw-overlay">`（HTML 内已建，JS 里 `document.getElementById('drawOverlay')`），并在 `setDrawTool(tool)` 里控制 `display`（画板工具激活→显示；`null`→隐藏并置 `drawing=null`）。
   - 覆盖层绑定 `mousedown`/`mousemove`/`mouseup`/`mouseleave`：
     - 坐标一律 `screenToWorld(event)`（复用现有 `currentTransform.invert(d3.pointer(...))`）。
     - `pen/highlighter`：`mousedown` 新建 `drawing`，在 `inkLayer` 追加临时 `<path>`（首点 `M`）；`mousemove` 追加线段并更新 `d`（必要时抽稀：与上点距离 <2px 跳过）；`mouseup`/`mouseleave` 收敛为 `strokes`，`drawing=null`。
     - `eraser`：`mousemove` 时取世界点，遍历 `strokes` 用**折线点到折线距离**判断命中（逐段 `min(distance)`，半径 8px），命中则从 `strokes` 移除该条并 `renderInk()`。左键按住连续擦，mouseup 停。
   - 拿起抑制：覆盖层 `mousedown` 里 `event.preventDefault()`，顶层盖住卡片故不会触发节点交互。
4. **交互守护**（避免画板时误触图形）：
   - `beginBoxSelect` 开头：`if (drawTool) return;`
   - `dragBehavior` 的 `.filter(...)`：`function(){ return !spacePressed && !drawTool; }`
   - `groupDragBehavior` 的 `.filter(...)`：同样加 `&& !drawTool`。
   - 连线/其他照旧：`drawTool` 激活时覆盖层盖住，连不进。
5. **工具条事件绑定**（`DOMContentLoaded` 或模块尾部）：
   - 工具切换 → `setDrawTool('pen'|'highlighter'|'eraser'|null)`；同步高亮 `.is-active`。
   - 粗细/色板 → 改 `inkSize`/`inkColor`（简单起见仅影响后续笔触）。
   - `撤销`：`strokes.pop(); renderInk();`
   - `清空`：`strokes=[]; renderInk();`

## 三、Assumptions & Decisions

1. **墨迹临时 + 无导出**：只存前端内存 `strokes[]`，刷新/重进/切页清空；**不做 SQLite 迁移、不动数据层、不做「导出图片」**。画布定位为临时擦写板，不承担导出/留档职责（用户明确）。
2. **墨迹随画布缩放平移**：墨迹层在缩放组 `g` 内、用世界坐标；`stroke-width` 会随 zoom 缩放（与卡片一致，属预期）。
3. **橡皮擦=整条擦除**：按「指针离墨迹折线最近距离 < 8px」命中后删除整条墨迹（点擦在 SVG/跨图层下不稳健，v1 用整条擦，简单可靠）。
4. **不改节点模型**：只在现有 SVG 上加一个墨迹层与工具条。
5. 复用现有主题 token 与绘制交互链路（`screenToWorld`/`d3.pointer`），不新造轮子。

## 四、Verification

1. **语法**：`node --check frontend/canvas.js`。
2. **浏览器实测**（`http://127.0.0.1:3001/canvas.html`，后端未起时先用内存桥注入节点，见下）：
   - 点「画笔」后，在画布/卡片上拖动能画出彩色线条；「荧光」为半透明宽笔触；缩放/平移后墨迹跟随画布。
   - 「橡皮」划过墨迹线条，命中的整条被擦除。
   - 「撤销」删最后一条；「清空」全清。
   - 切换笔/荧光/橡皮时，节点仍可框选/拖拽/连线（不画板时行为回归不变）。
   - 新建/删除一个节点后，已有墨迹不丢失（`renderCanvas` 重建后 `renderInk` 还原）。
3. **回归**：非画板工具时，空格/滚轮/中键平移缩放、节点拖拽吸附、框选分组、连线、空白双击新建均保持原样。
4. **临时语义验证**：刷新/重进画布后墨迹清空（不落库、无导出入口）。
