# 编辑器「插入模板」功能设计方案

> 状态：规划（待确认后实施）
> 背景：命令面板「插入模板…」点击后报错 `模板加载失败：(list || []).map is not a function`；斜杠菜单（输入 `/`）无模板入口；无模板管理能力。

---

## 一、现状分析（已探索确认）

### 1.1 报错根因（契约 bug）
- 主进程 `electron/main.js` L3874-3884 的 `editor-list-templates` IPC 返回 **对象** `{ success, dir, templates: [{name, path}] }`。
- 渲染进程 `frontend/js/editor.js` 却把返回值**当数组**使用：
  - L7380-7381 `insertTemplateByName`：`(list || []).find(...)` → 对象无 `.find`，抛错。
  - L7399-7400 `openTemplatePicker`：`(list || []).map(...)` → 对象无 `.map`，抛错 → 即用户看到的报错。
- `editor-read-template` 返回 `{ success, content }`，前端 L7384 直接 `api.readTemplate(tpl.name)` 拿到整个对象传给 `replaceTemplateVars`（当字符串 split），同样是隐式契约 bug。

### 1.2 已具备的能力（可复用）
- IPC 已存在：`editor-list-templates` / `editor-read-template` / `editor-save-template`（main.js L3874/3887/3902）；preload 已暴露 `listTemplates` / `readTemplate` / `saveTemplate`（preload.js L372/379/386）。
- 模板目录：`{vaultRoot}/templates/`（`resolveTemplatesDir`，main.js L3864），只收 `.md/.txt`。
- 变量替换 `replaceTemplateVars`（editor.js L7366-7374）：已支持 `{{date}}`/`{{now}}`/`{{title}}`；`{{author}}` 硬编码为空串。
- 命令面板：`registerCommand` 注册表 + `renderCommandList` 统一渲染（editor.js L7058-7164），item 结构 `{id,name,icon,handler,shortcut}`。
- 斜杠菜单：静态 `SLASH_ITEMS` 分组（标题/插入/AI，editor.js L2567-2586），`renderSlashMenu`/`executeSlashItem`（L2588/L2692）。
- 模态框模式：`.modal-backdrop.is-visible`（editor.css L1244-1257），参照 `dictModal`（editor.html L710-750、editor.js `openDictModal` L6087）。
- 工具函数齐备：`escapeHtml`（L6080）、`showToast`（L3453）、`openModal`/`closeModal`（L3101-3107）、`getElectronAPI`（L216）。

### 1.3 隐藏 bug（本次一并修复）
`openTemplatePicker` 复用命令面板时把 `paletteOpen=true` 并渲染模板列表，但**输入框打字会走 L7149 的 `renderCommandList`，把模板列表替换成命令注册表**——模板模式下过滤功能完全失效。需要引入 `paletteMode` 状态区分。

## 二、设计方案

### 2.1 契约统一：模板数据加载 helper
新增 `loadTemplateList()`（Promise，返回规范化的模板数组）：

```javascript
function loadTemplateList() {
  var api = getElectronAPI();
  if (!api || !api.listTemplates) return Promise.reject(new Error('模板功能仅桌面模式可用'));
  return api.listTemplates().then(function(result) {
    if (!result || !result.success) throw new Error((result && result.message) || '模板加载失败');
    return (result.templates || []).slice();
  });
}
```

所有消费方（选择器 / 斜杠菜单 / 管理弹窗）统一走它，从根上杜绝“对象当数组”类契约 bug。

### 2.2 命令面板模板选择器（修复 + 过滤）
引入 `paletteMode`（`'command' | 'template'`）：

- `openCommandPalette()`（L7093）与 `closeCommandPalette()`（L7103）分别置 `paletteMode='command'`。
- 新增模块级缓存 `paletteTemplateEntries = []`。
- 重写 `openTemplatePicker()`（L7396）：`loadTemplateList()` → 空列表时 toast「暂无模板，请在模板管理中新建」；非空时构建 `paletteTemplateEntries`（结构 `{id:'tpl-'+name, name, icon:'📌', handler: ()=>insertTemplateByName(name)}`），置 `paletteMode='template'` 后复用现有面板打开流程。
- `renderCommandList(query)`（L7110）改为按 `paletteMode` 选数据源：`template` → `paletteTemplateEntries`，`command` → `commandRegistry`；渲染逻辑不变（icon/name/shortcut 结构相同，天然复用）。
- **删除** 旧函数 `renderTemplateList`（L7416）与 `executeTemplate`（L7428）——被通用路径取代。

### 2.3 斜杠菜单动态模板组（双入口之二）
- 新增 `loadSlashTemplates()`：`loadTemplateList()` 成功后缓存到 `slashTemplates`，若菜单仍打开则 `renderSlashMenu() + positionSlashMenu()`（异步补渲染）。
- `openSlashMenu()`（L2646）末尾调用 `loadSlashTemplates()`。
- `SLASH_ICON` 新增 `template` 图标（沿用 ctx-icon 风格，如文档/文件 SVG）。
- `renderSlashMenu()`（L2588）在 AI 组后追加动态「模板」组：`slashTemplates` 非空时渲染 `{id:'tpl-'+name, title:name, keywords:'template 模板 插入 '+name, icon:'template', templateName:name}`。
- `executeSlashItem()`（L2692）在 `item.ai` 分支后新增：若 `item.templateName` → 先按 L2703-2710 的既有 `/` 前缀删除逻辑算 range 并 `closeSlashMenu()`，再 `insertTemplateByName(item.templateName)`（异步插入）。

### 2.4 插入函数修复 + 变量替换完善
- 重写 `insertTemplateByName(name)`（L7376）：`loadTemplateList()` 找目标 → `api.readTemplate(name)` 校验 `success` → `replaceTemplateVars(content)` → 光标处插入 → focus → toast。
- `replaceTemplateVars(content, author)` 增加可选参数：`{{author}}` 取该参数，否则空串。
- 插入前尝试 `getElectronAPI().getConfig()` 读取 `config.author || config.authorName` 作为作者值（config.json 手填，无则空；不新增设置项，控制范围）。

### 2.5 模板管理弹窗（新建/编辑/删除）
**`frontend/editor.html`**：在 dictModal 后新增 `templateModal`（`.modal-backdrop` 结构，参照 L710-750）：

- 头部：标题「模板管理」+ 说明「存储于知识库 templates 目录」+ 关闭按钮。
- 编辑区：`templateNameInput`（模板名，自动补 `.md` 后缀）+ `templateContentInput`（textarea，placeholder 注明支持 `{{date}} {{now}} {{title}} {{author}}`）+「保存模板」按钮 +「取消编辑」按钮（编辑既有模板时显示）。
- 列表区 `templateList`：每行 = 名称 + 「编辑」「删除」按钮；删除采用**两段式确认**（点击后按钮变「确认删除」，3 秒内再点才执行，避免新增确认弹窗）。

**`frontend/js/editor.js`**：

- `openTemplateManager()`：打开 modal + 刷新列表（`loadTemplateList()` 渲染）。
- `renderTemplateManagerList()`：渲染名称行 + 编辑/删除按钮；删除调 `api.deleteTemplate(name)`（新增 IPC）。
- 编辑：点「编辑」→ 该模板 `readTemplate` 内容填入 name/content 输入框，显示「取消编辑」。
- 保存：校验名称（空/非法字符）、后缀非 `.md/.txt` 时自动补 `.md` → `api.saveTemplate({name, content})` → 成功刷新列表 + toast。
- `closeTemplateManager()`：`closeModal` + 清空输入框/取消编辑态。
- 注册命令 `registerCommand('manage-templates', '管理模板…', '🗂', openTemplateManager)`。
- `elements` 映射（L87 附近）追加新 DOM id。

**`frontend/styles/editor.css`**：新增 `.template-modal-card`、`.template-content`（textarea 高度 ~180px）、`.template-list`、`.template-item`、`.template-actions` 等，复用 `--app-*` 变量，风格对齐 `.dict-modal-card`（L2950 起）。

### 2.6 主进程新增删除 IPC + preload
**`electron/main.js`**（在 L3902 保存 handler 后追加）：

```javascript
ipcMain.handle('editor-delete-template', async (event, name) => {
  try {
    const safe = String(name || '').replace(/[\\/:*?"<>|]/g, '_');
    if (!safe) throw new Error('模板名无效');
    const dir = resolveTemplatesDir();
    const filePath = path.join(dir, safe);
    if (!filePath.startsWith(dir) || !fs.existsSync(filePath)) throw new Error('模板不存在：' + name);
    fs.unlinkSync(filePath);
    log.info('[EditorTemplate] deleted', filePath);
    return { success: true };
  } catch (err) {
    return { success: false, message: err.message };
  }
});
```

**`electron/preload.js`**（L386 后追加）：

```javascript
deleteTemplate: (name) => ipcRenderer.invoke('editor-delete-template', name),
```

## 四、假设与决策

| 决策点 | 结论 |
|--------|------|
| 模板目录 | 沿用现有 `{vaultRoot}/templates/`，不迁移 |
| 支持后缀 | 沿用 `.md/.txt`；新建时未写后缀自动补 `.md` |
| 模板编辑形态 | 管理弹窗内 textarea 编辑（自包含），**不**把模板当普通文件在编辑器标签中打开（避免污染标签语义与保存链路） |
| 删除确认 | 两段式按钮确认（无新增确认弹窗） |
| `{{author}}` | 读 `config.json` 的 `author`/`authorName`，无则空；不新增设置 UI（控制范围，后续可扩展） |
| 命令面板过滤 | 以 `paletteMode` 区分数据源，复用现有渲染/导航/键盘路径 |
| 斜杠菜单入口 | 模板异步加载后追加动态「模板」分组，菜单已开时增量补渲染 |

## 五、验证步骤

1. **契约修复**：启动 `npm start` → 打开编辑器 → `Ctrl+P` → 「插入模板…」→ 不再报 `(list || []).map is not a function`，正确列出 `templates/` 下模板（无模板时提示新建）。
2. **模板模式过滤**：模板选择器中输入关键词过滤正常、↑↓/Enter/Esc 与命令模式一致；Esc 关闭后 `Ctrl+P` 恢复命令列表。
3. **插入**：选中模板 → 内容插入光标处，`{{date}}/{{now}}/{{title}}` 正确替换；配置了 `author` 时 `{{author}}` 生效。
4. **斜杠菜单**：行首输入 `/` → 弹出后出现「模板」分组 → Enter 插入并删除 `/` 前缀。
5. **管理弹窗**：`Ctrl+P` → 「管理模板…」→ 新建（自动补 `.md`）/编辑（内容回填）/删除（两段确认）均生效，刷新列表一致。
6. **持久化**：新建后检查 `{vaultRoot}/templates/` 出现对应文件；重开应用列表仍在。
7. **回归**：命令面板其他命令、斜杠菜单标题/插入/AI 组、设置弹窗、词典弹窗不受影响。
