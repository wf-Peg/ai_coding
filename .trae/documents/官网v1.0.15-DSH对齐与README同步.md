## Proposed Changes

### A. 官网版本对齐（`website/index.html`）

1. **footer 版本**：`index.html:1014` `<span class="footer-ver">v1.0.16</span>` → `v1.0.15`。
2. **下载兜底版本**（一致性，一步到位）：`index.html:1050-1056` 中 `BUILTIN_TAG` 与 5 条 `BUILTIN` 直链里的 `v1.0.14` 文案统一改为 `v1.0.15`。说明：这些仅是「API 解析失败时的兜底直链」，主线仍走同域 `/api/releases` 动态解析，改版本不会破坏正常下载。（若 `v1.0.15` 资产尚未上传 Release，仅影响兜底直链，不阻断主流程。）

### B. DSH 模块说明（`website/index.html`）

1. **特性卡**：在 `#features` 的 `.features` 网格末尾（`index.html:706` 第六张卡之后）新增第 7 张 `.feature reveal` 卡：
   - 图标：对话气泡 / 芯片风格 SVG（沿用现有 24×24 stroke 语法）。
   - 标题：`DSH 集成`
   - 文案：`DeepSeek Harness Agent 接入：内嵌「AI 干活」面板，让 AI 用你的知识库干活，干完自动落库沉淀。`
2. **使用文档小节**：在 `#docs` 的 `doc-tools`（`index.html:918`）之后、`doc-extension` 之前新增 `doc-sec id="doc-dsh"`，标题 `DSH 集成（AI 干活的底座）`，内容覆盖（事实依据 `integrations/dsh/README.md`）：
   - MCP 桥 13 个只读/写工具（剪藏 CRUD/待办/学习计划/Wiki 索引/周报状态/Tools Hub）。
   - 会话成果自动落库（`clip_session`，`source=dsh`）。
   - 内嵌「AI 干活」面板（固定端口 3081，按需启动/复用/离线打包）。
   - 技能包「一键安装」（`cut-shelter` SKILL）。
3. **文档目录**：`index.html:754-765` 的 `docs-toc` 增加 `<a href="#doc-dsh">DSH 集成</a>`（放在「工具模块」之后）。

### C. 功能 / 优势对标（`website/index.html`）

1. **新增区块 `#why`「为什么选择碎碎记」**：放在 `#features`（`index.html:710`）之后、`#workflow` 之前。`sec-kicker: Why CutShelter`，`sec-title: 为什么是你长期沉淀的第⼀选择`。含 4 张差异化卡（复用 `.feature` 语义，新 `.why-card` 轻量样式，全部消费 `--app-*` token）：
   - **本地优先 · 隐私**：数据纯文本存于本地、离线可用，不绑定云端账号（对标 Notion 云依赖）。
   - **剪藏全链路闭环**：截图/粘贴/链接/插图/文档 → 收件箱 → 一键 AI 整理 → 写作/知识库（对标 Cubox/YouMind 的收藏体验）。
   - **AI 助手 + DSH 深度集成**：AI 回答附来源、可一键整理；DSH Agent 直接读/写你的知识库（对标 NoteGen/YouMind 的 AI 能力）。
   - **无限画布 × 知识图谱**：双链关联 + 可视化画布把碎片知识连成第二大脑（对齐 Notion/YouMind 的知识组织）。
2. **对标参考表**：在同一区块内加一张紧凑对比表（新增 `.compare` 样式，移动端横向滚动），列维度 = `定位 / 存储与离线 / 剪藏闭环 / AI 能力 / 知识组织`，行 = `碎碎记 CutShelter / YouMind / Notion / NoteGen`。文案只做客观能力对照，不贬低竞品。

> 文案以「产品目前实际功能」为准，参考 `docs/产品说明书.md`（剪藏/待办/学习计划/知识库/知识图谱）与 `integrations/dsh/README.md`（DSH 能力），避免虚构未上线功能。

### D. 增量视觉打磨（`website/index.html` 的 `<style>`，不改结构）

在现有 token 体系内做以下优化（**不引入硬编码色值**，全部复用 `--app-*`）：

1. **Hero 焦点**：
   - `body`/`.hero` 增加一层极淡的径向渐变背景（用 `--app-primary-soft` 低透明度叠加），提升层次。
   - `appmock` 阴影升级为更柔的 `--app-shadow-xl`，并加 1px `--app-border-strong` 描边 + 顶部高光边框。
2. **排版节奏**：
   - `.hero h1` 字号 42→46px，`letter-spacing` 微调；`.sec-title` 28→30px，`.sec-kicker` 颜色/字距微调。
   - `.hero-desc` / `.sec-desc` 行高 `line-height` 统一到 1.7–1.75，增强可读性。
3. **卡片高级感**：
   - `.feature`/`.dl-card`/`.wf-step`/`.trust-card` hover 的 `translateY(-3px)` 统一为 `-4px`，阴影从 `--app-shadow-md` → `--app-shadow-lg`，过渡曲线保持 `--app-ease-smooth`。
   - `.feature-icon`/`.dl-icon`/`.d-ic` 增加极淡渐变背景（`--app-primary-soft` → 透明），图标 hover 微放大。
4. **按钮**：`.btn-primary` 增加 hover 轻微上浮与 `--app-shadow-md`，保持 `--app-primary` 主色。
5. **响应式**：新增的 `.why-card`/`.compare` 在 ≤960px/≤640px 断点补回退（2 列/1 列、表格横向滚动），与现有 media query 风格一致。
