# 编辑器右键菜单与"输入/唤起·直接开始写作"改版

> 范围修正说明：用户原话"画布右键弹出栏"实际指**编辑器模块**（编辑器工作区右键菜单），非知识图谱画布。本文档以编辑器为准。

## 优先级（大白话）

| 优先级 | 事项 | 为什么先做 |
|---|---|---|
| **P0** | 编辑器右键菜单改版（emoji → SVG 图标、分组、键盘导航、贴边翻转） | 改动集中在一个菜单组件上，见效最快，直接决定产品第一观感 |
| **P0** | 斜杠命令（输入 `/` 唤起菜单） | NoteGen 招牌功能，"输入/唤起菜单"的核心，编辑器是 Ace 需自行监听输入，属新能力、工作量大，但价值最高 |
| **P1** | 直接开始写作（空文档居中引导） | 打开即写的感觉，改动小，增强仪式感与引导 |
| **P2** | `⌘K` 唤起命令面板（Ctrl+P 增加别名） | 已有 Ctrl+P，加别名成本低，对齐 NoteGen 肌肉记忆 |

## Summary

对**编辑器模块**（frontend/editor.html、frontend/js/editor.js、frontend/styles/editor.css）做三项改造：
1. **右键菜单改版**：现有 15 项 emoji 文字菜单升级为 NoteGen 风格——SVG 线框图标、分组分隔、键盘 ↑↓+回车 导航、hover/危险态、入场动画、贴边视口翻转定位；**现有菜单项与选中态显隐逻辑全部保留**。
2. **输入/唤起菜单（斜杠命令）**：在 Ace 编辑器内输入 `/` 自动弹出命令菜单（插入图片/链接/代码块/表格/标题/引用/待办/分隔线、AI 续写/润色），实时过滤、键盘操作、插入到光标处——对齐 NoteGen 编辑器斜杠菜单。
3. **直接开始写作**：打开空文档时居中显示"开始写作…"引导层，点击或任意输入即进入写作，并提示"按 `/` 唤起命令菜单"。

**源码移植结论**：NoteGen（github.com/codexu/note-gen，GPL-3.0）**不可直接搬运**——GPL-3.0 传染整个闭源项目，且其实现重度依赖 React/Tiptap/radix（`@tiptap/suggestion`、cmdk、shadcn）。改为**原生 JS + Ace 重写**，仅借鉴其与框架无关的交互/视觉/纯算法（条目过滤、视口翻转定位）。

## Proposed Changes

### A. 右键菜单改版（P0）

**A1. editor.html L592-619**：保留结构与全部 `data-context-action` 按钮（动作/显隐逻辑零改动），仅将每项文字前缀 emoji 换成内联 SVG 图标（`<svg class="ctx-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">…</svg>`，16px，与工具栏同风格），例如：复制=文档复制、剪切=剪刀、粘贴=剪贴板、全选=框选、格式化=魔棒、自动换行=文本折行、AI=星星、翻译=语言、词典=书、管理=设置。危险项（当前无）预留 `.danger` class。

**A2. editor.js**：
- `openEditorContextMenu`（L1919-1922）定位升级为**视口翻转**：先显示测量 `offsetWidth/offsetHeight`，若右溢出则 `left = x - menuWidth`，若下溢出则 `top = y - menuHeight`，再钳制 ≥8px 留白（参考 NoteGen `calculateMenuPosition` 思路）。
- 新增键盘导航：菜单打开时（仅当菜单可见）监听 keydown——↑↓ 移动 `.focused` 高亮（视觉与 hover 相同）、Enter 触发 `executeEditorContextAction`、Esc 关闭；鼠标移入同步高亮；打开时把焦点留在菜单内，关闭恢复。关闭沿用 document click（L2316）+ Esc。

**A3. editor.css `.editor-context-menu`**：min-width 220px、padding 6px、radius 10px、`--app-shadow-md`、入场动画（opacity+translateY 120ms，`prefers-reduced-motion` 降级）；菜单项 icon 16px + 文字 gap 10px、padding 8px 12px、hover/focused 用 `--app-primary-soft` 底；`.editor-context-divider` 用 `--app-border`。全部走 `--app-*` 令牌自动适配明暗主题。

### B. 输入/唤起菜单——斜杠命令（P0，新能力）

**B1. DOM（editor.html，编辑器面板内新增浮层）**：
```html
<div class="slash-menu" id="slashMenu" hidden role="dialog" aria-label="命令菜单">
  <div class="slash-menu-list" id="slashMenuList"></div>
  <div class="slash-menu-hint">↑↓ 导航 · Enter 插入 · Esc 关闭</div>
</div>
```
（渲染形态复刻现有命令面板列表样式。）

**B2. JS（editor.js）**：
- 条目注册表 `SLASH_ITEMS`（模型对齐 NoteGen `SlashCommandItem`：`{ id, title, icon(SVG), group, keywords, insert }`）：
  - 标题组：H1/H2/H3（`# ` 前缀）
  - 插入组：图片、链接、代码块、表格、引用（`> `）、待办（`- [ ] `）、分隔线（`---`）
  - AI 组：AI 续写、AI 润色（复用现有 sendAiMessage/buildPrompt 管线）
- 触发：`mainEditor.session.on('change')`（防抖 ~150ms）→ 取光标所在行 `/\S*$/` 前文，若**行首（仅空白前缀）**为 `/` 则打开菜单；继续输入过滤（`filterItems(q)` = label/keywords 小写 includes，参考 NoteGen 纯算法）；删除 `/` 或光标移动出条件自动关闭。
- 定位：光标像素位置（`mainEditor.renderer.$cursorLayer.getPixelPosition(...)` + 容器 offset 换算屏幕坐标），视口翻转逻辑复用 A2 的定位函数。
- 执行：`session.replace`/`mainEditor.insert` 替换掉 `/` 前缀并插入条目 snippet；AI 项走既有 AI 流程；执行后关闭菜单并聚焦编辑器。
- 键盘：↑↓ 循环高亮、Enter 执行、Esc 关闭；空结果显示"无匹配命令"空态行；点击菜单外关闭。
- 与现有 Ctrl+P 命令面板互不干扰（不同的浮层与触发器）。

**B3. 样式（editor.css `.slash-menu`）**：居中于光标下方、max-height 320px + 滚动、分组标题（`--app-text-muted` 小字）、条目 icon+title+keywords 提示、高亮 `--app-primary-soft`、hint 复用命令面板样式；主题令牌化。

### C. 直接开始写作（P1）

- **C1. DOM（editor.html）**：编辑器面板内新增空态覆盖层：
  ```html
  <div class="start-writing" id="startWriting" hidden>
    <div class="start-writing-main">开始写作…</div>
    <div class="start-writing-hint">按 <kbd>/</kbd> 唤起命令菜单 · 或直接输入内容</div>
  </div>
  ```
- **C2. JS（editor.js）**：在文件打开/新建/内容变化时同步显隐——当前文档内容为空时显示，点击覆盖层或用户首次输入（Ace 获焦/内容非空）时隐藏并聚焦编辑器；不影响既有 `browserFileInput`/标签打开逻辑。
- **C3. 样式（editor.css `.start-writing`）**：绝对定位于编辑器区域中央，主文案大号（`--app-text-muted`）、hint 小字；`kbd` 键帽样式；点击穿透到编辑器聚焦。

### D. ⌘K 命令面板别名（P2，低成本）

- [editor.js] 命令面板打开逻辑（L6495 附近）增加 `Cmd/Ctrl+K` 快捷键注册（复用 `EditorShortcuts`），与 Ctrl+P 等价唤起；文档/设置页快捷键提示同步更新（editor-shortcuts.js 的 `commandPalette` 条目加别名）。

## Assumptions & Decisions

1. 范围 = **编辑器模块**（用户澄清），知识图谱画布不在本次范围。
2. 右键菜单**保留现有 15 项与显隐逻辑**，仅视觉/交互升级，不新增 NoteGen 的复制粘贴类项（Ace 已有原生复制粘贴）。
3. "输入/唤起菜单" = **编辑器斜杠命令**；"直接开始写作" = **空文档居中引导层**；两者都做，⌘K 别名按 P2 顺带。
4. 图标统一 **16px SVG 线框**（`currentColor`，与工具栏一致），弃用 emoji。
5. **不搬运 GPL-3.0 源码**；实现时仅把 NoteGen raw 文件当算法参考（过滤/定位）：
   - `https://raw.githubusercontent.com/codexu/note-gen/dev/src/app/core/main/editor/markdown/slash-command/suggestion.tsx`
   - `.../slash-command/slash-command-portal.tsx`
6. 新样式全部走 `--app-*` 令牌，明暗主题自适应；不动后端。
