Electron 透明窗口残影问题排查

问题：macOS 上透明窗口用 CSS opacity/transform 做淡入淡出，会出现黑色残影。

原因

合成器对透明窗口的 CSS 透明度处理与普通窗口不一致，动画期间未正确合成。

结论

  • 改用窗口级 setOpacity()
  • 透明窗口显式 backgroundColor: '#00000000'
  • 显示前重置 setOpacity(1)
