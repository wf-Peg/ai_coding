记录时不做选择题，先进收件箱；需要整理时，一键交给 AI 分类归档。

4

快速上手

① 安装与启动

安装桌面客户端后首次启动，将自动拉起本地后端服务与 OCR 模型初始化，状态栏可见「后端就绪」提示，即可开始使用。

② 完成第一次记录

在「剪藏」页顶部点「快速记录」一键发起（文本 / 插图 / 链接 / OCR），或点记录条展开完整表单；选择「稍后整理」，内容即进入收件箱。

③ 整理收件箱

进入「收件箱」视图，选中条目点击「整理」；AI 将自动生成摘要、分类与标签，沉淀为结构化笔记。

④ 浏览器里随手剪藏

安装「智能剪藏助手」浏览器插件，网页内容右键或快捷键一键进收件箱，稍后统一整理。

⑤ 开始写作与沉淀

整理完成的笔记可在编辑器中继续编辑，或进入知识库 / 知识图谱查看关联，形成你的个人知识网络。

离线可用：除「AI 整理 / AI 问答」需要联网调用大模型外，剪藏、OCR、编辑、存储等核心能力均可离线使用。

收件箱与整理

状态徽章

  • 待整理（橙）——在收件箱中等待整理
  • 已整理（绿）——已完成 AI 整理归档
  • 其它（灰）——归档等其它状态

批量操作

  • 勾选多条后浮现操作条：批量整理 / 删除
  • 删除带 240ms 动画 + Toast 撤销（6 秒内可恢复）

折叠式记录入口

表单默认折叠为一条记录条，按需展开、提交后自动收起，列表始终是主显示区；「待整理」默认筛选，快速记录一键直达。

每日回看

把「收藏完就忘」的旧内容重新翻出来：跳过 / 归档 / 仍有用，1 分钟完成回顾。

从收件箱到写作

整理为笔记后自动推送编辑器，在「最近」分组置顶显示「来自收件箱」，闭环直达。

知识库与知识图谱

剪藏落库

每一条剪藏对应一个 Markdown 文件，AI 字段自动写入 frontmatter，可直接在 Obsidian 等工具中打开使用。

双链关联

支持 `[[笔记名]]` 双向链接，反链、出链面板实时展示，知识互联互通。

无限画布

节点自由摆放、手动连线、分组整理，从知识图谱延伸出可视化的思考空间。

AI 助手「小记」

三种上下文

选中记录 / 整个剪藏库 / 当前文档——面板顶部指示器会明确告知「小记」正在看什么。

来源引用

回答附带来源卡片，可跳转原文，也可一键「整理为笔记」，直接进入写作。

Prompt 可配置

剪藏分析、整理收件箱、周报总结等场景的 Prompt 均可按需自定义。

工具模块

截图工具

全屏 / 选区截图，标注、贴图、取色一应俱全，快捷键可自定义。

离线 OCR

模型内置，对截图或插图一键识别文字，断网可用。

PDF 处理

合并、拆分、提取文本，内置工具不依赖外网服务。

提示词库

收藏常用 Prompt，分类管理，一键应用到系统槽位。

DSH 集成（AI 干活的底座）

碎碎记内置 DeepSeek Harness（DSH） 集成，让 AI Agent 能直接检索与写入你的知识库——「AI 用你的知识库干活，干完自动落库沉淀」。

内嵌「AI 干活」面板

桌面端侧栏进入即用，DeepSeek Harness 面板按需启动、可复用，离线打包可用，无需额外安装。

MCP 桥 · 13 个工具

剪藏检索/新增/删除、待办管理、学习计划、Wiki 索引、周报状态、Tools Hub——Agent 可直接读写你的知识库。

会话成果自动落库

Agent 完成一段有保留价值的工作后，成果摘要自动成为一条剪藏（source=dsh），沉淀进知识库。

技能包一键安装

内置 cut-shelter 技能，让 DSH 按剪藏知识库的读写规范操作，行为更可控。

浏览器插件

配套扩展「智能剪藏助手」，在浏览器里随时把网页内容一键收进碎碎记——配合桌面端收件箱，形成「网页读到 → 随手剪藏 → 稍后整理」的闭环。

三种剪藏方式

  • 右键菜单：剪藏整个页面 / 选中内容 / 图片
  • 快捷键：Ctrl+Shift+S 剪藏页面，Ctrl+Shift+V 剪藏选中内容（macOS 为 Cmd）
  • 弹出窗口：点击工具栏图标，手动输入或粘贴后添加剪藏

智能内容提取

自动识别并提取网页正文，去除导航、广告等噪音；支持 CSS 选择器规则自定义提取范围。

灵活配置

  • API 地址、超时与重试次数可配置
  • 默认剪藏类型（AI 整理 / 仅存储 / 链接解析 / 文档解析）
  • 自动生成标签、记录来源 URL、成功通知开关
  • 界面风格跟随（常规 / Notion）

快速安装

浏览器打开 chrome://extensions/，开启开发者模式 → 「加载已解压的扩展程序」，选择项目的 browser-extension 目录即可。

使用前提：插件需与桌面端后端服务配合使用，首次使用请在插件设置中配置 API 地址（默认 http://127.0.0.1:8081）并「测试连接」。
